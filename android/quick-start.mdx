## Requirements

- **Android**: 7.0 (API 24) and above
- **Language**: Java
- **ABIs**: `armeabi-v7a`, `arm64-v8a`
- **SDK**: Facebetter **2.0.0** (`net.pixpark:facebetter:2.0.0`)

## Get the sample

Clone the [GitHub repository](https://github.com/pixpark/facebetter-sdk) and open `demo/android` in Android Studio.

```bash
git clone https://github.com/pixpark/facebetter-sdk.git
```

## Bind the package name and credentials

### Bind the application package name

Follow [Subscribe](/intro/enable-service#bind-application-information) and bind your Android **application package name** in the Dashboard, for example `com.example.app`.

### Create the engine

Follow [Subscribe](/intro/enable-service#get-appid-and-appkey) to copy `appId` / `appKey`, or use a `licenseToken`. Open the demo camera Activity and set `EngineConfig` before `new BeautyEffectEngine(...)`.

**Online** (`appId` + `appKey` → `/facebetter/v2/auth`):

```java
BeautyEffectEngine.EngineConfig config = new BeautyEffectEngine.EngineConfig();
config.appId = "your appId";
config.appKey = "your appKey";
mBeautyEngine = new BeautyEffectEngine(this, config);
```

**Token** (license token string, `{token}` JSON, or offline `.lic` contents). If `licenseToken` is non-empty, it wins and the SDK does not call the network with `appId` / `appKey`:

```java
BeautyEffectEngine.EngineConfig config = new BeautyEffectEngine.EngineConfig();
config.licenseToken = "/* license token, {token} JSON, or .lic contents */";
mBeautyEngine = new BeautyEffectEngine(this, config);
```

<Tip>
Auth modes and offline `.lic` files: [License & Auth](/intro/license).
</Tip>

## Run

Sync Gradle in Android Studio, pick a device or emulator, and run.
