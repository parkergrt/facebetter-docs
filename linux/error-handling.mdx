## Return values

| Code | Meaning |
| --- | --- |
| `0` | Success |
| `-1` | Invalid argument |
| `-2` | Not initialized |
| `-3` | License |
| `-4` | Unsupported |
| `-5` | I/O |
| `-6` | No slot |
| `-7` | Process failed |
| `-8` | Out of memory |

`Create()` returns `nullptr` on failure. `ProcessImage` may return `nullptr`.

```cpp
int ret = engine->SetSmoothing(0.5f);
if (ret != 0) {
    std::cerr << "SetSmoothing failed: " << ret << std::endl;
}
```

## Engine events

| Code | Meaning |
| --- | --- |
| `0` | License success |
| `1` | License failed |
| `100` | Init complete |
| `101` | Init failed |

```cpp
EngineCallbacks cbs;
cbs.on_engine_event = [](int code, const std::string& message) {
    if (code == 1 || code == 101) {
        std::cerr << "engine event " << code << ": " << message << std::endl;
    }
};
engine->SetCallbacks(cbs);
```

## Common failures

### 1. `Create` returns `nullptr`

- `resource_path` is not the **`resource.fbd` file**
- Invalid `license_token` or `app_id` + `app_key`
- Online auth cannot reach `/facebetter/v2/auth`
- `libfacebetter.so` version mismatch

```cpp
LogConfig log_cfg;
log_cfg.console_enabled = true;
log_cfg.level = LogLevel::Debug;
BeautyEffectEngine::SetLogConfig(log_cfg);

cfg.resource_path =
    (std::filesystem::current_path() / "resource" / "resource.fbd").string();
auto engine = BeautyEffectEngine::Create(cfg);
```

---

### 2. `libfacebetter.so` not found

```
error while loading shared libraries: libfacebetter.so: cannot open shared object file
```

```bash
LD_LIBRARY_PATH=/path/to/sdk/lib ./your_app
cp /path/to/sdk/lib/libfacebetter.so ./
echo "/path/to/sdk/lib" | sudo tee /etc/ld.so.conf.d/facebetter.conf
sudo ldconfig
```

You can also set `RPATH` at link time (`-Wl,-rpath,/path/to/sdk/lib`).

---

### 3. `ProcessImage` returns `nullptr`

```cpp
auto input = ImageFrame::CreateWithFile("input.jpg");
if (!input || !input->Data()) return;
input->type = FrameType::Image;
auto output = engine->ProcessImage(input);
if (!output || !output->Data()) {
    std::cerr << "ProcessImage failed." << std::endl;
}
```

---

### 4. Effects look unchanged

No `SetBeautyTypeEnabled` in 2.0. Set intensities `> 0`. Reshape / makeup need a face.

```cpp
engine->SetSmoothing(0.5f);
engine->SetReshape(Reshape::FaceThin, 0.3f);
input->type = FrameType::Video;
```

---

### 5. GLFW cannot open the display

```
GLFW: X11: Display variable not set
```

```bash
echo $DISPLAY
export DISPLAY=:0
export WAYLAND_DISPLAY=wayland-0
```

SSH needs X11 forwarding (`ssh -X`) or a local compositor.

---

### 6. OpenGL init fails

```bash
# Ubuntu / Debian
sudo apt install libgl1-mesa-dev libglu1-mesa-dev mesa-utils
glxinfo | grep "OpenGL version"
```

Need OpenGL 3.0+. Headless servers can use OSMesa (`libosmesa6-dev`) with `external_context` set for your offscreen context.
