Facebetter es un filtro de belleza en tiempo real para OBS Studio. Piel, forma, maquillaje, color, stickers, cuerpo y fondo se procesan en este ordenador. No cubre toda la ventana de OBS. Sigue a la fuente que selecciones.

## Antes de empezar

- macOS 13 o posterior. En un Mac Intel usa OBS para Intel; en Apple silicon, OBS para Apple silicon.
- OBS Studio 28 o posterior, 64 bits.

Descarga: [https://facebetter.net/es/obs](https://facebetter.net/es/obs). Otros sistemas: [Windows](/es/obs/install-windows), [Ubuntu](/es/obs/install-ubuntu).

## Instalar

Cierra OBS por completo antes de instalar, también el icono de la barra de menús. Si OBS está abierto durante la instalación, esa sesión no cargará el plugin nuevo.

Descarga el zip de macOS en la página de arriba y descomprímelo. Dentro están `Facebetter-OBS-*-macos-universal.pkg` y las guías cortas `README.zh.txt` y `README.en.txt`.

Haz doble clic en el pkg. En la introducción, pulsa Continuar. En el disco, Continuar otra vez. En Tipo de instalación, deja el valor por defecto y pulsa Instalar. No cambies la ubicación. El plugin se instala solo para el usuario actual de macOS.

macOS puede pedir la contraseña o Touch ID. Al terminar, el plugin está aquí:

```text
~/Library/Application Support/obs-studio/plugins/facebetter.plugin
```

Después, [inicia sesión y úsalo](/es/obs/login).
