Facebetter es un filtro de belleza en tiempo real para OBS Studio. Piel, forma, maquillaje, color, stickers, cuerpo y fondo se procesan en este ordenador. No cubre toda la ventana de OBS. Sigue a la fuente que selecciones.

## Antes de empezar

- Windows 10 o Windows 11, 64 bits.
- OBS Studio 28 o posterior, 64 bits.

Descarga: [https://facebetter.net/es/obs](https://facebetter.net/es/obs). Otros sistemas: [macOS](/es/obs/install), [Ubuntu](/es/obs/install-ubuntu).

## Instalar

Cierra OBS por completo antes de instalar, también el icono de la barra de menús. Si OBS está abierto durante la instalación, esa sesión no cargará el plugin nuevo.

Descarga el zip de Windows y descomprímelo. Haz doble clic en `Facebetter-OBS-*-windows-x64-setup.exe`, acepta el aviso de administrador y termina el asistente.

El instalador no está firmado. Si SmartScreen dice que Windows protegió tu PC, pulsa Más información y después Ejecutar de todos modos.

El plugin queda aquí:

```text
C:\ProgramData\obs-studio\plugins\obs-facebetter\
```

Después, [inicia sesión y úsalo](/es/obs/login).
