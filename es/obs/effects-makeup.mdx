Cada bloque tiene **Intensidad**. En 0 ese elemento está apagado. Si hay estilo y color, elige ambos y después sube la intensidad.

Restablecer en esta página devuelve estos controles a sus valores iniciales.
Cómo el panel sigue a la fuente seleccionada: [Ajustar efectos](/es/obs/effects).

## Labial

Colores: **Rosa**, **Rojo retro**, **Melocotón**, **Coral**, **Rosa suave**, **Naranja**, **Palo de rosa**, **Rojo ladrillo**, **Bayas**, **Nude**.

- **Intensidad** — 0 apaga este elemento.

## Rubor

- **Intensidad** — 0 apaga este elemento.
