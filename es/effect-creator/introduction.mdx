El plugin de Figma Facebetter Effect Creator es una herramienta pensada para crear stickers y efectos de maquillaje para el SDK de Facebetter. Su objetivo es simplificar el proceso de creación de stickers y maquillaje. Con este plugin puedes completar en Figma el diseño del sticker, la vinculación de landmarks faciales, la configuración de atributos y la exportación de la vista previa 3D.

## Inicio de sesión e idioma
Hay que iniciar sesión en el plugin antes de usarlo. Puedes entrar con una cuenta de Facebetter o correo, o con cuentas sociales como Google o GitHub.

1.  **Abrir el plugin**: ejecuta el plugin Facebetter Effect Creator en Figma.
2.  **Inicio de sesión**: admite Google, GitHub o correo.
3.  **Cambio de idioma**: haz clic en el icono del menú desplegable de la parte superior de la interfaz para cambiar entre **chino simplificado** e **inglés**.

## Instalar el plugin
Haz clic en este enlace: [Plugin](https://www.figma.com/community/plugin/1591037386605818409/facebetter-effect-creator), o busca «Facebetter Effect Creator» en Figma y pulsa **Open In** para abrirlo en un documento existente o en uno nuevo. Se recomienda un documento en blanco.
