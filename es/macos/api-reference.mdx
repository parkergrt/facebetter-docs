Esta página corresponde al SDK **2.0.0**. Significados de los estilos: [Enumeraciones de parámetros](/es/intro/makeup). Autenticación: [Autenticación y licencia](/es/intro/license).

iOS y macOS comparten esta API Objective-C. Solo macOS: `+[FBImageFrame createWithNSImage:]`. SO mínimo: **macOS 10.15**, arquitecturas **x86_64** y **arm64**. Usa AppKit (`NSImage`) para fotos fijas.

## Logging

### `FBLogLevel`

```objc
typedef NS_ENUM(NSInteger, FBLogLevel) {
  FBLogLevel_Trace = 0,
  FBLogLevel_Debug,
  FBLogLevel_Info,
  FBLogLevel_Warn,
  FBLogLevel_Error,
  FBLogLevel_Critical,
};
```

### `FBLogConfig`

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| `consoleEnabled` | `BOOL` | Salida a consola |
| `fileEnabled` | `BOOL` | Salida a archivo |
| `level` | `FBLogLevel` | Nivel mínimo |
| `fileName` | `NSString *` | Ruta de log (se usa cuando `fileEnabled` es `YES`) |

```objc
FB_OBJC_API @interface FBLogConfig : NSObject
@property(nonatomic, assign) BOOL consoleEnabled;
@property(nonatomic, assign) BOOL fileEnabled;
@property(nonatomic, assign) FBLogLevel level;
@property(nonatomic, copy, nullable) NSString *fileName;
- (instancetype)init;
@end
```

Llama a `+[FBBeautyEffectEngine setLogConfig:]` **antes** de `createEngineWithConfig:`. Devuelve `FBErrorCode` (`0` correcto, `-1` si `config` es nil).

## Configuración del motor

### `FBEngineConfig`

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| `appId` | `NSString *` | App ID de la Consola (autenticación en línea) |
| `appKey` | `NSString *` | App Key de la Consola (autenticación en línea) |
| `licenseToken` | `NSString *` | Cadena del token de licencia, JSON `{token}` o contenido nativo `.lic` |
| `externalContext` | `BOOL` | Predeterminado `NO`. `YES`: usa el contexto OpenGL del llamador |

**Prioridad de autenticación:** si `licenseToken` no está vacío, valida ese token en local y omite `/facebetter/v2/auth`. En caso contrario usa `appId` + `appKey` para autenticación en línea. Vincula el **Bundle ID** de la app en la Consola. Las herramientas de línea de comandos sin bundle deben vincular el nombre del proceso.

```objc
FB_OBJC_API @interface FBEngineConfig : NSObject
@property(nonatomic, copy) NSString *appId;
@property(nonatomic, copy) NSString *appKey;
@property(nonatomic, copy, nullable) NSString *licenseToken;
@property(nonatomic, assign) BOOL externalContext;
- (instancetype)init;
@end
```

### `FBFrameType`

Configúralo en `FBImageFrame.type` antes de `processImage:`. No es un argumento del método.

```objc
typedef NS_ENUM(NSInteger, FBFrameType) {
  FBFrameTypeImage = 0,  // stills / NSImage
  FBFrameTypeVideo = 1   // live / camera
};
```

### Fondo virtual y croma

| Método | Descripción |
| --- | --- |
| `setChromaKey:` | Máscara desde verde / azul / rojo. El relleno sigue siendo desenfoque o imagen. |
| `clearChromaKey` | Restaura la máscara de segmentación de retrato; **no** borra el relleno |
| `setChromaKeySimilarity:` | Ajuste de clave `[0, 1]` |
| `setChromaKeySmoothness:` | Suavizado de bordes `[0, 1]` |
| `setChromaKeyDesaturation:` | Supresión de derrame `[0, 1]` |
| `setVirtualBackgroundBlur:` | Relleno de desenfoque `[0, 1]`; `0` borra el fondo virtual |
| `setVirtualBackground:` | Ruta de archivo png/jpg (no debe estar vacía) |
| `setVirtualBackgroundWithData:` | `NSData` png/jpg codificado |
| `clearVirtualBackground` | Borra el desenfoque y el relleno de imagen |

### Filtros y stickers

No hay registro por ID. Ruta o bytes; los recursos GPU se crean en el siguiente `processImage:`.

| Método | Descripción |
| --- | --- |
| `setFilter:` | LUT desde ruta `.fbd` |
| `setFilterWithData:` | LUT desde bytes `.fbd` |
| `clearFilter` | Quita el LUT |
| `setFilterIntensity:` | `[0, 1]` |
| `setSticker:` | Ruta `.fbd` del sticker 2D |
| `setStickerWithData:` | Bytes del sticker |
| `addResourcePack:` | Ruta del paquete extra (`resource_3d.fbd` antes de `set3DSticker:`, o `resource_body.fbd` antes de `setBodyReshape:`) |
| `addResourcePackWithData:` | Bytes del paquete extra |
| `set3DSticker:` | Ruta `.fbd` del sticker 3D |
| `set3DStickerWithData:` | Bytes del sticker 3D |
| `clear3DSticker` | Quita el sticker 3D |
| `clearSticker` | Quita el sticker |

Ruta vacía / `NSData` nil o vacío → `FBErrorCode_InvalidArgument`.

### Procesar

```objc
- (FBImageFrame * _Nullable)processImage:(FBImageFrame *)imageFrame;
```

Lee `imageFrame.type`. El formato de salida coincide con el de entrada. Devuelve `nil` si falla.

## `FBImageFrame`

### Crear

| Método | Notas |
| --- | --- |
| `createWithData:width:height:format:` | Búfer en bruto + `FBImageFormat` |
| `createWithRGBA:width:height:stride:` | |
| `createWithBGRA:width:height:stride:` | Habitual para bitmaps de AppKit |
| `createWithRGB:width:height:stride:` | |
| `createWithBGR:width:height:stride:` | |
| `createWithI420:...` | Y / U / V planes |
| `createWithNV12:...` | Y + UV |
| `createWithNV21:...` | Y + VU |
| `createWithFile:` | Ruta png / jpg |
| `createWithTexture:width:height:stride:` | `GL_TEXTURE_2D` en el contexto actual |
| `createWithNSImage:` | **Solo macOS** |

### Operaciones

| Método | Descripción |
| --- | --- |
| `rotate:` | `FBImageRotation`; devuelve `FBErrorCode` |
| `mirror:` | `"horizontal"` / `"vertical"` / `"both"`; muta los píxeles |
| `setMirror:` | Marca para `processImage:`. `nil` / `@""` la borra |
| `convert:` | Devuelve un fotograma nuevo en el `FBImageFormat` de destino |
| `toFile:quality:` | quality `0`–`100` |
| `toFile:` | quality `90` |

Accesores: `width`, `height`, `stride`, `size`, `type`, `data`, `format`, `texture`. YUV: `dataY` / `dataU` / `dataV` / `dataUV` y los stride correspondientes.

```objc
typedef NS_ENUM(NSInteger, FBImageFormat) {
  FBImageFormatI420,
  FBImageFormatNV12,
  FBImageFormatNV21,
  FBImageFormatBGRA,
  FBImageFormatRGBA,
  FBImageFormatBGR,
  FBImageFormatRGB,
  FBImageFormatTexture,
};

typedef NS_ENUM(NSInteger, FBImageRotation) {
  FBImageRotation0,
  FBImageRotation90,
  FBImageRotation180,
  FBImageRotation270,
};
```

```objc
FBImageFrame *frame = [FBImageFrame createWithNSImage:image];
frame.type = FBFrameTypeImage;
FBImageFrame *out = [engine processImage:frame];
```
