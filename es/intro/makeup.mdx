<Note>
Esta página corresponde al SDK **2.0**. Los valores numéricos son idénticos en C++, Objective-C, Java, JavaScript y Dart.
</Note>

El maquillaje se controla con tres mandos:

1. **Intensidad** — `SetLipstick` / `SetBlush` / `SetContour` / `SetEyeShadow` / `SetEyeLiner` / `SetEyebrow` / `SetEyelash` / `SetPupil`, rango `[0.0, 1.0]`. `0` desactiva el efecto.
2. **Forma** — cambia la textura de máscara (`SetBlushStyle`, `SetContourStyle`, `SetEyeShadowStyle`, …).
3. **Color** — tiñe la forma actual (`SetLipstickColor`, `SetBlushColor`, `SetEyeShadowColor`, …). **Pupil** y **Contour** no se tiñen; al cambiarlos se sustituye la textura.

| C++ / JS | Java | Objective-C | Dart |
| --- | --- | --- | --- |
| `LipstickColor::Rouge` | `LipstickColor.ROUGE` | `FBLipstickColor_Rouge` | `FBLipstickColor.rouge` |

## Blanqueamiento (`WhiteningStyle`)

Se usa con `SetWhiteningStyle`. La intensidad sigue siendo `SetWhitening`. Predeterminado: `ColdWhite`.

| Valor | Nombre | Significado |
| --- | --- | --- |
| 0 | `ColdWhite` | Blanco frío |
| 1 | `PinkWhite` | Blanco rosado |
| 2 | `WarmWhite` | Blanco cálido |
| 3 | `Wheat` | Trigo |
| 4 | `Tan` | Bronceado |

## Suavizado (`SmoothingStyle`)

Se usa con `SetSmoothingStyle`. La intensidad sigue siendo `SetSmoothing`. Predeterminado: `Natural`.

| Valor | Nombre | Significado |
| --- | --- | --- |
| 0 | `Natural` | Conserva los poros |
| 1 | `Texture` | Más limpio, con textura |
| 2 | `Smooth` | Piel cremosa |

## Remodelado facial (`Reshape`)

Se usa con `SetReshape(param, intensity)`. El rango es **`[-1.0, 1.0]`**. `0` desactiva el efecto. Positivo y negativo son direcciones opuestas (por ejemplo FaceThin: adelgazar / mejillas más llenas).

| Valor | Nombre | Positivo / negativo |
| --- | --- | --- |
| 0 | `FaceThin` | Adelgazar el rostro / mejillas más llenas |
| 1 | `FaceVShape` | Forma en V / mandíbula más cuadrada |
| 2 | `FaceNarrow` | Rostro más estrecho / más ancho |
| 3 | `FaceShort` | Rostro más corto / más largo |
| 4 | `Cheekbone` | Adelgazar / ensanchar pómulos |
| 5 | `Jawbone` | Adelgazar / ensanchar mandíbula |
| 6 | `Chin` | Mentón más largo / más corto |
| 7 | `NoseSlim` | Nariz más estrecha / más ancha |
| 8 | `EyeSize` | Ojos más grandes / más pequeños |
| 9 | `EyeDistance` | Ojos más separados / más juntos |
| 10 | `FaceSmall` | Rostro más pequeño / más grande |
| 11 | `Forehead` | Frente más llena / más baja |
| 12 | `NoseLong` | Nariz más larga / más corta |
| 13 | `Philtrum` | Filtrum más corto / más largo |
| 14 | `MouthSize` | Boca más grande / más pequeña |
| 15 | `MouthPosition` | Boca más baja / más alta |
| 16 | `MouthSmile` | Sonrisa / comisuras hacia abajo |
| 17 | `LipThickness` | Labios más gruesos / más finos |
| 18 | `EyeRound` | Ojos más redondos / más estrechos |
| 19 | `EyePosition` | Ojos más bajos / más altos |
| 20 | `EyeAngle` | Esquina exterior hacia arriba / abajo |
| 21 | `EyeCornerOpen` | Abrir / cerrar esquinas de los ojos |
| 22 | `LowerEyelid` | Bajar / levantar el párpado |
| 23 | `BrowPosition` | Cejas más altas / más bajas |
| 24 | `BrowDistance` | Cejas más separadas / más juntas |
| 25 | `BrowThickness` | Cejas más gruesas / más finas |

Los nombres Java son `SNAKE_CASE` (`FACE_THIN`, `FACE_V_SHAPE`, …). Objective-C usa `FBReshape_FaceThin`. Dart usa `FBReshape.faceThin`.

## Labial (`LipstickColor`)

Una sola máscara de labios + tinte. Predeterminado: `Rouge`.

| Valor | Nombre | Significado |
| --- | --- | --- |
| 0 | `Rouge` | Rosa |
| 1 | `RetroRed` | Rojo retro |
| 2 | `Peach` | Melocotón |
| 3 | `CoralOrange` | Naranja coral |
| 4 | `GentlePink` | Rosa suave |
| 5 | `VitalityOrange` | Naranja vivo |

## Rubor

Forma con `BlushStyle` (cambia la textura). Color con `BlushColor` (tinte). Forma predeterminada `SunKissed`, color predeterminado `CoralPink`.

| Valor | `BlushStyle` | Significado |
| --- | --- | --- |
| 0 | `SunKissed` | A través de pómulos y nariz |
| 1 | `Igari` | Banda de rubor “borracho” en la nariz |
| 2 | `Soft` | Suave en ambas mejillas |
| 3 | `Apple` | Mejillas de manzana redondas |
| 4 | `Classic` | Dos puntos clásicos |
| 5 | `Doll` | Mejillas + punta de la nariz |
| 6 | `Rose` | Rosa en ambas mejillas |

| Valor | `BlushColor` | Significado |
| --- | --- | --- |
| 0 | `CoralPink` | Rosa coral |
| 1 | `DustyRose` | Rosa empolvado |
| 2 | `VividRed` | Rojo puro |
| 3 | `Berry` | Baya |
| 4 | `SunsetOrange` | Naranja atardecer |

## Contorno (`ContourStyle`)

Mapa Overlay en gris medio: más claro que 128 ilumina, más oscuro contornea. Cambia la textura, sin tinte. Predeterminado: `Natural`.

| Valor | Nombre | Significado |
| --- | --- | --- |
| 0 | `Natural` | Contorno ligero cotidiano |
| 1 | `Sculpt` | Esculpido más marcado |
| 2 | `Glow` | Prioriza el iluminado |
| 3 | `Slim` | Adelgaza pómulos |
| 4 | `Nose` | Define la nariz |
| 5 | `Glam` | Puntos de iluminado |
