Este sitio documenta el **SDK 2.x**. Última versión: **v2.1.0**.

## v2.1.0

2026-09-21

1. Remodelado corporal: cuerpo, cintura, piernas, hombros, brazos, piernas más largas, busto y más. Consulta [Enumeraciones de parámetros](./makeup)
2. Stickers 3D (gafas, sombreros y otros accesorios de malla)
3. Paquetes de recursos opcionales para remodelado corporal y stickers 3D. Consulta [Paquetes de recursos opcionales](./resource-packs)

## v2.0.1

2026-09-15

1. Procesamiento más rápido en Web y Android

## v2.0.0

2026-09-09

1. Nueva autenticación: nativo `licenseToken` o `appId` + `appKey`; Web solo `licenseToken` (desde tu servidor)
2. Belleza de piel: suavizado, blanqueado, nitidez, rubor, solo piel, más estilos
3. Remodelado facial (26 controles)
4. Maquillaje: intensidad, forma y color. Consulta [Enumeraciones de parámetros](./makeup)
5. Filtros LUT y stickers 2D (`.fbd`)
6. Fondo virtual: desenfoque, imagen, croma
7. SDK Flutter para Android e iOS
8. Estadísticas de proceso (`getStats()`)
