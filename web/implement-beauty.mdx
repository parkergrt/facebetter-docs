## Create the engine

`EngineConfig` on Web has **only** these fields. There is no `appId` / `appKey` on the config object.

| Field | Purpose |
| --- | --- |
| `licenseToken` | License token string, or `{token}` JSON. **Required.** Fetch it before `init()`. |

The SDK loads runtime files during `init()`. You do not host a site-root `resource.fbd` for the engine. Optional download progress: `init({ onProgress })`. The engine does not fetch tokens. Web does **not** support offline `.lic`.

```javascript
const licenseToken = await fetch('/api/facebetter/auth', { method: 'POST' }).then((r) => r.text());
const engine = new BeautyEffectEngine(new EngineConfig({ licenseToken }));

await engine.setLogConfig({
  consoleEnabled: true,
  fileEnabled: false,
  level: 2, // TRACE=0 … CRITICAL=5
});

await engine.init();
```

<Warning>
Call `setLogConfig` before `init()` if you want to see load / auth logs. File logging is not supported in the browser (`fileEnabled` is ignored).
</Warning>

```javascript
try {
  await engine.init();
} catch (error) {
  if (error instanceof FacebetterError) {
    console.error(error.code, error.message);
  }
  throw error;
}
```

## Skin beauty

Intensity range **`[0.0, 1.0]`**. `0` turns the effect off.

```javascript
engine.setSmoothing(0.8);
engine.setSmoothingStyle(SmoothingStyle.Natural);
engine.setWhitening(0.5);
engine.setWhiteningStyle(WhiteningStyle.ColdWhite);
engine.setSharpening(0.3);
engine.setRosiness(0.2);
engine.setBeautySkinOnly(true);
```

<Tip>
`setBeautySkinOnly(true)` limits smoothing / whitening / sharpening / rosiness to detected skin. Clothing and background stay unchanged.
</Tip>

Style enums: [Parameter enums](/intro/makeup).

## Face reshape

```javascript
engine.setReshape(Reshape.FaceThin, 0.3);
engine.setReshape(Reshape.EyeSize, 0.2);
```

Range is **`[-1.0, 1.0]`**. `0` is off. Positive and negative are opposite directions (for example `FaceThin`: slim / fuller cheeks). Full list: [Parameter enums](/intro/makeup).

## Filters and stickers

Pass a `.fbd` URL or in-memory `Uint8Array` directly to the setter.

```javascript
engine.setFilter('/assets/filters/portrait/natural/natural.fbd');
engine.setFilterIntensity(0.8);
engine.clearFilter();

engine.setSticker('/stickers/face/fox.fbd');
engine.clearSticker();
```

```javascript
const bytes = new Uint8Array(await (await fetch('/filters/chuxin.fbd')).arrayBuffer());
engine.setFilter(bytes);
```

## Virtual background and chroma key

```javascript
engine.setVirtualBackgroundBlur(0.6);          // [0, 1]; 0 clears blur
engine.setVirtualBackground('/background.jpg'); // path or Uint8Array (png/jpg)
engine.clearVirtualBackground();

engine.setChromaKey(ChromaKeyColor.Green);
engine.setChromaKeySimilarity(0.4);
engine.setChromaKeySmoothness(0.2);
engine.setChromaKeyDesaturation(0.3);
engine.clearChromaKey();
```

<Tip>
Chroma key only replaces the **mask**. Fill is still `setVirtualBackgroundBlur` or `setVirtualBackground`. Blur and image replacement are mutually exclusive.
</Tip>

## Callbacks

```javascript
engine.setCallbacks({
  onEngineEvent: (code, message) => {
    if (code === EngineEventCode.LicenseValidationSuccess) {
      console.log('license ok');
    } else if (code === EngineEventCode.LicenseValidationFailed) {
      console.error('license failed', message);
    } else if (code === EngineEventCode.InitializationComplete) {
      console.log('engine ready');
    } else if (code === EngineEventCode.InitializationFailed) {
      console.error('init failed', message);
    }
  },
  onFaceLandmarks: (faces) => {
    // faces[].rect, key_points, visibility, face_id, score, pitch, roll, yaw
  },
  maxFaces: 10,
});
```

| Code | Name |
| --- | --- |
| `0` | `EngineEventCode.LicenseValidationSuccess` |
| `1` | `EngineEventCode.LicenseValidationFailed` |
| `100` | `EngineEventCode.InitializationComplete` |
| `101` | `EngineEventCode.InitializationFailed` |

Omit `onFaceLandmarks` unless you need landmarks. Enabling it runs face detection every frame.

## Process frames

Prefer `processImage`. It returns `ImageData` synchronously.

```javascript
const canvas = document.querySelector('canvas');
const ctx = canvas.getContext('2d');
const video = document.querySelector('video');

function loop() {
  if (engine.initialized && video.readyState >= 2) {
    const result = engine.processImage(
      video,
      video.videoWidth,
      video.videoHeight,
      FrameType.Video,
      MirrorMode.Horizontal, // front camera
    );
    if (result) {
      if (canvas.width !== result.width) canvas.width = result.width;
      if (canvas.height !== result.height) canvas.height = result.height;
      ctx.putImageData(result, 0, 0);
    }
  }
  requestAnimationFrame(loop);
}
loop();
```

`input` may be `ImageData`, `HTMLImageElement`, `HTMLCanvasElement`, `HTMLVideoElement`, or `Uint8ClampedArray` (then `width` / `height` are required).

- `FrameType.Video` — live camera / streaming (temporal smoothing)
- `FrameType.Image` — still photos

`processTexture(textureHandle, width, height, stride, frameType, mirrorMode)` is for custom GPU texture input. **Mirror is not applied on this path.** Typical web apps should use `processImage`.
