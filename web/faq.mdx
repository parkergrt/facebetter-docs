## Integration

### Engine create / `init()` failed

- `EngineConfig` must set **one of** `licenseToken`, `authProxyUrl`, `fetchAuthResponse`. There are no `appId` / `appKey` fields on Web config.
- Production: your proxy must return the auth API body (`{success, token}` or error JSON). See [Auth & License](/intro/license).
- Confirm `/resource.fbd` (or your `resourcePath`) is served with HTTP 200.
- Confirm the page is HTTPS or localhost.
- Check `FacebetterError.code` ([Error handling](/web/error-handling)).

### How do I pass AppID / AppKey?

You don't — not on `EngineConfig`. Hold them on the server and use `authProxyUrl`, or issue a `licenseToken`. Localhost only: `createDirectAuthFetcher({ appId, appKey })`.

### Can I use an offline `.lic` in the browser?

No. Web must complete an online v2 path.

### How do I update the package?

```bash
npm install facebetter@2.0.0
```

## Effects

### Beauty looks weak or too strong

Intensities are `[0.0, 1.0]`. Reshape is `[-1.0, 1.0]` (`0` = off). Try `FrameType.Image` for stills. Style enums: [Parameter enums](/intro/makeup).

### Filter / sticker does nothing

Pass the `.fbd` **path or bytes** directly to `setFilter` / `setSticker`. Empty string throws — call `clearFilter()` / `clearSticker()`.

### Virtual background is blank

Call `setVirtualBackgroundBlur(level)` or `setVirtualBackground(path|Uint8Array)`, not a options object. `0` blur clears the effect. For green screen, `setChromaKey` only sets the mask; still set blur or an image.

### Output is black

Video may not have a frame yet (`videoWidth === 0`). Canvas context missing. Call `processImage` only after `engine.initialized`.

## Performance

### Preview is slow

Use `FrameType.Video`, cap capture resolution (for example 720p), avoid landmarks callbacks, and run the loop in `requestAnimationFrame`. Watch `engine.getStats().avgProcessTimeMs`.

### Memory grows in an SPA

Call `engine.destroy()` when leaving the page. Do not leak engines across route changes.

## Compatibility

Supported: Chrome 57+, Firefox 52+, Safari 11+, Edge 16+. On mobile, lower capture resolution and effect intensities.

## React example

```jsx
import { useEffect, useRef } from 'react';
import { BeautyEffectEngine, EngineConfig } from 'facebetter';

function BeautyPreview() {
  const engineRef = useRef(null);

  useEffect(() => {
    const engine = new BeautyEffectEngine(new EngineConfig({
      authProxyUrl: '/api/facebetter/auth',
    }));
    engineRef.current = engine;
    engine.init().catch(console.error);
    return () => {
      engine.destroy();
      engineRef.current = null;
    };
  }, []);

  return <canvas />;
}
```

Full sample: `demo/web/react` in the SDK repo.
