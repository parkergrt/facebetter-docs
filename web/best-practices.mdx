## Auth in production

Keep `app_id` / `app_key` on the server. Configure the engine with `authProxyUrl` (or a short-lived `licenseToken` from your backend).

```javascript
const engine = new BeautyEffectEngine(new EngineConfig({
  authProxyUrl: '/api/facebetter/auth',
}));
```

<Warning>
Never put `appKey` in a production frontend bundle. `createDirectAuthFetcher` is localhost-only.
</Warning>

Bind the exact production domain in the Dashboard. Web cannot use offline `.lic`.

## One engine per page

Create **one** `BeautyEffectEngine`, call `init()` once, reuse it for the session. Do not construct a new engine every frame.

```javascript
useEffect(() => {
  let engine;
  (async () => {
    engine = new BeautyEffectEngine(new EngineConfig({ authProxyUrl: '/api/facebetter/auth' }));
    await engine.init();
    engineRef.current = engine;
  })();
  return () => {
    engineRef.current?.destroy();
    engineRef.current = null;
  };
}, []);
```

## Frame loop

- Drive video with `requestAnimationFrame`, not an unbounded `while`.
- Use `FrameType.Video` for camera; `FrameType.Image` for stills.
- Match canvas size to the processed `ImageData` to avoid extra scaling.
- Skip frames until `video.readyState >= 2` and `videoWidth > 0`.
- Prefer `processImage` for camera and canvas. `processTexture` does not apply mirror.

```javascript
const result = engine.processImage(
  video,
  video.videoWidth,
  video.videoHeight,
  FrameType.Video,
  MirrorMode.Horizontal,
);
ctx.putImageData(result, 0, 0);
```

## Parameters

Start low in real-time preview (`smoothing` ~ `0.2`–`0.5`). Reshape is `[-1, 1]`; small values look more natural on camera.

Do not register `onFaceLandmarks` unless the UI needs them — it forces per-frame detection.

`setBeautySkinOnly(true)` avoids smearing backgrounds when smoothing is high.

## Resources

- Put `resource.fbd` at `/resource.fbd` (or the `resourcePath` you configured).
- Host filter / sticker `.fbd` and background jpg/png as static files; pass the URL into `setFilter` / `setSticker` / `setVirtualBackground`.
- Switch filter / sticker on user input, not every frame.

## Memory

- Call `destroy()` on unmount / `beforeunload`.
- Reuse the display canvas; do not allocate a new canvas per frame.

## HTTPS and CORS

Camera access needs HTTPS or localhost. If `resource.fbd` is on another origin, send CORS headers.
