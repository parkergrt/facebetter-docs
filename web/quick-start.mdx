## Requirements

- **Browser**: Chrome 57+, Firefox 52+, Safari 11+, Edge 16+
- **Language**: JavaScript (ES6+) or TypeScript
- **Context**: HTTPS or `localhost` (required for camera)

## Install SDK

```bash
npm install facebetter
```

```javascript
import {
  BeautyEffectEngine,
  EngineConfig,
  FrameType,
  MirrorMode,
  Reshape,
  createDirectAuthFetcher,
} from 'facebetter';
```

## Get the example

Clone the [GitHub repository](https://github.com/pixpark/facebetter-sdk) and open `demo/web/react`:

```bash
git clone https://github.com/pixpark/facebetter-sdk.git
cd demo/web/react
```

The demo is a Vite + React app. It depends on the in-repo SDK via `file:` during development.

## Bind domain and get credentials

1. In the Dashboard, bind your Web **domain** (for example `example.com`). See [Subscribe](/intro/enable-service).
2. Copy `appId` / `appKey` from the Dashboard. **Do not put them on `EngineConfig`.** On Web they belong on your **server**, or only inside `createDirectAuthFetcher` for local debug.

Web has **no** offline `.lic`. Details: [License & Auth](/intro/license).

## Configure the demo

Open `src/views/BeautyPreview.jsx`. The sample uses direct auth for local debug:

```javascript
const config = new EngineConfig({
  fetchAuthResponse: createDirectAuthFetcher({
    appId: 'your-app-id',
    appKey: 'your-app-key',
  }),
});

const engine = new BeautyEffectEngine(config);
await engine.init();
```

<Warning>
`createDirectAuthFetcher` puts `appKey` in the browser bundle. Use it only on localhost. Production must use `authProxyUrl` or a server-issued `licenseToken`.
</Warning>

Serve `resource.fbd` at `/resource.fbd` (the default `resourcePath`). Copy the packed bundle into `public/` so Vite can serve it.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Verify

1. Open DevTools (F12) and watch the console.
2. Allow camera if prompted.
3. Drag beauty sliders — you should see skin smoothing / reshape on the preview.

## Minimal production init

```javascript
import { BeautyEffectEngine, EngineConfig } from 'facebetter';

const engine = new BeautyEffectEngine(new EngineConfig({
  authProxyUrl: '/api/facebetter/auth',
}));
await engine.init();
```

Your proxy holds `app_id` / `app_key` and forwards the SDK auth request. Example server code is on [License & Auth](/intro/license).
