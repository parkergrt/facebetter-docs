## Requirements

- **Browser**: Chrome 57+, Firefox 52+, Safari 11+, Edge 16+
- **Language**: JavaScript (ES6+) or TypeScript
- **Context**: HTTPS or `localhost` (required for camera)

## Install SDK

```bash
npm install facebetter
```

```javascript
import {
  BeautyEffectEngine,
  EngineConfig,
  FrameType,
  MirrorMode,
  Reshape,
  fetchLicenseToken,
} from 'facebetter';
```

## Get the example

Clone the [GitHub repository](https://github.com/pixpark/facebetter-sdk) and open `demo/web/react`:

```bash
git clone https://github.com/pixpark/facebetter-sdk.git
cd demo/web/react
```

The demo is a Vite + React app. It depends on the in-repo SDK via `file:` during development.

## Bind domain and get credentials

1. In the Dashboard, bind your Web **domain** (for example `example.com`). See [Subscription](/intro/enable-service).
2. Copy `appId` / `appKey` from the Dashboard. **Do not put them on `EngineConfig`.** On Web they belong on your **server**. Local debug only: `fetchLicenseToken({ appId, appKey })`.

Web has **no** offline `.lic`. Details: [Auth & License](/intro/license).

## Configure the demo

Open `src/useStudioEngine.js`. The sample fetches a token from `/api/fb-auth` (Vite proxy holds `app_id` / `app_key`), then passes `licenseToken`:

```javascript
const licenseToken = await fetch('/api/fb-auth', { method: 'POST' }).then((r) => r.text());
const engine = new BeautyEffectEngine(new EngineConfig({ licenseToken }));
await engine.init();
```

Local debug without a proxy:

```javascript
const engine = new BeautyEffectEngine(new EngineConfig({
  licenseToken: await fetchLicenseToken({
    appId: 'your-app-id',
    appKey: 'your-app-key',
  }),
}));
await engine.init();
```

<Warning>
`fetchLicenseToken` puts `appKey` in the browser bundle. Use it only on localhost. Production must fetch the token from **your** server and pass `licenseToken`.
</Warning>

Serve `resource.fbd` at `/resource.fbd` (the default `resourcePath`). Copy the packed bundle into `public/` so Vite can serve it.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Verify

1. Open DevTools (F12) and watch the console.
2. Allow camera if prompted.
3. Drag beauty sliders — you should see skin smoothing / reshape on the preview.

## Minimal production init

```javascript
import { BeautyEffectEngine, EngineConfig } from 'facebetter';

const licenseToken = await fetch('/api/facebetter/auth', { method: 'POST' }).then((r) => r.text());
const engine = new BeautyEffectEngine(new EngineConfig({ licenseToken }));
await engine.init();
```

Your server holds `app_id` / `app_key` and returns a token. Example server code is on [Auth & License](/intro/license).
