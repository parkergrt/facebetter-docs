<Note>
SDK **2.0.0**. Auth failures: [License & Auth](/intro/license).
</Note>

Failed calls throw `FacebetterError`. Numeric `code` values are listed below. Some load / auth failures use a **string** `code` instead.

```javascript
import { BeautyEffectEngine, EngineConfig, FacebetterError } from 'facebetter';

try {
  const engine = new BeautyEffectEngine(new EngineConfig({
    authProxyUrl: '/api/facebetter/auth',
  }));
  await engine.init();
  engine.setSmoothing(0.5);
} catch (error) {
  if (error instanceof FacebetterError) {
    console.error(error.code, error.message);
  } else {
    console.error(error);
  }
}
```

## Numeric codes

| Code | Meaning |
| --- | --- |
| `0` | Success (`checkResult` does not throw) |
| `-1` | Invalid argument (null, empty path, out-of-range intensity, …) |
| `-2` | Engine not initialized or already destroyed |
| `-3` | License invalid |
| `-4` | Unsupported platform / format |
| `-5` | I/O (resource / filter / sticker / background file) |
| `-6` | Slot pool full (back-pressure; drop the frame) |
| `-7` | Processing failed |
| `-8` | Out of memory |

## JavaScript-layer codes (string)

These are thrown during `init()` / load / auth:

| `error.code` | When |
| --- | --- |
| `'TIMEOUT'` | `init()` timed out |
| `'NETWORK_ERROR'` | Fetch / network failure |
| `'WASM_LOAD_ERROR'` | SDK failed to load (network, CDN, or ad blocker) |
| `'LICENSE_ERROR'` | Missing auth config, or `fetchAuthResponse` / proxy rejected |
| `'ENGINE_CREATE_FAILED'` | Engine failed to create |
| `'UNKNOWN_ERROR'` | Unclassified JS exception wrapped as `FacebetterError` |

```javascript
try {
  await engine.init({ timeout: 30000 });
} catch (error) {
  if (!(error instanceof FacebetterError)) throw error;
  if (error.code === 'LICENSE_ERROR' || error.code === -3) {
    // proxy down, domain not bound, or token expired — see /intro/license
  } else if (error.code === 'WASM_LOAD_ERROR' || error.code === 'TIMEOUT') {
    // network, CDN, or ad blocker
  }
}
```

## Init checklist

1. Config is valid: at least one of `licenseToken`, `authProxyUrl`, `fetchAuthResponse`.
2. `resource.fbd` is reachable at `resourcePath` (default `/resource.fbd`).
3. Page is a [secure context](https://developer.mozilla.org/en-US/docs/Web/Security/Secure_Contexts).
4. Dashboard domain matches the page origin (production).
5. Production does **not** embed `appKey` in frontend JS.

## Parameter and process errors

Beauty intensities must be `[0.0, 1.0]`. Reshape must be `[-1.0, 1.0]`. Out of range throws `FacebetterError` before the native call.

`processImage` throws if the engine is not initialized, buffers cannot be allocated, or the native process returns a non-zero status. Validate video `readyState` and non-zero `videoWidth` / `videoHeight` before calling.

Empty filter / sticker / background **paths** are rejected; use `clearFilter()`, `clearSticker()`, or `clearVirtualBackground()`.

## Engine events vs exceptions

Auth / init can also arrive on `onEngineEvent` (`EngineEventCode` `0` / `1` / `100` / `101`) after `init()` has already resolved. Listen for `LicenseValidationFailed` and `InitializationFailed` even if `init()` did not throw.
