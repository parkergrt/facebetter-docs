패널 오른쪽 위 계정 버튼을 엽니다. 로그인 전에는 **로그인**이고, 로그인 후에는 이메일의 이름이 보입니다. 메뉴에서 **환경설정**을 고릅니다.

같은 메뉴에 **Pro 업그레이드**(구독 후에는 **멤버십**), **구독 상태 새로고침**, **로그인** 또는 **로그아웃**도 있습니다. 로그인은 [로그인하고 사용](/ko/obs/login)을 봅니다.

## 일반 및 시작

- **OBS 시작 시 패널 열기** — 기본값은 켜짐입니다. 끄면 OBS를 열 때 Facebetter 패널이 자동으로 열리지 않습니다. 필요할 때는 **도구 → Facebetter**에서 엽니다.
- **소스 조절 시 필터 추가** — 기본값은 켜짐입니다. 영상이 있는 소스를 하나 고르고 슬라이더를 움직이면 그 소스에 **Facebetter Beauty**가 붙습니다. 직접 넣을 때는 끄고, 소스를 오른쪽 클릭해 필터를 연 다음 + 에서 **Facebetter Beauty**를 고릅니다.

## 로그 및 진단

**디버그 로그 기록**은 기본으로 꺼져 있습니다. 켜면 Facebetter가 더 자세한 기록을 `facebetter-obs.log`에 씁니다. OBS 자체 로그는 항상 있으며, `[Facebetter]`로 시작하는 줄이 있습니다.

문제가 생기면 다음 순서로 두 로그를 모두 보냅니다.

1. **디버그 로그 기록**을 켭니다.
2. 문제가 난 조작을 다시 합니다. 켜기 전의 조작은 이 파일에 남지 않습니다.
3. 그 줄 옆의 폴더 버튼을 누릅니다. 풍선 도움말은 **로그 폴더 열기**입니다. 안의 `facebetter-obs.log`를 보냅니다. 파일이 아직 없으면 조작을 한 번 더 한 뒤에 보냅니다.
4. OBS 로그도 가져옵니다. **도움말 → 로그 파일**에서 현재 로그를 보거나 업로드합니다. 아래 폴더에서 수정 시각이 가장 최근인 파일을 골라도 됩니다.

폴더 버튼을 찾지 못할 때의 위치입니다.

### macOS

```text
~/Library/Application Support/obs-studio/plugin_config/facebetter/facebetter-obs.log
```

OBS 로그 폴더:

```text
~/Library/Application Support/obs-studio/logs/
```

### Windows

```text
%APPDATA%\obs-studio\plugin_config\obs-facebetter\facebetter-obs.log
```

현재 사용자 폴더입니다. 플러그인을 설치한 `C:\ProgramData\...`가 아닙니다. OBS 로그 폴더:

```text
%APPDATA%\obs-studio\logs\
```

### Ubuntu

```text
~/.config/obs-studio/plugin_config/obs-facebetter/facebetter-obs.log
```

OBS 로그 폴더:

```text
~/.config/obs-studio/logs/
```

확인이 끝나면 **디버그 로그 기록**은 다시 끕니다.

## 정보 및 업데이트

여기에 현재 버전이 표시됩니다. 예: `v1.3.0`.

- **확인** — 새 버전이 있는지 봅니다. 최신이면 **최신 안정 버전입니다**. 업데이트가 있으면 **새 버전이 있습니다**가 되고, 버튼은 **다운로드**로 바뀝니다. 다운로드 페이지가 열립니다. OBS를 종료하고 새 버전을 설치한 뒤 다시 엽니다. 실패하면 **확인에 실패했습니다. 다시 시도하세요**.
- **서비스 약관**과 **개인정보 처리방침**은 브라우저에서 열립니다.
