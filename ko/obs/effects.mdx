필터를 소스에 추가한 뒤 오른쪽 패널에서 조절합니다. 슬라이더에 따라 OBS 미리보기가 바뀝니다. 방송과 녹화로 나가는 것은 처리된 화면입니다. 아직 필터를 추가하지 않았다면 먼저 [로그인하고 필터 추가](/ko/obs/login) 를 보세요.

  <img src="/images/obs/panel.png" alt="Facebetter 패널에서 피부 조절" />
</Frame>

패널 맨 위는 왼쪽부터 다음과 같습니다.

- **스위치**: 켜짐과 꺼짐을 비교합니다. 꺼지면 원본 미리보기입니다. 방송 전에 다시 켭니다.
- **소스 메뉴**: 필터가 이미 있는 소스 하나, 또는 **All sources(모든 소스)**. 모든 소스를 고르면 변경이 모든 Facebetter 필터에 기록됩니다.
- **초기화**: 현재 페이지를 기본값으로 되돌립니다.
- **톱니바퀴**: 설정입니다. OBS 를 시작할 때 패널을 열지 고를 수 있고, 계정과 구독도 여기 있습니다.

그 아래 일곱 페이지가 있습니다.

| 페이지 | 하는 일 |
| --- | --- |
| Skin 피부 | 매끈, 미백, 혈색, 선명도. **Skin only(피부만)** 를 켜면 피부만 처리되어 옷, 배경, 손에 든 상품은 같이 하얘지지 않습니다. 매끈 스타일은 Texture(결 유지), Natural(자연), Smooth(매끄러움)입니다. 미백 톤은 Cool, Pink, Warm, Wheat, Tan 다섯 가지입니다. |
| Shape 윤곽 | 얼굴, 이마와 눈썹, 눈, 코, 입. 각 항목은 양쪽으로 조절됩니다. 0 은 그대로입니다. |
| Makeup 화장 | 립, 블러셔, 윤곽, 아이섀도, 아이라인, 눈썹, 속눈썹, 렌즈. 스타일, 색, 강도는 따로입니다. |
| Filter 필터 | 필름 색 보정입니다. LUT 를 고른 뒤 강도를 조절합니다. None 은 색 보정을 끕니다. |
| Sticker 스티커 | 2D 얼굴 추적, 2D 화면 스티커, 3D 스티커. None 이면 제거됩니다. |
| Body 바디 | 몸, 허리, 다리, 어깨, 팔을 날씬하게 하고, 다리를 길게 하며, 가슴을 조절합니다. 반신 또는 전신 화면에 맞습니다. |
| BG 배경 | 원래 배경을 유지하거나, 흐리게 하거나, 프리셋으로 바꿉니다. 배경 제거는 인물 분리, 또는 그린, 블루, 레드 스크린입니다. |

패널 언어는 OBS 를 따릅니다. 간체 중국어, 번체 중국어, 영어, 일본어, 한국어, 포르투갈어, 스페인어, 독일에는 각자 화면이 있습니다. 그 외 OBS 언어는 영어로 표시됩니다.

## 워터마크 제거

무료 플랜에는 위의 모든 효과가 포함되고 출력에 워터마크가 들어갑니다. 프로는 워터마크가 없고 기기 2대에서 사용할 수 있습니다.

- 월: $8.99
- 연: $69

패널 위의 워터마크 제거를 누르거나, 톱니바퀴 → 계정에서 구독합니다. 안내를 닫아도 OBS 를 종료할 때까지만 숨겨집니다. 구독과 기기 관리는 [facebetter.net/ko/dashboard/obs](https://facebetter.net/ko/dashboard/obs) 입니다.
