Facebetter는 OBS Studio용 실시간 뷰티 필터입니다. 피부, 윤곽, 화장, 컬러, 스티커, 바디, 배경은 모두 이 컴퓨터에서 처리됩니다. OBS 전체에 깔리지 않고, 선택한 소스만 따라갑니다.

## 시작하기 전에

- Ubuntu 22.04 이상, x86_64.
- OBS Studio 28 이상, 64비트.
- 이 Ubuntu 빌드는 베타입니다.

다운로드: [https://facebetter.net/ko/obs](https://facebetter.net/ko/obs). 다른 시스템: [macOS](/ko/obs/install), [Windows](/ko/obs/install-windows).

## 설치

설치 전에 OBS를 완전히 종료하세요. 메뉴 막대 아이콘도 종료합니다. OBS가 켜진 채 설치하면 그 실행에서는 새 플러그인을 불러오지 않습니다.

Ubuntu tar.gz를 풀고 설치 스크립트를 실행합니다:

```bash
tar -xzf facebetter-obs-*-linux-x64.tar.gz
cd Facebetter-OBS-*-linux-x64
./install.sh
```

현재 사용자에게 설치됩니다:

```text
~/.config/obs-studio/plugins/obs-facebetter/
```

Flatpak OBS는 정식 지원 대상이 아닙니다. 그래도 시험하려면:

```bash
./install.sh --flatpak
```

플러그인이 `~/.var/app/com.obsproject.Studio/config/obs-studio/plugins/`로 복사됩니다. 그 Flatpak에 들어 있는 OBS 런타임이 필요합니다.

그다음 [로그인하고 사용](/ko/obs/login)을 보세요.
