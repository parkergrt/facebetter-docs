## 패널과 필터 목록에 Facebetter 가 없음

OBS 를 완전히 종료한 뒤 다시 엽니다. 그다음 플러그인이 여기 있는지 확인합니다.

```text
~/Library/Application Support/obs-studio/plugins/facebetter.plugin
```

Intel Mac 은 Intel 용 OBS, Apple 실리콘은 Apple 실리콘용 OBS 가 필요합니다. 짝이 맞지 않으면 OBS 는 플러그인을 읽지 않습니다. 절차는 [macOS 설치](/ko/obs/install) 입니다.

## 플러그인이 손상되었다고 함

터미널을 열고 다음 줄을 붙여 넣은 뒤 Return 을 누르고 OBS 를 다시 엽니다.

```bash
xattr -dr com.apple.quarantine ~/Library/Application\ Support/obs-studio/plugins/facebetter.plugin
```

## 슬라이더가 회색이라 움직이지 않음

소스에 필터가 아직 없습니다. 패널에는 조절하려면 필터를 추가하라고 나옵니다. 소스를 우클릭 → 필터 → + → Facebetter 뷰티. 페이지 제목은 눌러 내용을 볼 수 있습니다. 슬라이더는 필터를 추가한 뒤에 움직입니다. 절차는 [로그인하고 필터 추가](/ko/obs/login) 입니다.

## 필터를 추가했는데 미리보기가 바뀌지 않음

패널 위 스위치가 켜져 있는지, 소스 메뉴가 지금 보는 소스인지 확인합니다. 슬라이더가 모두 0 이면 화면은 원본과 같아 보입니다. 바디는 사람이 화면에서 비교적 크게 보여야 합니다. 얼굴만 나오면 변화가 거의 보이지 않습니다. 각 페이지의 내용은 [효과 조절](/ko/obs/effects) 입니다.
