Facebetter는 OBS Studio용 실시간 뷰티 필터입니다. 피부, 얼굴형, 메이크업, 컬러 필터, 스티커, 바디, 배경은 이 컴퓨터에서 처리됩니다.

OBS 전체에 자동으로 적용되지 않습니다. 처리할 소스에 **Facebetter 뷰티**를 추가해야 오른쪽 패널의 슬라이더를 쓸 수 있습니다. 카메라, 이미지, 비디오 모두 됩니다. Mac 절차는 [macOS 설치](/ko/obs/install) 입니다. 설치 뒤 로그인과 조절은 두 시스템에서 같습니다. [로그인하고 필터 추가](/ko/obs/login) 를 보세요.

시작하기 전에:

- Windows 10 또는 Windows 11, 64비트.
- OBS Studio 30 이상, 64비트.

다운로드: [facebetter.net/ko/obs](https://facebetter.net/ko/obs)

## OBS 종료 후 설치

먼저 OBS를 완전히 종료하세요. 설치 중 OBS가 열려 있으면 그 세션은 플러그인을 불러오지 않습니다.

Windows zip을 받아 압축을 풉니다. `Facebetter-OBS-*-windows-x64-setup.exe`를 더블클릭하고, 관리자 권한을 허용한 뒤 안내에 따라 설치합니다.

설치 프로그램은 서명되어 있지 않습니다. SmartScreen이 PC를 보호했다고 나오면 추가 정보 → 그래도 실행을 누르세요.

설치 위치:

```text
C:\ProgramData\obs-studio\plugins\obs-facebetter\
```

OBS를 연 뒤 [로그인하고 필터 추가](/ko/obs/login)로 이어가세요.
