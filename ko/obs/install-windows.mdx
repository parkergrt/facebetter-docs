Facebetter는 OBS Studio용 실시간 뷰티 필터입니다. 피부, 윤곽, 화장, 컬러, 스티커, 바디, 배경은 모두 이 컴퓨터에서 처리됩니다. OBS 전체에 깔리지 않고, 선택한 소스만 따라갑니다.

## 시작하기 전에

- Windows 10 또는 Windows 11, 64비트.
- OBS Studio 28 이상, 64비트.

다운로드: [https://facebetter.net/ko/obs](https://facebetter.net/ko/obs). 다른 시스템: [macOS](/ko/obs/install), [Ubuntu](/ko/obs/install-ubuntu).

## 설치

설치 전에 OBS를 완전히 종료하세요. 메뉴 막대 아이콘도 종료합니다. OBS가 켜진 채 설치하면 그 실행에서는 새 플러그인을 불러오지 않습니다.

Windows zip의 압축을 풀고 `Facebetter-OBS-*-windows-x64-setup.exe`를 더블 클릭합니다. 관리자 확인을 허용하고 마법사를 마칩니다.

설치 프로그램은 서명되어 있지 않습니다. SmartScreen이 PC를 보호했다는 창을 띄우면 추가 정보를 누른 뒤 실행을 누릅니다.

설치 위치:

```text
C:\ProgramData\obs-studio\plugins\obs-facebetter\
```

그다음 [로그인하고 사용](/ko/obs/login)을 보세요.
