<Note>
이 페이지는 SDK **2.0**에 해당합니다. 숫자 값은 C++, Objective-C, Java, JavaScript, Dart에서 동일합니다.
</Note>

메이크업은 세 가지 조절입니다.

1. **강도** — `SetLipstick` / `SetBlush` / `SetContour` / `SetEyeShadow` / `SetEyeLiner` / `SetEyebrow` / `SetEyelash` / `SetPupil`, 범위 `[0.0, 1.0]`. `0`이면 효과가 꺼집니다.
2. **형태** — 마스크 텍스처를 바꿉니다(`SetBlushStyle`, `SetContourStyle`, `SetEyeShadowStyle`, …).
3. **색상** — 현재 형태에 틴트를 적용합니다(`SetLipstickColor`, `SetBlushColor`, `SetEyeShadowColor`, …). **Pupil**과 **Contour**는 틴트하지 않으며, 항목을 바꾸면 텍스처가 교체됩니다.

| C++ / JS | Java | Objective-C | Dart |
| --- | --- | --- | --- |
| `LipstickColor::Rouge` | `LipstickColor.ROUGE` | `FBLipstickColor_Rouge` | `FBLipstickColor.rouge` |

## 미백 (`WhiteningStyle`)

`SetWhiteningStyle`과 함께 사용합니다. 강도는 계속 `SetWhitening`입니다. 기본값: `ColdWhite`.

| 값 | 이름 | 의미 |
| --- | --- | --- |
| 0 | `ColdWhite` | 쿨 화이트 |
| 1 | `PinkWhite` | 핑크 화이트 |
| 2 | `WarmWhite` | 웜 화이트 |
| 3 | `Wheat` | 밀색 |
| 4 | `Tan` | 탠 |

## 스무딩 (`SmoothingStyle`)

`SetSmoothingStyle`과 함께 사용합니다. 강도는 계속 `SetSmoothing`입니다. 기본값: `Natural`.

| 값 | 이름 | 의미 |
| --- | --- | --- |
| 0 | `Natural` | 모공 유지 |
| 1 | `Texture` | 더 깨끗하면서 질감 유지 |
| 2 | `Smooth` | 크림 피부 |

## 페이스 리셰이프 (`Reshape`)

`SetReshape(param, intensity)`와 함께 사용합니다. 범위는 **`[-1.0, 1.0]`**입니다. `0`은 꺼짐입니다. 양수와 음수는 반대 방향입니다(예: FaceThin: 슬림 / 볼 볼륨).

| 값 | 이름 | 양수 / 음수 |
| --- | --- | --- |
| 0 | `FaceThin` | 슬림 얼굴 / 볼 볼륨 |
| 1 | `FaceVShape` | V라인 / 각진 턱 |
| 2 | `FaceNarrow` | 좁은 얼굴 / 넓은 얼굴 |
| 3 | `FaceShort` | 짧은 얼굴 / 긴 얼굴 |
| 4 | `Cheekbone` | 광대 슬림 / 광대 확장 |
| 5 | `Jawbone` | 턱선 슬림 / 턱선 확장 |
| 6 | `Chin` | 턱 길게 / 턱 짧게 |
| 7 | `NoseSlim` | 코 슬림 / 코 넓게 |
| 8 | `EyeSize` | 눈 크게 / 눈 작게 |
| 9 | `EyeDistance` | 눈 간격 넓게 / 좁게 |
| 10 | `FaceSmall` | 작은 얼굴 / 큰 얼굴 |
| 11 | `Forehead` | 이마 볼륨 / 이마 낮게 |
| 12 | `NoseLong` | 코 길게 / 코 짧게 |
| 13 | `Philtrum` | 인중 짧게 / 인중 길게 |
| 14 | `MouthSize` | 입 크게 / 입 작게 |
| 15 | `MouthPosition` | 입 아래로 / 입 위로 |
| 16 | `MouthSmile` | 미소 / 입꼬리 내림 |
| 17 | `LipThickness` | 입술 두껍게 / 얇게 |
| 18 | `EyeRound` | 둥근 눈 / 가늘고 긴 눈 |
| 19 | `EyePosition` | 눈 아래로 / 눈 위로 |
| 20 | `EyeAngle` | 눈꼬리 올림 / 내림 |
| 21 | `EyeCornerOpen` | 눈꼬리 열기 / 닫기 |
| 22 | `LowerEyelid` | 애교살 / 눈꺼풀 리프트 |
| 23 | `BrowPosition` | 눈썹 위로 / 아래로 |
| 24 | `BrowDistance` | 눈썹 간격 넓게 / 좁게 |
| 25 | `BrowThickness` | 눈썹 두껍게 / 얇게 |

Java 이름은 `SNAKE_CASE`입니다(`FACE_THIN`, `FACE_V_SHAPE`, …). Objective-C는 `FBReshape_FaceThin`입니다. Dart는 `FBReshape.faceThin`입니다.

## 컨투어 (`ContourStyle`)

중간 회색 Overlay 맵입니다. 128보다 밝으면 하이라이트, 어두우면 음영입니다. 텍스처를 바꾸며 틴트는 없습니다. 기본값: `Natural`.

| 값 | 이름 | 의미 |
| --- | --- | --- |
| 0 | `Natural` | 일상 라이트 컨투어 |
| 1 | `Sculpt` | 더 강한 스컬프팅 |
| 2 | `Glow` | 하이라이트 중심 |
| 3 | `Slim` | 광대 슬림 |
| 4 | `Nose` | 코 입체감 |
| 5 | `Glam` | 하이라이트 포인트 |
