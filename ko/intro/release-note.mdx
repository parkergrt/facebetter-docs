이 사이트는 **SDK 2.0**을 문서화합니다.

## v2.0.0

2026-09-09

1. **인증**: 네이티브는 `licenseToken` 또는 `appId` + `appKey`를 사용합니다. Web은 `licenseToken`만 사용합니다. 토큰은 서버에서 받고, 브라우저 JS에 `appKey`를 넣지 마세요
2. **뷰티**: `setSmoothing`, `setWhitening`, `setSharpening`, `setRosiness`, `setBeautySkinOnly`와 스타일 프리셋
3. **리셰이프**: 26개 파라미터(`FaceThin` … `BrowThickness`), 강도 `[-1.0, 1.0]`
4. **메이크업**: 강도 + Style(형태) + Color(틴트). [파라미터 열거형](./makeup)을 참고하세요
5. **필터 / 스티커**: `setFilter` / `setSticker`에 `.fbd` 경로 또는 바이트; `clearFilter` / `clearSticker`
6. **가상 배경**: 블러, 이미지 교체, 크로마키
7. **통계**: `getStats()` — FPS, 평균 처리 시간, 세션 길이
8. **프레임 유형**: `FrameType.Image` / `FrameType.Video`
9. **오류 코드**: `0` 성공, `-1` 잘못된 인자, `-2` 미초기화, `-3` 라이선스, `-4` 미지원, `-5` IO, `-6` 슬롯 없음, `-7` 처리, `-8` 메모리 부족
10. **Flutter**: `FBEngine.create(FBEngineConfig)`. 실시간 영상은 네이티브 `FacebetterPlugin.processTexture`로 처리합니다

**이벤트** (`onEngineEvent` / Flutter `events`): `0` 라이선스 성공, `1` 라이선스 실패, `100` 초기화 완료, `101` 초기화 실패.
