## 가입 / 로그인

[Facebetter 웹사이트](https://facebetter.net/ko)를 연 뒤 [로그인](https://facebetter.net/ko/sign-in) 또는 [계정 만들기](https://facebetter.net/ko/sign-up)를 진행하세요. 이메일/비밀번호와 소셜 로그인(Google, GitHub)을 지원합니다.

로그인하면 [콘솔](https://facebetter.net/ko/dashboard)로 이동합니다. 프로젝트를 만들면 프로젝트마다 요금제, 자격 증명, 플랫폼 바인딩이 따로 있습니다. 새 프로젝트는 **Free** 요금제로 시작합니다(대부분의 효과를 사용할 수 있으며, 출력에는 항상 워터마크가 들어갑니다). 요금제 세부 사항은 [요금제 및 기능](./pricing)을 참고하세요.

## 애플리케이션 정보 바인딩 {#bind-application-information}

프로젝트의 **Credentials**를 엽니다. SDK는 실행 중인 앱이 콘솔에 바인딩된 식별자와 일치하는지 확인합니다. 출시할 플랫폼마다 값을 입력하고 저장하세요.

- **iOS / macOS**: Bundle ID (예: `com.example.app`)
- **Android**: 애플리케이션 패키지 이름 (예: `com.example.app`)
- **Windows**: 애플리케이션 이름 또는 실행 파일 이름
- **Linux**: 애플리케이션 이름 또는 패키지 이름
- **Web**: 애플리케이션 도메인 (예: `example.com`)
- **Flutter**: **iOS Bundle ID**와 **Android 패키지 이름**을 모두 바인딩합니다

바인딩이 없거나 일치하지 않으면 인증이 실패합니다. Bundle ID가 없는 CLI 도구는 콘솔에 안내된 대로 프로세스 이름을 바인딩하세요.

## 요금제 구독

프로젝트 **Overview** 또는 **Billing** 페이지에서 업그레이드합니다.

1. **Adjust plan**(또는 Overview의 업그레이드 동작)을 엽니다.
2. **Monthly** 또는 **Yearly**를 선택합니다(연간은 약 20% 할인).
3. **Basic / Pro / Pro+**(또는 다른 유료 등급)를 고릅니다. [요금제 및 기능](./pricing)을 참고하세요.
4. 결제를 완료합니다. 카드 등 일반적인 결제 수단을 지원합니다. 중국어 콘솔에서는 알리페이 일회성 선결제(월간 또는 연간, 자동 갱신 없음)도 제공합니다.

**Billing**에서 갱신·만료, 인보이스를 확인하고, 카드 구독의 자동 갱신을 취소할 수 있습니다. 알리페이 선결제는 만료 전에 다시 구매해야 합니다.

## AppID와 AppKey 받기 {#get-appid-and-appkey}

프로젝트 **Credentials** 페이지에서 **App ID**와 **App Key**를 복사합니다.

네이티브 앱은 `appId` + `appKey`로 인증하거나, `licenseToken`(라이선스 토큰 문자열, `{token}` JSON, 또는 오프라인 `.lic` 파일 내용)을 사용할 수 있습니다. Web에서는 프론트엔드 JavaScript에 `appKey`를 넣지 마세요. 자세한 내용은 [인증 및 라이선스](./license)를 참고하세요.

App Key를 교체하려면 같은 페이지의 **Reset key**를 사용합니다. 이전 키는 즉시 무효화되므로, 먼저 앱을 업데이트하세요.
