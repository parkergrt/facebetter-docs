Facebetter는 개발자를 위한 실시간 뷰티 효과 엔진입니다. 이미지와 실시간 영상 스트림에 고품질 AI 뷰티 처리를 제공합니다. GPU 가속으로 지연이 낮고 프레임 레이트가 높으며, Android, iOS, macOS, Windows, Linux, Web, Flutter에 연동할 수 있습니다.

## 핵심 기능

### 피부 뷰티

스무딩, 미백, 혈색, 샤프닝 네 가지 파라미터를 독립적으로 조절하는 세밀한 피부 보정입니다. 강도는 `[0.0, 1.0]`입니다(`0`은 꺼짐). 스무딩과 미백에는 스타일 프리셋도 있습니다.

### 페이스 리셰이프

얼굴 윤곽과 이목구비 비율을 폭넓게 조절합니다.

- **얼굴형**: 슬림, V라인, 좁은 얼굴, 짧은 얼굴, 작은 얼굴, 이마
- **윤곽**: 광대, 턱선, 턱
- **이목구비**: 코 슬림/길이, 인중, 입 크기/위치/미소, 입술 두께
- **눈·눈썹**: 눈 크기/간격/둥근 정도/위치/각도/눈꼬리, 애교살, 눈썹 위치/간격/두께

강도 범위는 `[-1.0, 1.0]`입니다. [파라미터 열거형](./makeup)을 참고하세요.

> 한 프레임에서 리셰이프와 메이크업을 동시에 적용할 수 있는 얼굴은 최대 **5명**입니다.

### 바디 리셰이프

전신 슬림과 비율 조절: 전신, 허리, 다리, 어깨, 팔, 다리 길게, 가슴 볼륨. 강도는 `[0.0, 1.0]`입니다(`0`은 꺼짐). 선택 팩 `resource_body.fbd`가 필요합니다. [선택 리소스 팩](./resource-packs)과 [파라미터 열거형](./makeup)을 참고하세요. **Pro+**가 필요합니다(Free는 워터마크와 함께 체험). [요금제 및 기능](./pricing)을 참고하세요.

### 메이크업

립스틱, 블러셔, 아이섀도, 아이라이너, 눈썹, 속눈썹, 컬러 렌즈, 컨투어를 레이어로 적용합니다. 강도, 형태, 색상은 따로 설정합니다. 여러 항목을 동시에 적용할 수 있습니다. [파라미터 열거형](./makeup)을 참고하세요.

### 필터 및 스타일

인물, 음식, 풍경, 모던 등 테마를 다루는 20종 이상의 실시간 스타일 필터가 있습니다. 강도를 조절할 수 있습니다. 커스텀 필터는 `setFilter`로 로드하는 `.fbd` 파일입니다.

### 가상 배경

실시간 인물 세그멘테이션을 사용합니다.

- **배경 블러**: 전경 피사체는 선명하게 유지하고 배경에 가우시안 블러를 적용합니다
- **배경 교체**: 배경을 JPEG / PNG 이미지로 바꿉니다

### 스티커 효과

2D·3D 스티커 효과입니다.

- **화면 스티커**: 프레임의 고정 위치에 오버레이합니다
- **얼굴 추적 스티커**: 얼굴 키포인트에 고정되어 머리 움직임을 따라갑니다
- **3D 스티커**: 메시 소품(안경, 모자, 마스크). 선택 팩 `resource_3d.fbd`가 필요합니다. [선택 리소스 팩](./resource-packs)을 참고하세요. **Pro+**가 필요합니다(Free는 워터마크와 함께 체험). [요금제 및 기능](./pricing)을 참고하세요

스티커(및 필터) 리소스는 **`.fbd` 파일**입니다. 2D 스티커 하나는 `setSticker`로, 3D 스티커 하나는 `set3DSticker`로 적용합니다(경로 또는 바이트). 제거는 `clearSticker` / `clear3DSticker`입니다. 새 리소스는 다음에 처리되는 프레임부터 적용됩니다.

### 고급 기능

- **얼굴 키포인트 콜백**: 감지된 얼굴마다 **111**개의 정규화 랜드마크(가시성, 포즈, face id 포함)를 반환하며, 커스텀 효과와 비즈니스 로직에 사용할 수 있습니다
- **크로마키**: 초록, 파랑, 빨강 스크린을 가상 배경 마스크로 키아웃합니다

기능 제공 여부는 구독 요금제에 따라 다릅니다. Free는 워터마크와 함께 대부분의 효과를 체험할 수 있습니다. [요금제 및 기능](./pricing)을 참고하세요.

## 입력 / 출력 형식

### 이미지 형식

| 유형 | 지원 형식 |
| --- | --- |
| 정적 이미지 | `JPEG`, `PNG` |
| 비디오 프레임 | `YUV I420`, `NV12`, `NV21`, `RGB`, `RGBA`, `BGR`, `BGRA` |
| GPU 텍스처 | OpenGL / OpenGL ES `Texture` |

### 해상도 제한

| 시나리오 | 최대 |
| --- | --- |
| 실시간 비디오 스트림 | `720P @ 60fps` / `1080P @ 30fps` |
| 정적 이미지 처리 | 최대 `4K` |

`ImageFrame`은 위 형식 간에 변환합니다.

## 성능

| 지표 | 값 |
| --- | --- |
| 렌더 지연 | `1080P`에서 평균 약 `10ms`(GPU 병렬) |
| CPU 사용량 | 실시간 렌더링 중 < `5%` |
| 메모리 사용량 | 주로 GPU 메모리이며, 시스템 RAM 사용량은 낮습니다 |
