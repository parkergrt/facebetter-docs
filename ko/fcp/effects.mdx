**Facebetter Beauty**를 클립에 적용하고 효과 패널에서 조절합니다. 영상은 이 Mac에서 처리됩니다.

각 페이지에 초기화가 있습니다. 다른 페이지는 그대로입니다.

<Note>
컨트롤은 [OBS 뷰티 필터](/ko/obs/effects)와 같습니다. OBS 문서의 소스 선택, 로그인, 눌러서 비교, 효과 프리셋은 이 플러그인에 없습니다. Facebetter 계정도 없습니다. 워터마크와 구매는 FxFactory에서 처리합니다. [설치](/ko/fcp/install)를 보세요.
</Note>

| 페이지 | 조절 내용 |
| --- | --- |
| 피부 | 스무딩 스타일, 잡티 제거, 피부톤, 혈색, 선명도. 피부만 적용할 수 있습니다. |
| 윤곽 | 얼굴, 이마와 눈썹, 눈, 코, 입. 각 항목은 양쪽으로 움직입니다. 0은 그대로입니다. |
| 화장 | 립스틱, 블러시, 치아, 컨투어, 아이섀도, 아이라이너, 눈썹, 속눈썹, 렌즈. 강도 0이면 그 항목은 꺼집니다. |
| 컬러 | 밝기, 대비, 채도, 색온도, 틴트 다음에 LUT 하나. |
| 스티커 | 얼굴 스티커, 화면 스티커, 3D 소품 중 하나. 없음이면 제거됩니다. |
| 바디 | 몸, 어깨와 팔, 다리. 얼굴만 나온 것보다 더 크게 보여야 변화가 분명합니다. |
| 배경 | 배경을 유지, 흐림 또는 교체합니다. 인물 검출, 또는 녹색·파랑·빨강 스크린으로 누끼를 냅니다. |
