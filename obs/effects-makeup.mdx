Each block has an **Intensity** slider. At 0 that item is off. Where a block has a style row and a color row, pick both, then raise the intensity.

Reset on this page returns these controls to their defaults.
How the panel follows the selected source: [Adjust effects](/obs/effects).

## Lipstick

Colors: **Rose**, **Retro red**, **Peach**, **Coral**, **Soft pink**, **Orange**, **Rosewood**, **Brick red**, **Berry**, **Nude**.

- **Intensity** — 0 turns this item off.

## Blush

Choices: **Sun-kissed**, **Flushed**, **Soft**, **Apple**, **Classic**, **Doll**, **Rose**.

Colors: **Peach**, **Dusty rose**, **Red**, **Berry**, **Sunset**, **Peach**, **Sakura pink**.

- **Intensity** — 0 turns this item off.

## Teeth

- **Intensity** — 0 turns this item off.
