Facebetter is a realtime beauty filter for OBS Studio. Skin, shape, makeup, color, stickers, body, and background are processed on this computer. It does not cover the whole OBS window. It follows the source you select.

## Before you start

- macOS 13 or later. Use the Intel build of OBS on an Intel Mac, and the Apple silicon build on Apple silicon.
- OBS Studio 28 or later, 64-bit.

Download: [https://facebetter.net/obs](https://facebetter.net/obs). Other systems: [Windows](/obs/install-windows), [Ubuntu](/obs/install-ubuntu).

## Install

Quit OBS completely first, including the menu-bar icon. If OBS is running during install, that session will not load the plugin.

Download the macOS zip from the page above and unzip it. Inside are `Facebetter-OBS-*-macos-universal.pkg` and the short guides `README.zh.txt` and `README.en.txt`.

Double-click the pkg. On the introduction page, click Continue. On the disk page, click Continue again. On Installation Type, keep the default and click Install. Do not change the install location. The plugin is installed for the current macOS user only.

macOS may ask for your password or Touch ID. When it finishes, the plugin is here:

```text
~/Library/Application Support/obs-studio/plugins/facebetter.plugin
```

Then [sign in and use it](/obs/login).
