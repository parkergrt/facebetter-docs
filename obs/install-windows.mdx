Facebetter is a realtime beauty filter for OBS Studio. Skin, shape, makeup, color, stickers, body, and background are processed on this computer. It does not cover the whole OBS window. It follows the source you select.

## Before you start

- Windows 10 or Windows 11, 64-bit.
- OBS Studio 28 or later, 64-bit.

Download: [https://facebetter.net/obs](https://facebetter.net/obs). Other systems: [macOS](/obs/install), [Ubuntu](/obs/install-ubuntu).

## Install

Quit OBS completely first, including the menu-bar icon. If OBS is running during install, that session will not load the plugin.

Download the Windows zip and unzip it. Double-click `Facebetter-OBS-*-windows-x64-setup.exe`, allow the admin prompt, and finish the wizard.

The installer is unsigned. If SmartScreen says Windows protected your PC, click More info, then Run anyway.

The plugin is installed here:

```text
C:\ProgramData\obs-studio\plugins\obs-facebetter\
```

Then [sign in and use it](/obs/login).
