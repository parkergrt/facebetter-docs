Facebetter is a realtime beauty filter for OBS Studio. Skin, face shape, makeup, color filters, stickers, body, and background are processed on this computer.

It does not affect the whole OBS window by itself. Add **Facebetter Beauty** to the source you want, and the sliders in the side panel start working. A camera, image, or video source all work. Mac install steps are in [Install on Mac](/obs/install). After install, sign-in and adjustments are the same on both systems: [Sign in and add the filter](/obs/login).

Before you start:

- Windows 10 or Windows 11, 64-bit.
- OBS Studio 30 or later, 64-bit.

Download: [facebetter.net/obs](https://facebetter.net/obs)

## Quit OBS and install

Quit OBS completely first. If OBS is running while you install, that session will not load the plugin.

Download the Windows zip and unzip it. Double-click `Facebetter-OBS-*-windows-x64-setup.exe`, allow the admin prompt, and finish the wizard.

The installer is unsigned. If SmartScreen says Windows protected your PC, click More info → Run anyway.

Installs to:

```text
C:\ProgramData\obs-studio\plugins\obs-facebetter\
```

Open OBS, then [sign in and add the filter](/obs/login).
