Select a source, then adjust it here. The OBS preview follows the sliders. Streaming and recording send the processed picture. While **Hold to compare** is down, that moment is unprocessed.

If the header says **Adjusting will add a Facebetter filter**, moving a slider adds **Facebetter Beauty** to that source. See [Sign in and use it](/obs/login) if the panel is missing or the sliders are locked.

Each page has its own reset. **Auto-add to sources** in [Preferences](/obs/settings) is on by default.

| Page | What you set there |
| --- | --- |
| [Skin](/obs/effects-skin) | Smoothing style, blemish, tone, rosy, clarity. Optional: skin areas only. |
| [Shape](/obs/effects-shape) | Face, forehead and brows, eyes, nose, mouth. Each control moves both ways. 0 means unchanged. |
| [Makeup](/obs/effects-makeup) | Lipstick, blush, teeth, contour, eyeshadow, eyeliner, brows, lashes, lenses. Intensity 0 turns that item off. |
| [Color](/obs/effects-color) | Brightness, contrast, saturation, temperature, tint, then a LUT look. |
| [Sticker](/obs/effects-sticker) | One face sticker, screen sticker, or 3D prop. None removes it. |
| [Body](/obs/effects-body) | Torso, shoulders and arms, legs. Needs more of the person in frame than a face-only shot. |
| [BG](/obs/effects-background) | Keep, blur, or replace the background. Cut out with portrait detection, or a green, blue, or red screen. |
