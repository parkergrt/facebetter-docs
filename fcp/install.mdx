The Beauty Effect FCP plugin is **Facebetter Beauty**, a realtime effect for **Final Cut Pro** and **Motion** on macOS Apple silicon. Skin, reshape, makeup, color, stickers, body, and background run on this Mac. The controls match the [OBS beauty filter](/obs/effects). This plugin has no Facebetter account login, no effect presets, and no hold-to-compare.

It is sold only on **FxFactory**. There is no standalone download. A trial runs with a watermark. Buying in FxFactory removes the watermark. The purchase is one-time, not a Facebetter subscription.

## Before you start

- macOS on **Apple silicon** (M1 / M2 / M3 / M4).
- Final Cut Pro or Motion.
- [FxFactory](https://fxfactory.com).

## Install

1. Install FxFactory from [fxfactory.com](https://fxfactory.com).
2. In FxFactory, install **Facebetter Beauty**. You can try it before you buy.
3. Fully quit Final Cut Pro or Motion, then open it again.
4. In the effects browser, find **Facebetter Beauty** and apply it to a clip.

The same install is available in Motion.

If the panel says FxFactory is missing, install it and open the product again. **Buy** opens the purchase in FxFactory.

What each page adjusts: [Effects](/fcp/effects). If the effect does not appear: [FAQ](/fcp/faq).
