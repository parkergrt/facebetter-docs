Facebetter Beauty is a realtime beauty effect for **Final Cut Pro** and **Motion** on macOS Apple silicon. Skin, reshape, makeup, color filters, stickers, body, and virtual background run on this Mac.

Download: [facebetter.net/edit](https://facebetter.net/edit).

Before you start:

- macOS on **Apple silicon** (M1 / M2 / M3 / M4).
- Final Cut Pro (or Motion) installed.

## Install

1. Download the macOS zip and unzip it.
2. Move **Facebetter FCP Beauty.app** into **Applications** (or `~/Applications`).
3. Open the app and click **Set up for Final Cut** (registers the plugin and installs the Motion template).
4. Fully quit Final Cut Pro, reopen it, then find **Facebetter Beauty** under Effects and drag it onto a clip.

No admin password is required for the usual install path.

<Tip>
The same setup also installs the Motion template so you can use the effect in Motion.
</Tip>
