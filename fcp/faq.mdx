## Facebetter Beauty does not appear

1. Install [FxFactory](https://fxfactory.com), then install **Facebetter Beauty** inside it.
2. Fully quit Final Cut Pro or Motion. Closing the library window is not enough. Open the app again.
3. Search for **Facebetter Beauty** in the effects browser.

Email [hello@facebetter.net](mailto:hello@facebetter.net) if it is still missing.

## Is there a standalone installer?

No. There is no zip from facebetter.net. Install and buy only in FxFactory.

## The picture has a watermark

The trial adds a watermark. Buy **Facebetter Beauty** in FxFactory to remove it. This plugin does not use a Facebetter account.

## Does it support Intel Macs?

No. Final Cut and Motion support is **Apple silicon** only.
