<Note>
このページは SDK **2.0** に対応します。数値は C++、Objective-C、Java、JavaScript、Dart で同一です。
</Note>

メイクは 3 つのつまみです。

1. **強度** — `SetLipstick` / `SetBlush` / `SetContour` / `SetEyeShadow` / `SetEyeLiner` / `SetEyebrow` / `SetEyelash` / `SetPupil`、範囲 `[0.0, 1.0]`。`0` で効果をオフにします。
2. **形状** — マスクテクスチャを差し替えます（`SetBlushStyle`、`SetContourStyle`、`SetEyeShadowStyle` など）。
3. **色** — 現在の形状に着色します（`SetLipstickColor`、`SetBlushColor`、`SetEyeShadowColor` など）。**瞳孔**と**シェーディング**は着色せず、項目を変えるとテクスチャが切り替わります。

| C++ / JS | Java | Objective-C | Dart |
| --- | --- | --- | --- |
| `LipstickColor::Rouge` | `LipstickColor.ROUGE` | `FBLipstickColor_Rouge` | `FBLipstickColor.rouge` |

## 美白（`WhiteningStyle`）

`SetWhiteningStyle` と組み合わせて使います。強度はこれまでどおり `SetWhitening` です。デフォルト: `ColdWhite`。

| 値 | 名前 | 意味 |
| --- | --- | --- |
| 0 | `ColdWhite` | クールホワイト |
| 1 | `PinkWhite` | ピンクホワイト |
| 2 | `WarmWhite` | ウォームホワイト |
| 3 | `Wheat` | 小麦色 |
| 4 | `Tan` | 日焼け |

## スムージング（`SmoothingStyle`）

`SetSmoothingStyle` と組み合わせて使います。強度はこれまでどおり `SetSmoothing` です。デフォルト: `Natural`。

| 値 | 名前 | 意味 |
| --- | --- | --- |
| 0 | `Natural` | 毛穴を残す |
| 1 | `Texture` | よりきれいに、質感は残す |
| 2 | `Smooth` | クリーミーな肌 |

## フェイスリシェイプ（`Reshape`）

`SetReshape(param, intensity)` と組み合わせて使います。範囲は **`[-1.0, 1.0]`** です。`0` はオフです。正と負は逆方向です（例: FaceThin は瘦顔 / 頬をふっくら）。

| 値 | 名前 | 正方向 / 負方向 |
| --- | --- | --- |
| 0 | `FaceThin` | 瘦顔 / 頬をふっくら |
| 1 | `FaceVShape` | V 字 / 四角い顎 |
| 2 | `FaceNarrow` | 狭い顔 / 広い顔 |
| 3 | `FaceShort` | 短い顔 / 長い顔 |
| 4 | `Cheekbone` | 頬骨を細く / 広げる |
| 5 | `Jawbone` | 顎を細く / 広げる |
| 6 | `Chin` | あごを長く / 短く |
| 7 | `NoseSlim` | 鼻を細く / 広く |
| 8 | `EyeSize` | 目を大きく / 小さく |
| 9 | `EyeDistance` | 目幅を広く / 狭く |
| 10 | `FaceSmall` | 小顔 / 大きな顔 |
| 11 | `Forehead` | 額を豊かに / 低く |
| 12 | `NoseLong` | 鼻を長く / 短く |
| 13 | `Philtrum` | 人中を短く / 長く |
| 14 | `MouthSize` | 口を大きく / 小さく |
| 15 | `MouthPosition` | 口を下へ / 上へ |
| 16 | `MouthSmile` | 笑顔 / 口角を下げる |
| 17 | `LipThickness` | 唇を厚く / 薄く |
| 18 | `EyeRound` | 丸い目 / 細い目 |
| 19 | `EyePosition` | 目を下へ / 上へ |
| 20 | `EyeAngle` | 目尻を上げる / 下げる |
| 21 | `EyeCornerOpen` | 目尻を開く / 閉じる |
| 22 | `LowerEyelid` | 下まぶたを下げる / 上げる |
| 23 | `BrowPosition` | 眉を上げる / 下げる |
| 24 | `BrowDistance` | 眉間を広く / 狭く |
| 25 | `BrowThickness` | 眉を太く / 細く |

Java の名前は `SNAKE_CASE`（`FACE_THIN`、`FACE_V_SHAPE` など）です。Objective-C は `FBReshape_FaceThin`、Dart は `FBReshape.faceThin` です。

## シェーディング（`ContourStyle`）

中間グレーの Overlay マップです。128 より明るい部分はハイライト、暗い部分は陰影です。テクスチャ差し替えのみで着色はありません。デフォルト: `Natural`。

| 値 | 名前 | 意味 |
| --- | --- | --- |
| 0 | `Natural` | 日常の軽いシェーディング |
| 1 | `Sculpt` | より強いスカルプト |
| 2 | `Glow` | ハイライト重視 |
| 3 | `Slim` | 頬骨を細く |
| 4 | `Nose` | 鼻筋の定義 |
| 5 | `Glam` | ハイライトスポット |
