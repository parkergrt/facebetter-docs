このサイトは **SDK 2.x** をドキュメント化しています。最新版: **v2.1.0**。

## v2.1.0

2026-09-21

1. ボディリシェイプ：全身、ウエスト、脚、肩、腕、脚長、バストアップなど。[パラメータ列挙](/ja/intro/makeup) を参照してください
2. 3D ステッカー（メガネ、帽子などのメッシュ小道具）
3. ボディリシェイプと 3D ステッカー用のオプションリソースパック。[オプションリソースパック](/ja/intro/resource-packs) を参照してください

## v2.0.1

2026-09-15

1. Web と Android の処理性能を向上

## v2.0.0

2026-09-09

1. 新しい認証：ネイティブは `licenseToken` または `appId` + `appKey`。Web は `licenseToken` のみ（自社サーバーで取得）
2. 美顔：スムージング、美白、シャープ、血色、肌のみ、およびスタイルプリセット
3. 顔リシェイプ（26 項目）
4. メイク：強度、形状、色。[パラメータ列挙](/ja/intro/makeup) を参照してください
5. LUT フィルターと 2D ステッカー（`.fbd`）
6. バーチャル背景：ぼかし、画像置換、クロマキー
7. Flutter SDK（Android / iOS）
8. 処理統計（`getStats()`）
