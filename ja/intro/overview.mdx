title: "概要"
description: "画像とライブ映像向け Beauty Effect SDK の機能"
---

Beauty Effect SDK は、Android、iOS、Web、macOS、Windows、Linux で画像とライブ映像を処理します。処理は GPU で加速されます。列挙値は [パラメータ列挙](./makeup)、プランは [プランと機能](./pricing) を参照してください。

## 主な機能

### 美肌

スムージング、美白、血色、ニキビ除去。それぞれ `[0.0, 1.0]` で、`0` はオフです。

- スムージングは 3 スタイル：Natural、Texture、Smooth。デフォルトは Natural。
- 美白は 5 種類：Cold white、Pink white、Warm white、Wheat、Tan。デフォルトは Cold white。
- `setBeautySkinOnly` は美肌を皮膚領域だけに限定します。
- ニキビ除去はスムージングとは独立し、顔のキーポイントではなく皮膚領域を使います。

### 色調

画面全体の調整です。顔のキーポイントも皮膚マスクも使わず、美白、血色、LUT フィルターとも独立しています。

明るさ、コントラスト、彩度、色温度、ティントは `[-1.0, 1.0]`（`0` がニュートラル）。明瞭度は `[0.0, 1.0]`（`0` はオフ）で、局所コントラストを上げます。

### 歯

`setTeethWhiten` は `[0.0, 1.0]`（`0` はオフ）。開いた口の歯を白くし、閉じた口はそのままです。

### 顔リシェイプ

26 項目。各値は `[-1.0, 1.0]`。`0` は元の比率です。正と負は逆方向です。1 フレームでリシェイプとメイクを同時に適用できる顔は最大 **5** です。一覧は [パラメータ列挙](./makeup)。**Pro** が必要です（Free は透かし付きで試用）。[プランと機能](./pricing) を参照してください。

### ボディリシェイプ

9 項目。各値は `[0.0, 1.0]`（`0` はオフ）。負の方向はありません。

全身、ウエスト、脚、肩、腕、脚の長さ、バストの 7 項目は体に沿って変形します。これらにはオプションの `resource_body.fbd` が必要です。[オプションリソースパック](./resource-packs) を参照してください。

`LegStretch` と `TorsoLong` は顔のキーポイントだけで、このパックは不要です。

**Pro+** が必要です（Free は透かし付きで試用）。[プランと機能](./pricing) を参照してください。

### メイク

口紅、チーク、コントゥア、アイシャドウ、アイライン、眉、まつ毛、カラコン。強度は `[0.0, 1.0]`。形状と色は別に設定します。例外は次の二つです。

- 口紅は唇マスク 1 枚に色を乗せます。色は 6 色で、スタイルの切り替えはありません。
- コントゥアとカラコンはテクスチャを差し替えるだけで、着色しません。カラコンは 9 色です。

複数のメイクを同時にオンにできます。列挙は [パラメータ列挙](./makeup)。**Pro** が必要です（Free は透かし付きで試用）。

### フィルター

ライブラリには **51** 種類の LUT があり、ポートレート、モダン、フード、ランドスケープの 4 グループです。強度は調整できます。カスタムフィルターは `.fbd` を `setFilter` に渡します。**Pro** が必要です（Free は透かし付きで試用）。

### ステッカー

- **画面ステッカー**はフレーム上の固定位置に残ります。
- **顔ステッカー**は顔のキーポイントに追従します。
- **3D ステッカー**はメガネ、帽子、マスクなどのメッシュです。`resource_3d.fbd` が必要です。[オプションリソースパック](./resource-packs) を参照してください。

リソースは `.fbd` です。2D は `setSticker`、3D は `set3DSticker`（パスまたはバイト）で 1 つずつ適用します。`clearSticker` / `clear3DSticker` で外します。新しいファイルは次に処理したフレームから有効です。**Pro+** が必要です（Free は透かし付きで試用）。

### バーチャル背景

- **ぼかし**：`setVirtualBackgroundBlur`。`0` でオフ。
- **画像**：`setVirtualBackground` に JPEG または PNG のパスかエンコード済みバイト。
- **クロマキー**：緑、青、赤をマスクにします。類似度、エッジのフェザー、スピル抑制は別の値です。ぼかしも画像もないとき、キーした領域は透明です。
- **被写体のアウトライン**：切り抜きの縁に線を描きます。ぼかし、画像置換、クロマキーのいずれかがオンのときに描画されます。

**Pro+** が必要です（Free は透かし付きで試用）。

## 入力形式

| 種類 | 形式 |
| --- | --- |
| 静止画 | JPEG、PNG |
| 動画フレーム | YUV I420、NV12、NV21、RGB、RGBA、BGR、BGRA |
| GPU テクスチャ | OpenGL / OpenGL ES テクスチャ |

`ImageFrame` はこれらのピクセル形式を相互に変換します。

## プラットフォーム

| プラットフォーム | 要件 |
| --- | --- |
| Android | 7.0+（API 24） |
| iOS | 12.0+ |
| Web | Chrome 57+、Firefox 52+、Safari 11+、Edge 16+。カメラには HTTPS または `localhost` |
| macOS | 10.15+ |
| Windows | Windows 10+ |
| Linux | Ubuntu 22.04+ |

| 言語 | 用途 |
| --- | --- |
| Java / Kotlin | Android |
| Objective-C / Swift | iOS、macOS |
| C++ | Windows、Linux、macOS |
| JavaScript | ブラウザ SDK。ページに `appKey` を置かないでください。Node はライセンストークンの交換専用です。[認証とライセンス](./license) を参照してください。 |
