Facebetter は、開発者向けのリアルタイム美顔エフェクトエンジンです。静止画とライブ動画の両方に、高品質な AI 美顔処理を提供します。GPU 加速により低遅延・高フレームレートで動作し、Android、iOS、macOS、Windows、Linux、Web、Flutter に統合できます。

## 主な機能

### 美肌

4 つの独立パラメータ（スムージング、美白、血色、シャープニング）で肌を細かく調整します。強度は `[0.0, 1.0]`（`0` はオフ）です。スムージングと美白にはスタイルプリセットもあります。

### リシェイプ

顔の輪郭から五官の比率まで、包括的に調整できます。

- **顔型**: 瘦顔、V 字、幅、長さ、小顔、額
- **輪郭**: 頬骨、顎、あご先
- **五官**: 鼻の細さ / 長さ、人中、口の大きさ / 位置 / 笑顔、唇の厚さ
- **目と眉**: 目の大きさ / 間隔 / 丸み / 位置 / 角度 / 目尻、下まぶた、眉の位置 / 間隔 / 太さ

強度の範囲は `[-1.0, 1.0]` です。[パラメータ列挙](/ja/intro/makeup) を参照してください。

> 1 フレームあたり、リシェイプとメイクを同時に適用できる顔は最大 **5 つ**です。

### メイク

リップ、チーク、アイシャドウ、アイライナー、アイブロウ、まつ毛、カラーコンタクト、シェーディングを重ねて適用できます。強度、形状、色は個別に設定でき、複数項目を同時に使えます。[パラメータ列挙](/ja/intro/makeup) を参照してください。

### フィルターとスタイル

ポートレート、料理、風景、モダンなど、20 種以上のリアルタイムスタイルフィルターを内蔵しています。強度は調整可能です。カスタムフィルターは `.fbd` ファイルで、`setFilter` で読み込みます。

### バーチャル背景

リアルタイムの人物セグメンテーションを利用します。

- **背景ぼかし**: 前景の人物を鮮明に保ち、背景にガウシアンブラーを適用します
- **背景置換**: 背景を JPEG / PNG 画像に差し替えます

### ステッカーエフェクト

2D および 3D ステッカーに対応します。

- **スクリーンステッカー**: フレーム上の固定位置に重ねます
- **フェイストラッキングステッカー**: 顔のキーポイントに固定し、頭部の動きに追従します
- **3D ステッカー**: メガネ、帽子、マスクなどのメッシュ小道具。オプションの `resource_3d.fbd` パックが必要です。[オプションリソースパック](/ja/intro/resource-packs) を参照してください

ステッカーとフィルターのリソースは **`.fbd` ファイル**です。2D ステッカーは `setSticker`、3D ステッカーは `set3DSticker`（パスまたはバイト）で 1 つずつ適用し、`clearSticker` / `clear3DSticker` で解除します。新しいリソースは、次に処理されるフレームから有効になります。

### 高度な機能

- **顔キーポイントコールバック**: 検出された各顔について、正規化されたランドマーク **111** 点（可視性、姿勢、face id 付き）を返し、カスタムエフェクトや業務ロジックに使えます
- **クロマキー**: グリーン / ブルー / レッドスクリーンをキーアウトし、バーチャル背景のマスクとして使います

機能の可否はサブスクリプションプランによります。Free では大部分の効果を透かし付きで試せます。[プランと機能](/ja/intro/pricing) を参照してください。

## 入出力フォーマット

### 画像フォーマット

| 種類 | 対応フォーマット |
| --- | --- |
| 静止画 | `JPEG`、`PNG` |
| 動画フレーム | `YUV I420`、`NV12`、`NV21`、`RGB`、`RGBA`、`BGR`、`BGRA` |
| GPU テクスチャ | OpenGL / OpenGL ES `Texture` |

### 解像度の上限

| 用途 | 最大 |
| --- | --- |
| リアルタイム動画ストリーム | `720P @ 60fps` / `1080P @ 30fps` |
| 静止画処理 | 最大 `4K` |

`ImageFrame` はこれらのフォーマット間で変換できます。

---

## パフォーマンス

| 指標 | 値 |
| --- | --- |
| レンダリング遅延 | `1080P` で平均約 `10ms`（GPU 並列） |
| CPU 使用率 | リアルタイムレンダリング中は < `5%` |
| メモリ使用量 | 主に GPU メモリ。システム RAM の使用は少なめです |
