## 登録 / ログイン

[Facebetter ウェブサイト](https://facebetter.net/ja) を開き、[ログイン](https://facebetter.net/ja/sign-in) または [アカウント作成](https://facebetter.net/ja/sign-up) を行います。メール / パスワードと、ソーシャルログイン（Google、GitHub）に対応しています。

ログイン後は [コンソール](https://facebetter.net/ja/dashboard) に入ります。プロジェクトを作成してください。各プロジェクトには独自のプラン、認証情報、プラットフォームバインドがあります。新規プロジェクトは **Free** プランから始まります（大部分の効果を利用でき、出力には常に透かしが付きます）。プランの詳細は [プランと機能](/ja/intro/pricing) を参照してください。

## アプリ情報のバインド

プロジェクトの **認証情報** を開きます。SDK は、実行中のアプリがコンソールにバインドした識別子と一致するかを確認します。出荷する各プラットフォームを記入して保存してください。

- **iOS / macOS**: Bundle ID（例: `com.example.app`）
- **Android**: アプリケーションのパッケージ名（例: `com.example.app`）
- **Windows**: アプリケーション名または実行ファイル名
- **Linux**: アプリケーション名またはパッケージ名
- **Web**: アプリケーションドメイン（例: `example.com`）
- **Flutter**: **iOS Bundle ID** と **Android パッケージ名の両方**をバインドします

バインドが欠けていたり一致しなかったりすると、認証は失敗します。Bundle ID のない CLI ツールでは、コンソールの案内どおりプロセス名をバインドしてください。

## プランの契約

プロジェクトの **概要** または **請求** ページからアップグレードします。

1. **プランを変更**（または概要のアップグレード操作）を開きます。
2. **月額** または **年額** を選びます（年額は約 20% オフ）。
3. **Basic / Pro / Pro+**（または他の有料プラン）を選びます。[プランと機能](/ja/intro/pricing) を参照してください。
4. 決済を完了します。カードなど一般的な方法に対応しています。中国語コンソールでは、Alipay による一括前払い（月額または年額、自動更新なし）も利用できます。

**請求** では、更新や有効期限、請求書の確認、カード契約の自動更新キャンセルができます。Alipay の前払いは、期限前に再度購入する必要があります。

## AppID と AppKey の取得

プロジェクトの **認証情報** ページで **App ID** と **App Key** をコピーします。

ネイティブアプリは `appId` + `appKey`、または `licenseToken`（ライセンストークン文字列、`{token}` JSON、オフライン `.lic` ファイルの内容）で認証できます。Web では、フロントエンドの JavaScript に `appKey` を埋め込まないでください。詳細は [認証とライセンス](/ja/intro/license) を参照してください。

App Key をローテーションする場合は、同じページの **キーをリセット** を使います。以前のキーはすぐに無効になるため、先にアプリ側を更新してください。
