**Beauty Effect SDK 2.0** は、静止画とライブ動画向けのリアルタイム美顔エフェクトエンジンです。下のプラットフォームを選ぶか、まずサブスクリプションとライセンスから始めてください。

<Tip>
Cursor、Claude、ChatGPT と連携する場合は、[AI との連携](/ja/intro/use-with-ai) で MCP と `llms.txt` を確認してください。
</Tip>

<CardGroup cols={2}>
  <Card title="サービスを有効にする" icon="key" href="/ja/intro/enable-service">
    プロジェクトを作成し、AppID / AppKey を取得します。
  </Card>
  <Card title="Android" icon="android" href="/ja/android/quick-start">
    サンプルを動かしてから、アプリに美顔を組み込みます。
  </Card>
  <Card title="iOS" icon="apple" href="/ja/ios/quick-start">
    CocoaPods または Framework による統合。
  </Card>
  <Card title="Web" icon="globe" href="/ja/web/quick-start">
    JavaScript SDK。
  </Card>
  <Card title="Linux" icon="linux" href="/ja/linux/quick-start">
    Linux 向け C++ SDK。
  </Card>
  <Card title="OBS プラグイン" icon="video" href="/ja/obs/install">
    OBS に美顔フィルタを入れて調整します。

    Figma でフェイスステッカーとスクリーンステッカーを作成します。
  </Card>
  <Card title="編集プラグイン" icon="clapperboard" href="/ja/fcp/install">
    Final Cut Pro / Motion 美顔プラグイン。After Effects は近日公開。
  </Card>
</CardGroup>
