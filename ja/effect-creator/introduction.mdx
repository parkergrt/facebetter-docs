Facebetter Effect Creator Figma プラグインは、Facebetter SDK 向けのステッカーとメイク効果を作成するための専用ツールです。ステッカーとメイクの制作工程を簡素化します。このプラグインを使うと、Figma 内でステッカーデザイン、顔ランドマークのバインド、属性設定、3D プレビューとエクスポートまで完了できます。

## ログインと言語設定
プラグインはログイン後に利用できます。Facebetter アカウントまたはメール、あるいは Google や GitHub などのソーシャルアカウントでログインできます。

1.  **プラグインを起動**: Figma で Facebetter Effect Creator プラグインを実行します。
2.  **ログイン**: Google、GitHub、またはメールログインに対応しています。
3.  **言語切り替え**: 画面上部のドロップダウンメニューアイコンをクリックし、**簡体字中国語** と **English** を切り替えます。

## プラグインのインストール
このリンクをクリックするか、[プラグイン](https://www.figma.com/community/plugin/1591037386605818409/facebetter-effect-creator)、あるいは Figma で "Facebetter Effect Creator" を検索し、"Open In" をクリックして既存ドキュメントまたは新規デザインドキュメントで開きます。新規の空白ドキュメントを推奨します。
