Facebetter Beauty は、macOS Apple シリコン上の **Final Cut Pro** と **Motion** 向けリアルタイム美顔エフェクトです。美肌、輪郭、メイク、カラーフィルタ、スタンプ、ボディ、仮想背景はこの Mac 上で処理されます。

ダウンロード：[facebetter.net/ja/edit](https://facebetter.net/ja/edit)。

始める前に：

- **Apple シリコン**（M1 / M2 / M3 / M4）の macOS。
- Final Cut Pro（または Motion）がインストール済みであること。

## インストール

1. macOS 用 zip をダウンロードして解凍します。
2. **Facebetter FCP Beauty.app** を「アプリケーション」（または `~/Applications`）へ移動します。
3. アプリを開き、**ワンクリックで設定**をクリックします（プラグイン登録と Motion テンプレートのインストール）。
4. Final Cut Pro を完全に終了して開き直し、エフェクトで **Facebetter Beauty** を探してクリップにドラッグします。

通常の手順では管理者パスワードは不要です。

<Tip>
同じセットアップで Motion テンプレートも入り、Motion でも使えます。
</Tip>

詳しくは [FAQ](/ja/fcp/faq)。
