**Facebetter Beauty** をクリップに適用し、エフェクトパネルで調整します。映像はこの Mac 上で処理されます。

各ページにリセットがあります。他のページはそのままです。

<Note>
コントロールは [OBS 美顔フィルター](/ja/obs/effects) と同じです。OBS のページにあるソースの選択、ログイン、比較の長押し、エフェクトプリセットは、このプラグインにはありません。Facebetter アカウントもありません。透かしと購入は FxFactory で扱います。[インストール](/ja/fcp/install) を参照してください。
</Note>

| ページ | 調整内容 |
| --- | --- |
| 美肌 | スムージングのスタイル、ニキビ除去、肌色、血色、明瞭度。肌だけに限定できます。 |
| 輪郭 | 顔、額と眉、目、鼻、口。各項目は両方向に動けます。0 は変更なしです。 |
| メイク | 口紅、チーク、歯、コントゥア、アイシャドウ、アイライン、眉、まつ毛、カラコン。強度 0 でその項目はオフです。 |
| カラー | 明るさ、コントラスト、彩度、色温度、ティントのあと、LUT を 1 つ選びます。 |
| スタンプ | 顔スタンプ、画面スタンプ、3D 小道具のいずれか 1 つ。なしで外れます。 |
| 体型 | 体、肩と腕、脚。顔だけより大きく映っていると変化が分かります。 |
| 背景 | 背景を残す、ぼかす、または置き換えます。人物検出、または緑・青・赤のスクリーンで切り抜きます。 |
