Facebetter は OBS Studio のリアルタイム美顔フィルタです。美肌、輪郭、メイク、カラー、スタンプ、体型、背景はすべてこのパソコンで処理します。OBS 全体にはかからず、選んだソースだけに従います。

## 始める前に

- macOS 13 以降。Intel Mac には Intel 版 OBS、Apple シリコンには Apple シリコン版 OBS。
- OBS Studio 28 以降、64 ビット。

ダウンロード：[https://facebetter.net/ja/obs](https://facebetter.net/ja/obs)。 ほかのシステム：[Windows](/ja/obs/install-windows)、[Ubuntu](/ja/obs/install-ubuntu)。

## インストール

インストール前に OBS を完全に終了します。メニューバーのアイコンも終了してください。OBS を開いたまま入れると、その起動では新しいプラグインを読みません。

上のページから macOS の zip をダウンロードして解凍します。中にあるのは `Facebetter-OBS-*-macos-universal.pkg` と、短い説明 `README.zh.txt`、`README.en.txt` です。

pkg をダブルクリックします。紹介で「続ける」、ディスクの確認でもう一度「続ける」。インストールの種類では初期のまま「インストール」を押します。場所は変えないでください。プラグインは今の macOS ユーザーだけに入ります。

パスワードまたは Touch ID を求められることがあります。終わるとここにあります：

```text
~/Library/Application Support/obs-studio/plugins/facebetter.plugin
```

そのあと [ログインして使う](/ja/obs/login) を見てください。
