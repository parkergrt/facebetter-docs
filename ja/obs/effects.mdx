ソースを選んで、ここで調整します。OBS のプレビューはスライダーに従います。配信と録画に出るのは処理後の映像です。下部の **長押しで比較** を押しているあいだだけ、その区間は未処理です。

ヘッダーが **調整すると美顔フィルタが付きます** のとき、スライダーを動かすとそのソースに **Facebetter Beauty** が付きます。パネルがない、またはスライダーがロックされているときは [ログインして使う](/ja/obs/login)。

各ページにリセットがあります。[環境設定](/ja/obs/settings) の **調整時にフィルタを追加** は初期状態でオンです。

| ページ | 調整すること |
| --- | --- |
| [美肌](/ja/obs/effects-skin) | スムージングの種類、ニキビ・シミ、美白、血色、明瞭度。肌の領域だけに限ることもできます。 |
| [輪郭](/ja/obs/effects-shape) | 顔、額と眉、目、鼻、口。各項目は両方向です。0 は変化なし。 |
| [メイク](/ja/obs/effects-makeup) | リップ、チーク、歯、シェーディング、アイシャドウ、アイライン、眉、まつ毛、カラコン。強さ 0 でその項目はオフ。 |
| [カラー](/ja/obs/effects-color) | 明るさ、コントラスト、彩度、色温度、色調、そのあと LUT。 |
| [スタンプ](/ja/obs/effects-sticker) | 顔スタンプ、画面スタンプ、3D アイテムのいずれか一つ。なしで外れます。 |
| [体型](/ja/obs/effects-body) | 体、肩と腕、脚。顔だけより、人が大きく映っている必要があります。 |
| [背景](/ja/obs/effects-background) | 背景を残す、ぼかす、差し替える。人物検出、または緑・青・赤のスクリーン。 |
