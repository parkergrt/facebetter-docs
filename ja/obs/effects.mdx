フィルタをソースに追加したあと、右のパネルで調整します。スライダーに合わせて OBS のプレビューが変わります。配信と録画に出るのは処理後の映像です。まだフィルタを追加していないときは、先に [ログインしてフィルタを追加](/ja/obs/login) を見てください。

<Frame>
  <img src="/images/obs/panel.png" alt="Facebetter パネルで美肌を調整する" />
</Frame>

パネル最上段は左から次のとおりです。

- **スイッチ**：オンとオフを比べます。オフのときは元のプレビューです。配信の前にオンに戻します。
- **ソースメニュー**：すでにフィルタがあるソースを一つ選ぶか、**All sources（すべてのソース）** を選びます。すべてのソースを選ぶと、変更はすべての Facebetter フィルタに書き込まれます。
- **リセット**：今のページを初期値に戻します。
- **歯車**：設定です。OBS の起動時にパネルを開くかどうかを選べます。アカウントとサブスクリプションもここです。

その下に 7 つのページがあります。

| ページ | 内容 |
| --- | --- |
| Skin 美肌 | スムージング、美白、血色。**Skin only（肌のみ）** をオンにすると肌だけが処理され、服、背景、手に持った商品は白くなりません。スムージングは Texture（質感を残す）、Natural（自然）、Smooth（なめらか）です。美白の色は Cool、Pink、Warm、Wheat、Tan の 5 つです。 |
| Shape 輪郭 | 顔、額と眉、目、鼻、口。各項目は両方向に動かせます。0 は変化なしです。 |
| Makeup メイク | リップ、チーク、シェーディング、アイシャドウ、アイライン、眉、まつ毛、カラコン。スタイル、色、強さは別々です。 |
| Filter 色調 | フィルム調色です。LUT を選んでから強さを調整します。None は色調なしです。 |
| Sticker スタンプ | 2D の顔追従、2D の画面スタンプ、3D スタンプ。None で外します。 |
| Body 体型 | 全身、ウエスト、脚、肩、二の腕を細くし、脚を長くし、バストを調整します。半身または全身の映像向きです。 |
| BG 背景 | 元の背景を残す、ぼかす、またはプリセットに差し替えます。切り抜きは人物分割、またはグリーン、ブルー、レッドのスクリーンです。 |

パネルの言語は OBS に従います。簡体字中国語、繁体字中国語、英語、日本語、韓国語、ポルトガル語、スペイン語、ドイツ語にはそれぞれの表示があります。それ以外の OBS の言語では英語になります。

## 透かしを外す

無料プランには上のすべての効果が含まれ、出力に透かしが入ります。プロは透かしがなく、2 台のデバイスで使えます。

- 月額：$8.99
- 年額：$69

パネル上部の「透かしを外す」を押すか、歯車 → アカウントを開いてページで購読します。その案内を閉じても、OBS を終了するまでしか隠れません。購読とデバイスの管理は [facebetter.net/ja/dashboard/obs](https://facebetter.net/ja/dashboard/obs) です。
