パネル右上のアカウントボタンを開きます。ログイン前は **ログイン**、ログイン後はメールの名前です。メニューで **環境設定** を選びます。

同じメニューに **プロ版**（購読後は **会員**）、**購読状態を更新**、**ログイン** または **ログアウト** もあります。ログインは [ログインして使う](/ja/obs/login)。

## 一般と起動

- **OBS 起動時にパネルを開く** — 初期状態はオンです。オフにすると、OBS 起動時に Facebetter パネルは開きません。必要なときは **ツール → Facebetter** から開きます。
- **調整時にフィルタを追加** — 初期状態はオンです。映像のあるソースを一つ選び、スライダーを動かすと、そのソースに **Facebetter Beauty** が付きます。自分で付けるときはオフにし、ソースを右クリックしてフィルタを開き、+ から **Facebetter Beauty** を選びます。

## ログと診断

**デバッグログを書く** は初期状態でオフです。オンにすると、Facebetter は詳しい記録を `facebetter-obs.log` に書きます。OBS 自身のログは常にあり、`[Facebetter]` で始まる要約が入っています。

問題が起きたときは、次の順で両方のログを送ります。

1. **デバッグログを書く** をオンにします。
2. 問題の操作をもう一度します。オンにする前の操作はこのファイルに残りません。
3. その行の横にあるフォルダボタンを押します。ヒントは **ログフォルダを開く** です。中の `facebetter-obs.log` を送ります。まだファイルが無いときは、操作をもう一度してから送ります。
4. OBS のログも取ります。**ヘルプ → ログファイル** から現在のログを表示またはアップロードします。下のフォルダを開き、更新日時が最新のファイルでも構いません。

フォルダボタンが見つからないときの場所です。

### macOS

```text
~/Library/Application Support/obs-studio/plugin_config/facebetter/facebetter-obs.log
```

OBS のログフォルダ：

```text
~/Library/Application Support/obs-studio/logs/
```

### Windows

```text
%APPDATA%\obs-studio\plugin_config\obs-facebetter\facebetter-obs.log
```

これは現在のユーザーのフォルダです。プラグインのインストール先 `C:\ProgramData\...` ではありません。OBS のログフォルダ：

```text
%APPDATA%\obs-studio\logs\
```

### Ubuntu

```text
~/.config/obs-studio/plugin_config/obs-facebetter/facebetter-obs.log
```

OBS のログフォルダ：

```text
~/.config/obs-studio/logs/
```

調べ終わったら **デバッグログを書く** はオフに戻します。

## 情報と更新

ここに現在のバージョンが表示されます。例：`v1.3.0`。

- **確認** — 新しいバージョンがあるか調べます。最新なら **最新の安定版です**。更新があるときは **アップデートがあります** となり、ボタンは **ダウンロード** に変わります。ダウンロードページが開きます。OBS を終了し、新しい版を入れてから開き直します。失敗したときは **確認に失敗しました。再試行してください**。
- **利用規約** と **プライバシーポリシー** はブラウザで開きます。
