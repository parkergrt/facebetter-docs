Facebetter は OBS Studio のリアルタイム美顔フィルタです。美肌、輪郭、メイク、カラー、スタンプ、体型、背景はすべてこのパソコンで処理します。OBS 全体にはかからず、選んだソースだけに従います。

## 始める前に

- Windows 10 または Windows 11、64 ビット。
- OBS Studio 28 以降、64 ビット。

ダウンロード：[https://facebetter.net/ja/obs](https://facebetter.net/ja/obs)。 ほかのシステム：[macOS](/ja/obs/install)、[Ubuntu](/ja/obs/install-ubuntu)。

## インストール

インストール前に OBS を完全に終了します。メニューバーのアイコンも終了してください。OBS を開いたまま入れると、その起動では新しいプラグインを読みません。

Windows の zip を解凍し、`Facebetter-OBS-*-windows-x64-setup.exe` をダブルクリックします。管理者の確認を許可して、ウィザードを終わらせます。

インストーラは未署名です。SmartScreen が「Windows によって PC が保護されました」と出たら、「詳細情報」から「実行」を選びます。

入り先：

```text
C:\ProgramData\obs-studio\plugins\obs-facebetter\
```

そのあと [ログインして使う](/ja/obs/login) を見てください。
