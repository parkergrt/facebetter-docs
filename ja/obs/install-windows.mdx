Facebetter は OBS Studio 用のリアルタイム美顔フィルタです。肌、顔立ち、メイク、カラーフィルタ、ステッカー、ボディ、背景は、このパソコン上で処理されます。

OBS 全体には自動ではかかりません。処理したいソースに **Facebetter ビューティー** を追加すると、右のパネルのスライダーが使えます。カメラ、画像、動画のいずれでも構いません。Mac の手順は [Mac にインストール](/ja/obs/install) です。インストールのあと、ログインと調整は両方のシステムで同じです。[ログインしてフィルタを追加](/ja/obs/login) を見てください。

始める前に：

- Windows 10 または Windows 11、64 ビット。
- OBS Studio 30 以降、64 ビット。

ダウンロード：[facebetter.net/ja/obs](https://facebetter.net/ja/obs)

## OBS を終了してインストール

先に OBS を完全に終了してください。インストール中に OBS が開いていると、そのセッションではプラグインが読み込まれません。

Windows の zip をダウンロードして解凍します。`Facebetter-OBS-*-windows-x64-setup.exe` をダブルクリックし、管理者の許可を出してウィザードを完了します。

インストーラは署名されていません。SmartScreen が PC を保護したと出たら、「詳細情報」→「実行」を選びます。

インストール先：

```text
C:\ProgramData\obs-studio\plugins\obs-facebetter\
```

OBS を開き、[ログインしてフィルタを追加](/ja/obs/login) に進みます。
