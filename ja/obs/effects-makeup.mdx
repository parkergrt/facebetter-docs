各ブロックに **強さ** があります。0 でその項目はオフです。種類と色の両方があるときは、先に両方選んでから強さを上げます。

このページのリセットは、これらの項目を初期値に戻します。
パネルが選択中のソースに従うしくみは [効果を調整](/ja/obs/effects)。

## リップ

色：**ローズ**、**レトロレッド**、**ピーチ**、**コーラル**、**ソフトピンク**、**オレンジ**、**ローズウッド**、**ブリックレッド**、**ベリー**、**ヌード**。

- **強さ** — 0 でこの項目はオフです。

## チーク

種類：**日焼け**、**ほんのり赤み**、**ソフト**、**りんご頬**、**クラシック**、**ドール**、**ローズ**。

色：**コーラルピンク**、**ダスティローズ**、**レッド**、**ベリー**、**サンセット**、**ピーチ**、**サクラピンク**。

- **強さ** — 0 でこの項目はオフです。

## 歯

- **強さ** — 0 でこの項目はオフです。

## シェーディング

種類：**ナチュラル**、**立体**、**明るく**、**小顔**、**鼻筋**、**ハイライト**。

- **強さ** — 0 でこの項目はオフです。

## アイシャドウ

種類：**ソフト**、**二重幅**、**スモーキー**、**ハロー**、**ツヤ**、**濃いめ**、**ウォーム**。

色：**プラム**、**ブラウン**、**ゴールド**、**ピンク**、**シャンパン**、**キャラメル**、**バーガンディ**、**チャコール**。

- **強さ** — 0 でこの項目はオフです。

## アイライン

種類：**クラシック**、**はね上げ**、**キャット**、**ナチュラル**、**太め**、**ソフト**。

色：**ブラック**、**コーヒー**、**チョコ**、**グレー**、**バーガンディ**、**プラム**、**モーブ**。

- **強さ** — 0 でこの項目はオフです。

## 眉

種類：**ナチュラル**、**ソフト**、**フェザー**、**ミスト**、**アーチ**、**パウダー**、**毛流れ**、**しっかり**、**ストレート**。

色：**ダークブラウン**、**アッシュブラウン**、**ライトブラウン**、**ブラック**。

- **強さ** — 0 でこの項目はオフです。

## まつ毛

種類：**クラシック**、**漫画**、**はね上げ**、**軽やか**、**束感**、**ドール**。

色：**ブラック**、**ブラウン**、**ソフトブラック**。

- **強さ** — 0 でこの項目はオフです。

## カラコン

色：**ヘーゼル**、**アイスブルー**、**モカ**、**オリーブ**、**ダークブラウン**、**モスグリーン**、**サンド**、**ハイライト**、**スレート**。

- **強さ** — 0 でこの項目はオフです。
