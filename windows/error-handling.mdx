## Return values

Most setters return `int`:

| Code | Meaning |
| --- | --- |
| `0` | Success |
| `-1` | Invalid argument |
| `-2` | Not initialized |
| `-3` | License |
| `-4` | Unsupported |
| `-5` | I/O |
| `-6` | No slot |
| `-7` | Process failed |
| `-8` | Out of memory |

`BeautyEffectEngine::Create()` returns `std::shared_ptr`; failure is `nullptr`. `ProcessImage` may return `nullptr` on failure.

```cpp
int ret = engine->SetSmoothing(0.5f);
if (ret != 0) {
    std::cerr << "SetSmoothing failed: " << ret << std::endl;
}
```

## Engine events

Register `on_engine_event` after `Create`. Codes:

| Code | Meaning |
| --- | --- |
| `0` | License success |
| `1` | License failed |
| `100` | Init complete |
| `101` | Init failed |

The `message` string has extra detail on failures.

```cpp
EngineCallbacks cbs;
cbs.on_engine_event = [](int code, const std::string& message) {
    if (code == 1 || code == 101) {
        std::cerr << "engine event " << code << ": " << message << std::endl;
    }
};
engine->SetCallbacks(cbs);
```

## Common failures

### 1. `Create` returns `nullptr`

Typical causes:

- `resource_path` is a directory, missing, or not the `resource.fbd` **file**
- Invalid / inactive `app_id` + `app_key`, or bad `license_token`
- `facebetter.dll` missing or mismatched with `facebetter.lib`
- Online auth cannot reach `/facebetter/v2/auth`

Enable logs **before** `Create`:

```cpp
LogConfig log_cfg;
log_cfg.console_enabled = true;
log_cfg.level = LogLevel::Debug;
BeautyEffectEngine::SetLogConfig(log_cfg);

EngineConfig cfg;
cfg.app_id = "your_app_id";
cfg.app_key = "your_app_key";
cfg.resource_path =
    (std::filesystem::current_path() / "resource" / "resource.fbd").string();

auto engine = BeautyEffectEngine::Create(cfg);
if (!engine) {
    std::cerr << "Create failed — check logs, resource.fbd, and license." << std::endl;
    return -1;
}
```

---

### 2. `facebetter.dll` not found

Windows shows a dialog if the DLL is not on the loader path.

```bat
dir build\facebetter.dll
copy sdk\lib\facebetter.dll build\
```

Or rebuild so CMake copies it next to the executable.

---

### 3. `ProcessImage` returns `nullptr`

Check the input frame, engine pointer, and logs (`-7` process / `-8` OOM on setters).

```cpp
auto input = ImageFrame::CreateWithFile("input.jpg");
if (!input || !input->Data()) {
    std::cerr << "Failed to load input." << std::endl;
    return;
}
input->type = FrameType::Image;
auto output = engine->ProcessImage(input);
if (!output || !output->Data()) {
    std::cerr << "ProcessImage failed." << std::endl;
}
```

---

### 4. Effects look unchanged

2.0 does **not** use `SetBeautyTypeEnabled`. Effects are off at intensity `0`. Reshape / makeup also need a detected face.

```cpp
engine->SetSmoothing(0.5f);
engine->SetReshape(Reshape::FaceThin, 0.3f);
engine->SetLipstick(0.5f);
input->type = FrameType::Video;
```

---

### 5. OpenGL / display

GLFW or `gladLoadGLLoader` can fail on outdated drivers, VMs, or Remote Desktop without GPU.

```cpp
if (!glfwInit()) {
    std::cerr << "GLFW init failed." << std::endl;
    return 1;
}
glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 0);
```

If your app already owns the GL context, set `EngineConfig::external_context = true` and call `ProcessImage` on that thread.

## Debug logs

```cpp
LogConfig log_cfg;
log_cfg.console_enabled = true;
log_cfg.file_enabled = true;
log_cfg.level = LogLevel::Debug;
log_cfg.file_name = "facebetter.log";
BeautyEffectEngine::SetLogConfig(log_cfg);
```

The file is written relative to the current working directory unless you pass an absolute `file_name`.
