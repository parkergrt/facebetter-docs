## FBEngineConfig

```dart
const FBEngineConfig({
  String? appId,
  String? appKey,
  String? licenseToken,
  bool enableLandmarks = false,
  bool externalContext = true,
  String? resourcePath,
});
```

Create with `appId` + `appKey`, or `licenseToken`. If `licenseToken` is non-empty it is used and online `appId` / `appKey` is skipped.

## FBEngine

```dart
static Future<FBEngine> create(FBEngineConfig config)
static String get version
static void setLogConfig({
  bool console = true,
  bool file = false,
  FBLogLevel level = FBLogLevel.info,
  String fileName = '',
})
void dispose()
```

Create one instance with `FBEngine.create`. It is not a process-wide singleton. At most one `externalContext: true` engine can be bound to `processTexture` at a time.

Beauty / reshape / makeup / chroma / blur / `clear*` / `setFilterIntensity` are **synchronous**. Filter, sticker, background **image**, and photo APIs return **`Future`**.

### Skin

`setSmoothing`, `setSmoothingStyle(FBSmoothingStyle)`, `setWhitening`, `setWhiteningStyle(FBWhiteningStyle)`, `setSharpening`, `setRosiness`, `setBeautySkinOnly(bool)` — intensity `[0, 1]`.

### Reshape

`setReshape(FBReshape param, double intensity)` — **`[-1.0, 1.0]`**. Dart names: `FBReshape.faceThin`, `faceVShape`, … `browThickness`. Tables: [Parameter enums](/intro/makeup).

### Body reshape

`setBodyReshape(FBBodyReshape param, double intensity)` — **`[0.0, 1.0]`**. Dart names: `FBBodyReshape.bodySlim` … `torsoLong`. Requires `resource_body.fbd` via `addResourcePack` first. Tables: [Parameter enums](/intro/makeup). Packs: [Optional resource packs](/intro/resource-packs).

### Filter / sticker / VB / chroma

```dart
Future<void> setFilter({String? path, Uint8List? data})

Future<void> setSticker({String? path, Uint8List? data})
```

`path` and `data` are mutually exclusive; exactly one is required. For 3D stickers and body reshape see [Optional resource packs](/intro/resource-packs).

## FBException

Thrown when a native call returns `< 0`.

| `code` | Meaning |
| --- | --- |
| `0` | Success (not thrown) |
| `-1` | Invalid argument |
| `-2` | Not initialized / disposed |
| `-3` | License |
| `-4` | Unsupported |
| `-5` | I/O |
| `-6` | No slot (back-pressure) |
| `-7` | Process failed |
| `-8` | Out of memory |

```dart
} on FBException catch (e) {
  debugPrint('${e.operation} ${e.code} ${e.reason}');
}
```

## Other types

- `FBBitmap` — `width`, `height`, `stride`, `pixels` (RGBA8888 copy)
- `FBLogLevel` — `trace` … `critical`

## Native texture (not Dart)

After `create` with `externalContext: true`, call on the **vendor SDK GL thread**. Only one live engine can be bound at a time; a second `create(externalContext: true)` throws until you `dispose()` the first. Still-image engines (`externalContext: false`) do not bind.

- iOS: `[FacebetterPlugin processTexture:width:height:]`
- Android: `FacebetterPlugin.processTexture(textureId, width, height)`

Returns `0` on failure. Full snippets: [Third-party Integration](/flutter/third-party-integration).
