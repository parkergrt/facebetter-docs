This site documents **SDK 2.0**.

## v2.0.0

2026-09-09

1. **Auth**: Native uses `licenseToken` or `appId` + `appKey`. Web uses `licenseToken` only — fetch the token on your server; never put `appKey` in browser JS
2. **Beauty**: `setSmoothing`, `setWhitening`, `setSharpening`, `setRosiness`, `setBeautySkinOnly`, plus style presets
3. **Reshape**: 26 parameters (`FaceThin` … `BrowThickness`), intensity `[-1.0, 1.0]`
4. **Body reshape**: 7 parameters (`BodySlim` … `BustEnhance`), intensity `[0.0, 1.0]`. Requires optional `resource_body.fbd` via `addResourcePack`. **Pro+**. See [Parameter enums](./makeup) and [Optional resource packs](./resource-packs)
5. **Makeup**: intensity + Style (shape) + Color (tint). See [Parameter enums](./makeup)
6. **Filter / sticker**: `setFilter` / `setSticker` with a `.fbd` path or bytes; 3D stickers use `set3DSticker` (needs `resource_3d.fbd`, **Pro+**). `clearFilter` / `clearSticker` / `clear3DSticker`
7. **Virtual background**: blur, image replace, chroma key
8. **Stats**: `getStats()` — FPS, average process time, session duration
9. **Frame type**: `FrameType.Image` / `FrameType.Video`
10. **Error codes**: `0` success, `-1` invalid argument, `-2` not initialized, `-3` license, `-4` unsupported, `-5` IO, `-6` no slot, `-7` process, `-8` OOM
11. **Flutter**: `FBEngine.create(FBEngineConfig)`. Live video is processed natively via `FacebetterPlugin.processTexture`

**Events** (`onEngineEvent` / Flutter `events`): `0` license OK, `1` license failed, `100` init complete, `101` init failed.
