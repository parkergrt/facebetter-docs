This site documents **SDK 2.0**.

## v2.0.0

2026-09-09

1. **Auth**: Native uses `licenseToken` or `appId` + `appKey`. Web uses `licenseToken` only — fetch the token on your server (or `fetchLicenseToken` for local debug); never put `appKey` in production browser JS
2. **Beauty**: `setSmoothing`, `setWhitening`, `setSharpening`, `setRosiness`, `setBeautySkinOnly`, plus style presets
3. **Reshape**: 26 parameters (`FaceThin` … `BrowThickness`), intensity `[-1.0, 1.0]`
4. **Makeup**: intensity + Style (shape) + Color (tint). See [Parameter enums](./makeup)
5. **Filter / sticker**: `setFilter` / `setSticker` with a `.fbd` path or bytes; `clearFilter` / `clearSticker`
6. **Virtual background**: blur, image replace, chroma key
7. **Stats**: `getStats()` — FPS, average process time, session duration
8. **Frame type**: `FrameType.Image` / `FrameType.Video`
9. **Error codes**: `0` success, `-1` invalid argument, `-2` not initialized, `-3` license, `-4` unsupported, `-5` IO, `-6` no slot, `-7` process, `-8` OOM
10. **Flutter**: `FBEngine.create(FBEngineConfig)`. Live video is processed natively via `FacebetterPlugin.processTexture`

**Events** (`onEngineEvent` / Flutter `events`): `0` license OK, `1` license failed, `100` init complete, `101` init failed.
