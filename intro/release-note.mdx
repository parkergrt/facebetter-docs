This site documents **SDK 2.x**. Latest: **v2.1.0**.

## v2.1.0

2026-09-21

1. Body reshape: slim, waist, legs, shoulders, arms, longer legs, bust, and more. See [Parameter enums](./makeup)
2. 3D stickers (glasses, hats, and other mesh props)
3. Optional resource packs for body reshape and 3D stickers. See [Optional resource packs](./resource-packs)

## v2.0.1

2026-09-15

1. Faster processing on Web and Android

## v2.0.0

2026-09-09

1. New auth: native `licenseToken` or `appId` + `appKey`; Web uses `licenseToken` only (from your server)
2. Skin beauty: smoothing, whitening, sharpening, rosiness, skin-only, plus style presets
3. Face reshape (26 controls)
4. Makeup: intensity, shape, and color. See [Parameter enums](./makeup)
5. LUT filters and 2D stickers (`.fbd`)
6. Virtual background: blur, image replace, chroma key
8. Processing stats (`getStats()`)
