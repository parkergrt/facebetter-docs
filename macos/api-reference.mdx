iOS and macOS share this Objective-C API. macOS-only: `+[FBImageFrame createWithNSImage:]`. Minimum OS: **macOS 10.15**, architectures **x86_64** and **arm64**. Use AppKit (`NSImage`) for stills.

## Logging

### `FBLogLevel`

```objc
typedef NS_ENUM(NSInteger, FBLogLevel) {
  FBLogLevel_Trace = 0,
  FBLogLevel_Debug,
  FBLogLevel_Info,
  FBLogLevel_Warn,
  FBLogLevel_Error,
  FBLogLevel_Critical,
};
```

### `FBLogConfig`

| Property | Type | Description |
| --- | --- | --- |
| `consoleEnabled` | `BOOL` | Console output |
| `fileEnabled` | `BOOL` | File output |
| `level` | `FBLogLevel` | Minimum level |
| `fileName` | `NSString *` | Log path (used when `fileEnabled` is `YES`) |

```objc
FB_OBJC_API @interface FBLogConfig : NSObject
@property(nonatomic, assign) BOOL consoleEnabled;
@property(nonatomic, assign) BOOL fileEnabled;
@property(nonatomic, assign) FBLogLevel level;
@property(nonatomic, copy, nullable) NSString *fileName;
- (instancetype)init;
@end
```

Call `+[FBBeautyEffectEngine setLogConfig:]` **before** `createEngineWithConfig:`. Returns `FBErrorCode` (`0` success, `-1` if `config` is nil).

## Engine configuration

### `FBEngineConfig`

| Property | Type | Description |
| --- | --- | --- |
| `appId` | `NSString *` | Dashboard App ID (online auth) |
| `appKey` | `NSString *` | Dashboard App Key (online auth) |
| `licenseToken` | `NSString *` | License token string, `{token}` JSON, or native `.lic` contents |
| `externalContext` | `BOOL` | Default `NO`. `YES`: use the caller’s OpenGL context |

**Auth priority:** if `licenseToken` is non-empty, validate that token locally and skip `/facebetter/v2/auth`. Otherwise use `appId` + `appKey` for online auth. Bind the app **Bundle ID** in the Dashboard. Command-line tools without a bundle should bind the process name.

```objc
FB_OBJC_API @interface FBEngineConfig : NSObject
@property(nonatomic, copy) NSString *appId;
@property(nonatomic, copy) NSString *appKey;
@property(nonatomic, copy, nullable) NSString *licenseToken;
@property(nonatomic, assign) BOOL externalContext;
- (instancetype)init;
@end
```

### `FBFrameType`

Set on `FBImageFrame.type` before `processImage:`. Not a method argument.

```objc
typedef NS_ENUM(NSInteger, FBFrameType) {
  FBFrameTypeImage = 0,  // stills / NSImage
  FBFrameTypeVideo = 1   // live / camera
};
```

### Virtual background and chroma key

| Method | Description |
| --- | --- |
| `setChromaKey:` | Mask from green / blue / red. Fill is still blur or image. |
| `clearChromaKey` | Restore portrait-segmentation mask; does **not** clear fill |
| `setChromaKeySimilarity:` | Key tightness `[0, 1]` |
| `setChromaKeySmoothness:` | Edge feather `[0, 1]` |
| `setChromaKeyDesaturation:` | Spill suppression `[0, 1]` |
| `setVirtualBackgroundBlur:` | Blur fill `[0, 1]`; `0` clears virtual background |
| `setVirtualBackground:` | png/jpg file path (must be non-empty) |
| `setVirtualBackgroundWithData:` | Encoded png/jpg `NSData` |
| `clearVirtualBackground` | Clear blur and image fill |

```objc
typedef NS_ENUM(NSInteger, FBChromaKeyColor) {

  FBChromaKeyColor_Blue,
  FBChromaKeyColor_Red,
};
```

### Filters and stickers

No register-by-id. Path or bytes; GPU resources are created on the next `processImage:`.

| Method | Description |
| --- | --- |
| `setFilter:` | LUT from `.fbd` path |
| `setFilterWithData:` | LUT from `.fbd` bytes |
| `clearFilter` | Remove LUT |
| `setFilterIntensity:` | `[0, 1]` |
| `setSticker:` | 2D sticker `.fbd` path |
| `setStickerWithData:` | Sticker bytes |
| `addResourcePack:` | Extra capability pack path (`resource_3d.fbd` before `set3DSticker:`, or `resource_body.fbd` before `setBodyReshape:`) |
| `addResourcePackWithData:` | Extra pack bytes |
| `set3DSticker:` | 3D sticker `.fbd` path |
| `set3DStickerWithData:` | 3D sticker bytes |
| `clear3DSticker` | Remove the 3D sticker |
| `clearSticker` | Remove sticker |

Empty path / nil or empty `NSData` → `FBErrorCode_InvalidArgument`.

### Process

```objc
- (FBImageFrame * _Nullable)processImage:(FBImageFrame *)imageFrame;
```

Reads `imageFrame.type`. Output format matches input. Returns `nil` on failure.

## `FBImageFrame`

### Create

| Method | Notes |
| --- | --- |
| `createWithData:width:height:format:` | Raw buffer + `FBImageFormat` |
| `createWithRGBA:width:height:stride:` | |
| `createWithBGRA:width:height:stride:` | Common for AppKit bitmaps |
| `createWithRGB:width:height:stride:` | |
| `createWithBGR:width:height:stride:` | |
| `createWithI420:...` | Y / U / V planes |
| `createWithNV12:...` | Y + UV |
| `createWithNV21:...` | Y + VU |
| `createWithFile:` | png / jpg path |
| `createWithTexture:width:height:stride:` | `GL_TEXTURE_2D` in the current context |
| `createWithNSImage:` | **macOS only** |

### Operations

| Method | Description |
| --- | --- |
| `rotate:` | `FBImageRotation`; returns `FBErrorCode` |
| `mirror:` | `"horizontal"` / `"vertical"` / `"both"`; mutates pixels |
| `setMirror:` | Flag for `processImage:`. `nil` / `@""` clears |
| `convert:` | Returns a new frame in the target `FBImageFormat` |
| `toFile:quality:` | quality `0`–`100` |
| `toFile:` | quality `90` |

Accessors: `width`, `height`, `stride`, `size`, `type`, `data`, `format`, `texture`. YUV: `dataY` / `dataU` / `dataV` / `dataUV` and matching strides.

```objc
typedef NS_ENUM(NSInteger, FBImageFormat) {
  FBImageFormatI420,
  FBImageFormatNV12,
  FBImageFormatNV21,
  FBImageFormatBGRA,
  FBImageFormatRGBA,
  FBImageFormatBGR,
  FBImageFormatRGB,
  FBImageFormatTexture,
};

typedef NS_ENUM(NSInteger, FBImageRotation) {
  FBImageRotation0,
  FBImageRotation90,
  FBImageRotation180,
  FBImageRotation270,
};
```

```objc
FBImageFrame *frame = [FBImageFrame createWithNSImage:image];
frame.type = FBFrameTypeImage;
FBImageFrame *out = [engine processImage:frame];
```
