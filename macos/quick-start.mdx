## Environment Requirements

- **macOS Version**: `macOS 10.15` and above
- **Development Language**: `Objective-C` (AppKit / `NSImage`)
- **Architecture Support**: `x86_64`, `arm64` (Apple Silicon)

## Get Sample Source Code

Clone the [GitHub repository](https://github.com/pixpark/facebetter-sdk) locally, and navigate to the `demo/macos` directory.

```bash
# clone
git clone https://github.com/pixpark/facebetter-sdk.git

# Enter macOS Demo directory
cd facebetter-sdk/demo/macos

# Install dependencies
pod install
```

<Warning>
**Xcode 15+ compilation error**

If you are using **Xcode 15** or later, you might encounter a `Sandbox: rsync.samba deny(1)` error during compilation. This is caused by Xcode's default **User Script Sandboxing**.

**Solution:**
1. Select your **Project** in Xcode.
2. Navigate to the **Build Settings** tab.
3. Search for `ENABLE_USER_SCRIPT_SANDBOXING`.
4. Change its value from `Yes` to **`No`**.
</Warning>

## Configure Application Information and Keys

### Bind Application Bundle ID

Follow [Bind Application Information](/intro/enable-service#bind-application-information) to bind your macOS application Bundle ID in the console, for example: `com.example.app`.

### Get credentials

Follow [Get AppID and AppKey](/intro/enable-service#get-appid-and-appkey) to obtain `appId` and `appKey`. Open `demo/macos/FBExampleObjc/BeautyCameraViewController.m` and set credentials on `FBEngineConfig`.

```objc
FBEngineConfig *engineConfig = [[FBEngineConfig alloc] init];
engineConfig.appId = @"your appId";
engineConfig.appKey = @"your appKey";
// Preferred: licenseToken (license token, {token} JSON, or .lic contents)
// engineConfig.licenseToken = @"your license token";

self.beautyEffectEngine = [FBBeautyEffectEngine createEngineWithConfig:engineConfig];
```

<Tip>
If `licenseToken` is non-empty, the SDK validates that token locally and does **not** call `/facebetter/v2/auth` with `appId` / `appKey`. See [Auth & License](/intro/license).
</Tip>
