## Choose the right frame type

Set `FBImageFrame.type` **before** `processImage:`. There is no process-mode argument on the engine.

- **`FBFrameTypeVideo` (`1`)**: camera preview, live, calls — lower latency.
- **`FBFrameTypeImage` (`0`)**: still photos / `NSImage` — higher quality.

```objc
input.type = FBFrameTypeVideo;
FBImageFrame *output = [engine processImage:input];
```

## Parameter ranges

- Skin / makeup / filter intensity: `[0.0, 1.0]`. `0` turns that effect off.
- Reshape (`setReshape:intensity:`): **`[-1.0, 1.0]`**. `0` is off. Positive and negative are opposite directions.

Start low on live video. Full enum meanings: [Parameter enums](/intro/makeup).

```objc
[engine setSmoothing:0.25f];
[engine setSmoothingStyle:FBSmoothingStyle_Natural];
[engine setWhitening:0.15f];
[engine setReshape:FBReshape_FaceThin intensity:0.12f];
[engine setBeautySkinOnly:YES];
```

## One engine, one serial queue

`createEngineWithConfig:` returns an **instance**, not a process-wide singleton. Keep one engine per session and call it from a **serial** queue (or the GL thread when `externalContext = YES`).

```objc
@interface BeautyEngineManager : NSObject
@property (nonatomic, strong, readonly) FBBeautyEffectEngine *engine;
@property (nonatomic, strong, readonly) dispatch_queue_t queue;
+ (instancetype)sharedManager;
@end

@implementation BeautyEngineManager

+ (instancetype)sharedManager {
  static BeautyEngineManager *instance;
  static dispatch_once_t onceToken;
  dispatch_once(&onceToken, ^{
    instance = [[BeautyEngineManager alloc] init];
  });
  return instance;
}

- (instancetype)init {
  self = [super init];
  if (self) {
    _queue = dispatch_queue_create("com.facebetter.process", DISPATCH_QUEUE_SERIAL);
    FBEngineConfig *config = [[FBEngineConfig alloc] init];
    config.appId = @"your_app_id";
    config.appKey = @"your_app_key";
    _engine = [FBBeautyEffectEngine createEngineWithConfig:config];
  }
  return self;
}

- (void)process:(FBImageFrame *)input completion:(void (^)(FBImageFrame * _Nullable))completion {
  dispatch_async(self.queue, ^{
    input.type = FBFrameTypeVideo;
    FBImageFrame *output = [self.engine processImage:input];
    dispatch_async(dispatch_get_main_queue(), ^{
      completion(output);
    });
  });
}

@end
```

Do not process frames on the main thread except for tiny stills. Do not share one engine across concurrent queues.

## Memory

- Prefer ARC. Drop `FBImageFrame` references when a frame is done.
- Reuse camera pixel buffers (NV12 / BGRA) instead of converting every frame to RGBA.
- Call `setFilter:` / `setSticker:` once; textures load on the next `processImage:`.
- Use `clearFilter`, `clearSticker`, `clearVirtualBackground`, and `clearChromaKey` instead of creating a second engine.

## External OpenGL

When the AppKit view already owns a GL context:

1. Set `config.externalContext = YES`.
2. Create the engine **on that GL thread**.
3. Wrap the texture with `createWithTexture:width:height:stride:`.
4. Read the output with `[output texture]`.

## Monitor with `getStats`

```objc
FBEngineStats *stats = [engine getStats];
NSLog(@"fps=%.1f avg=%.2fms session=%.1fs",
      stats.fps, stats.avgProcessTimeMs, stats.sessionTimeS);
```

Aim for `avgProcessTimeMs` under ~33 ms at 30 fps. Desktop GPUs can run higher resolutions; still drop effects if the UI hitchs.

## Lifecycle (AppKit)

Hold the engine on the `NSViewController` (or a session object). Stop capture in `viewWillDisappear`. Pause when the window miniaturizes. Nil the engine in `dealloc` / `applicationWillTerminate`.

```objc
- (void)viewWillDisappear {
  [super viewWillDisappear];
  [self.captureSession stopRunning];
}

- (void)dealloc {
  self.beautyEffectEngine = nil;
}
```

Use `__weak` in `FBEngineCallbacks` blocks.

## macOS capture and display

- Build frames with `createWithNV12:...`, `createWithBGRA:...`, or `createWithNSImage:`.
- Front camera / user-facing preview: `setMirror:@"horizontal"`.
- Retina: process in pixel size (`backingScaleFactor`), not point size.
- Camera: `NSCameraUsageDescription`. Sandboxed apps need **Outgoing Connections** for online auth.
- User-picked `.fbd` / background images: security-scoped URLs.

## Testing

- Bind the Mac app Bundle ID (or process name for CLI tools).
- Use a real `appId` / `appKey` or `licenseToken`.
- Cover `FBFrameTypeImage` + `createWithNSImage:` and `FBFrameTypeVideo`.
- Assert setter codes are `FBErrorCode_Success`. Universal Binary: test Intel and Apple Silicon.
