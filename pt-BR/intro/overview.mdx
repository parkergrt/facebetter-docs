O Beauty Effect SDK processa imagens e vídeo ao vivo no Android, iOS, Web, macOS, Windows e Linux. O processamento usa aceleração por GPU. As enumerações estão em [Enums de parâmetros](./makeup). Os planos estão em [Planos e recursos](./pricing).

## Recursos principais

### Pele

Suavização, clareamento, tom rosado e remoção de manchas. Cada um vai de `[0.0, 1.0]` (`0` desliga).

- A suavização tem três estilos: Natural, Texture e Smooth. O padrão é Natural.
- O clareamento tem cinco tons: Cold white, Pink white, Warm white, Wheat e Tan. O padrão é Cold white.
- `setBeautySkinOnly` limita a beleza de pele à região de pele segmentada.
- A remoção de manchas é independente da suavização. Ela usa a região de pele, não os pontos do rosto.

### Correção de cor

Controles de quadro inteiro. Não usam pontos faciais nem a máscara de pele, e ficam independentes do clareamento, do tom rosado e dos filtros LUT.

Brilho, contraste, saturação, temperatura e matiz vão de `[-1.0, 1.0]` (`0` é neutro). A nitidez vai de `[0.0, 1.0]` (`0` desliga) e aumenta o contraste local.

### Dentes

`setTeethWhiten` vai de `[0.0, 1.0]` (`0` desliga). Clareia os dentes com a boca aberta e não altera uma boca fechada.

### Remodelagem facial

26 controles, cada um em `[-1.0, 1.0]`. `0` mantém a proporção original. Positivo e negativo são direções opostas. Um quadro pode remodelar e maquiar no máximo **5 rostos**. A lista está em [Enums de parâmetros](./makeup). Exige **Pro** (Free: teste com marca d'água). Veja [Planos e recursos](./pricing).

### Remodelagem corporal

Nove controles, cada um em `[0.0, 1.0]` (`0` desliga). Não há direção negativa.

Sete acompanham o corpo: corpo inteiro, cintura, pernas, ombros, braços, alongar pernas e busto. Esses precisam do pacote opcional `resource_body.fbd`. Veja [Pacotes de recursos opcionais](./resource-packs).

`LegStretch` e `TorsoLong` usam só pontos faciais e não precisam desse pacote.

Exige **Pro+** (Free: teste com marca d'água). Veja [Planos e recursos](./pricing).

### Maquiagem

Batom, blush, contorno, sombra, delineador, sobrancelhas, cílios e lentes de contato. A intensidade é `[0.0, 1.0]`. Forma e cor são ajustadas à parte, com duas exceções:

- O batom é uma máscara de lábios mais uma cor. Há seis cores e não há troca de estilo.
- Contorno e lentes trocam uma textura e não recebem tinta. Há nove cores de lente.

Vários itens podem ficar ativos ao mesmo tempo. As enumerações estão em [Enums de parâmetros](./makeup). Exige **Pro** (Free: teste com marca d'água).

### Filtros

A biblioteca traz **51** LUTs em quatro grupos: retrato, moderno, comida e paisagem. A intensidade é ajustável. Um filtro próprio é um arquivo `.fbd` passado a `setFilter`. Exige **Pro** (Free: teste com marca d'água).

### Adesivos

- **Adesivos de tela** ficam em um lugar fixo do quadro.
- **Adesivos de rosto** seguem os pontos faciais.
- **Adesivos 3D** são malhas como óculos, chapéus e máscaras. Precisam de `resource_3d.fbd`. Veja [Pacotes de recursos opcionais](./resource-packs).

Os recursos são arquivos `.fbd`. Aplique um adesivo 2D com `setSticker` e um 3D com `set3DSticker` (caminho ou bytes). Remova com `clearSticker` / `clear3DSticker`. O arquivo novo vale no próximo quadro processado. Exige **Pro+** (Free: teste com marca d'água).

### Fundo virtual

- **Desfoque**: `setVirtualBackgroundBlur`. `0` desliga.
- **Imagem**: `setVirtualBackground` com um caminho ou bytes JPEG ou PNG.
- **Chroma key**: verde, azul ou vermelho como máscara. Similaridade, suavização da borda e supressão de vazamento são controles separados. Sem desfoque nem imagem, a área recortada fica transparente.
- **Contorno do sujeito**: um traço ao redor do recorte. Ele aparece quando desfoque, troca de imagem ou chroma key está ligado.

Exige **Pro+** (Free: teste com marca d'água).

## Formatos de entrada

| Tipo | Formatos |
| --- | --- |
| Imagem estática | JPEG, PNG |
| Quadro de vídeo | YUV I420, NV12, NV21, RGB, RGBA, BGR, BGRA |
| Textura de GPU | Textura OpenGL / OpenGL ES |

`ImageFrame` converte entre esses formatos de pixel.

## Plataformas

| Plataforma | Requisito |
| --- | --- |
| Android | 7.0+ (API 24) |
| iOS | 12.0+ |
| Web | Chrome 57+, Firefox 52+, Safari 11+, Edge 16+. A câmera precisa de HTTPS ou `localhost` |
| macOS | 10.15+ |
| Windows | Windows 10+ |
| Linux | Ubuntu 22.04+ |

| Linguagem | Onde |
| --- | --- |
| Java / Kotlin | Android |
| Objective-C / Swift | iOS, macOS |
| C++ | Windows, Linux, macOS |
| JavaScript | SDK de navegador. Não coloque `appKey` na página. Node serve só para trocar o token de licença. Veja [Autenticação e licença](./license). |
