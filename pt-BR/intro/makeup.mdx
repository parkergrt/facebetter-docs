<Note>
Esta página corresponde ao SDK **2.0**. Os valores numéricos são idênticos em C++, Objective-C, Java, JavaScript e Dart.
</Note>

A maquiagem tem três controles:

1. **Intensidade** — `SetLipstick` / `SetBlush` / `SetContour` / `SetEyeShadow` / `SetEyeLiner` / `SetEyebrow` / `SetEyelash` / `SetPupil`, faixa `[0.0, 1.0]`. `0` desliga o efeito.
2. **Formato** — troca a textura da máscara (`SetBlushStyle`, `SetContourStyle`, `SetEyeShadowStyle`, …).
3. **Cor** — tinge o formato atual (`SetLipstickColor`, `SetBlushColor`, `SetEyeShadowColor`, …). **Pupil** e **Contour** não recebem tintura; alterá-los troca a textura.

| C++ / JS | Java | Objective-C | Dart |
| --- | --- | --- | --- |
| `LipstickColor::Rouge` | `LipstickColor.ROUGE` | `FBLipstickColor_Rouge` | `FBLipstickColor.rouge` |

## Clareamento (`WhiteningStyle`)

Usado com `SetWhiteningStyle`. A intensidade continua sendo `SetWhitening`. Padrão: `ColdWhite`.

| Valor | Nome | Significado |
| --- | --- | --- |
| 0 | `ColdWhite` | Branco frio |
| 1 | `PinkWhite` | Branco rosado |
| 2 | `WarmWhite` | Branco quente |
| 3 | `Wheat` | Trigo |
| 4 | `Tan` | Bronzeado |

## Suavização (`SmoothingStyle`)

Usado com `SetSmoothingStyle`. A intensidade continua sendo `SetSmoothing`. Padrão: `Natural`.

| Valor | Nome | Significado |
| --- | --- | --- |
| 0 | `Natural` | Mantém os poros |
| 1 | `Texture` | Mais limpo, ainda texturizado |
| 2 | `Smooth` | Pele cremosa |

## Remodelagem facial (`Reshape`)

Usado com `SetReshape(param, intensity)`. A faixa é **`[-1.0, 1.0]`**. `0` desliga. Positivo e negativo são direções opostas (por exemplo FaceThin: afinar / bochechas mais cheias).

| Valor | Nome | Positivo / negativo |
| --- | --- | --- |
| 0 | `FaceThin` | Afinar o rosto / bochechas mais cheias |
| 1 | `FaceVShape` | Formato em V / mandíbula mais quadrada |
| 2 | `FaceNarrow` | Estreitar / alargar o rosto |
| 3 | `FaceShort` | Encurtar / alongar o rosto |
| 4 | `Cheekbone` | Afinar / expandir as maçãs do rosto |
| 5 | `Jawbone` | Afinar / expandir a mandíbula |
| 6 | `Chin` | Alongar / encurtar o queixo |
| 7 | `NoseSlim` | Afinar / alargar o nariz |
| 8 | `EyeSize` | Aumentar / diminuir os olhos |
| 9 | `EyeDistance` | Afastar / aproximar os olhos |
| 10 | `FaceSmall` | Diminuir / aumentar o rosto |
| 11 | `Forehead` | Testa mais cheia / mais baixa |
| 12 | `NoseLong` | Alongar / encurtar o nariz |
| 13 | `Philtrum` | Encurtar / alongar o filtro |
| 14 | `MouthSize` | Aumentar / diminuir a boca |
| 15 | `MouthPosition` | Baixar / subir a boca |
| 16 | `MouthSmile` | Sorriso / cantos para baixo |
| 17 | `LipThickness` | Lábios mais grossos / mais finos |
| 18 | `EyeRound` | Olhos mais redondos / mais estreitos |
| 19 | `EyePosition` | Baixar / subir os olhos |
| 20 | `EyeAngle` | Canto externo para cima / para baixo |
| 21 | `EyeCornerOpen` | Abrir / fechar os cantos dos olhos |
| 22 | `LowerEyelid` | Baixar / levantar a pálpebra |
| 23 | `BrowPosition` | Subir / baixar as sobrancelhas |
| 24 | `BrowDistance` | Afastar / aproximar as sobrancelhas |
| 25 | `BrowThickness` | Sobrancelhas mais grossas / mais finas |

Os nomes em Java são `SNAKE_CASE` (`FACE_THIN`, `FACE_V_SHAPE`, …). Objective-C usa `FBReshape_FaceThin`. Dart usa `FBReshape.faceThin`.

## Blush

Formato via `BlushStyle` (troca a textura). Cor via `BlushColor` (tintura). Formato padrão `SunKissed`, cor padrão `CoralPink`.

| Valor | `BlushStyle` | Significado |
| --- | --- | --- |
| 0 | `SunKissed` | Nas maçãs do rosto e no nariz |
| 1 | `Igari` | Faixa de blush “bêbado” no nariz |
| 2 | `Soft` | Suave nas duas bochechas |
| 3 | `Apple` | Maçãs do rosto redondas |
| 4 | `Classic` | Dois pontos clássicos |
| 5 | `Doll` | Bochechas + ponta do nariz |
| 6 | `Rose` | Rosa nas duas bochechas |

| Valor | `BlushColor` | Significado |
| --- | --- | --- |
| 0 | `CoralPink` | Rosa coral |
| 1 | `DustyRose` | Rosa empoeirado |
| 2 | `VividRed` | Vermelho puro |
| 3 | `Berry` | Berry |
| 4 | `SunsetOrange` | Laranja pôr do sol |

## Contorno (`ContourStyle`)

Mapa Overlay em cinza médio: mais claro que 128 destaca, mais escuro contorna. Troca a textura, sem tintura. Padrão: `Natural`.

| Valor | Nome | Significado |
| --- | --- | --- |
| 0 | `Natural` | Contorno leve do dia a dia |
| 1 | `Sculpt` | Escultura mais forte |
| 2 | `Glow` | Prioriza o highlight |
| 3 | `Slim` | Afina as maçãs do rosto |
| 4 | `Nose` | Definição do nariz |
| 5 | `Glam` | Pontos de highlight |
