## Requisitos de ambiente

- **Versão do iOS**: `iOS 12.0` ou superior
- **Linguagem de desenvolvimento**: `Objective-C`
- **Arquiteturas suportadas**: `arm64`

## Obter o código-fonte do exemplo

Clone o [repositório GitHub](https://github.com/pixpark/facebetter-sdk) localmente e navegue até o diretório `demo/ios`.

```bash
# clone
git clone https://github.com/pixpark/facebetter-sdk.git

# Enter iOS Demo directory
cd facebetter-sdk/demo/ios

# Install dependencies
pod install
```

<Warning>
**Erro de compilação no Xcode 15+**

Se você usa **Xcode 15** ou posterior, pode encontrar o erro `Sandbox: rsync.samba deny(1)` durante a compilação. Isso é causado pelo **User Script Sandboxing** padrão do Xcode.

**Solução:**
1. Selecione o **Project** no Xcode.
2. Vá até a aba **Build Settings**.
3. Pesquise `ENABLE_USER_SCRIPT_SANDBOXING`.
4. Altere o valor de `Yes` para **`No`**.
</Warning>

## Configurar informações do aplicativo e chaves

### Vincular o Bundle ID do aplicativo

Siga [Vincular informações do aplicativo](/pt-BR/intro/enable-service#bind-application-information) para vincular o Bundle ID do aplicativo iOS no console, por exemplo: `com.example.app`.

### Obter credenciais

Siga [Obter AppID e AppKey](/pt-BR/intro/enable-service#get-appid-and-appkey) para obter `appId` e `appKey`. Abra `demo/ios/FBExampleObjc/CameraViewController.m` e defina as credenciais em `FBEngineConfig`.

```objc
FBEngineConfig *engineConfig = [[FBEngineConfig alloc] init];
engineConfig.appId = @"your appId";
engineConfig.appKey = @"your appKey";
// Preferred: licenseToken (license token, {token} JSON, or .lic contents)
// engineConfig.licenseToken = @"your license token";

self.beautyEffectEngine = [FBBeautyEffectEngine createEngineWithConfig:engineConfig];
```

<Tip>
Se `licenseToken` não estiver vazio, o SDK valida esse token localmente e **não** chama `/facebetter/v2/auth` com `appId` / `appKey`. Veja [Autenticação e licença](/pt-BR/intro/license).
</Tip>
