O plugin Facebetter Effect Creator para Figma é uma ferramenta prática pensada para criar adesivos e efeitos de maquiagem para o SDK Facebetter. O objetivo é simplificar o processo de criação de adesivos e maquiagem. Com este plugin, você conclui diretamente no Figma o design do adesivo, a vinculação aos landmarks do rosto, a configuração de atributos e a exportação da prévia 3D.

## Login e configurações de idioma
O plugin precisa estar autenticado antes de ser usado. Você pode entrar com uma conta Facebetter ou e-mail, ou usar contas sociais como Google ou GitHub.

1.  **Iniciar o plugin**: execute o plugin Facebetter Effect Creator no Figma.
2.  **Login**: suporta login com Google, GitHub ou e-mail.
3.  **Troca de idioma**: clique no ícone de menu suspenso no topo da interface para alternar entre **chinês simplificado** e **inglês**.

## Instalar o plugin
Clique neste link: [Plugin](https://www.figma.com/community/plugin/1591037386605818409/facebetter-effect-creator), ou pesquise "Facebetter Effect Creator" no Figma, clique em "Open In" para abrir o plugin em um documento existente ou em um documento de design recém-criado. Recomenda-se um documento em branco novo.
