Os cinco primeiros controles são centralizados. 0 deixa aquele ajuste igual. Dá para arrastar para os dois lados.

Redefinir nesta página devolve estes controles aos valores iniciais.
Como o painel segue a fonte selecionada: [Ajustar efeitos](/pt-BR/obs/effects).

## Correção básica

- **Brilho** — Mais claro ou mais escuro.
- **Contraste** — Mais ou menos diferença entre claro e escuro.
- **Saturação** — Mais ou menos cor.
- **Temperatura** — Para o amarelo fica mais quente; para o azul, mais frio.
- **Matiz** — Para o verde ou para o magenta.
