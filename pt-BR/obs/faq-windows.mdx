## O Facebetter não está no painel nem na lista de filtros

Use o OBS Studio 28 ou posterior, 64 bits. Depois de copiar a pasta, feche o OBS por completo e abra de novo.

O plugin não fica em `%APPDATA%\obs-studio\`. Confirme que estes dois arquivos existem, com estes nomes:

```text
C:\ProgramData\obs-studio\plugins\obs-facebetter\bin\64bit\obs-facebetter.dll
C:\ProgramData\obs-studio\plugins\obs-facebetter\bin\64bit\facebetter.dll
```

Mantenha a pasta `data` ao lado de `bin`. Veja [Instalar no Windows](/pt-BR/obs/install-windows).

## Os controles estão cinza e não se movem

O filtro ainda não está em uma fonte. O painel diz que é preciso adicionar um filtro para ajustar. Clique com o botão direito na fonte → Filtros → + → Facebetter Beauty. Dá para clicar nos títulos das páginas para ver o que há. Os controles liberam depois que o filtro é adicionado. Veja [Entrar e adicionar o filtro](/pt-BR/obs/login).

## O filtro foi adicionado, mas a prévia não muda

Confira se o interruptor no topo do painel está ligado e se o menu de fonte é a fonte que você está vendo. Se todos os controles estão em 0, a imagem parece a original. Os efeitos de corpo precisam que a pessoa ocupe mais do quadro. Um plano só do rosto quase não muda. O que cada página faz está em [Ajustar efeitos](/pt-BR/obs/effects).
