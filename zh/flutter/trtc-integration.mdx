<Note>
SDK **2.0.0**。Dart 只设置美颜参数。每一帧视频都留在原生 GL 线程，通过 `FacebetterPlugin.processTexture` 处理。
</Note>

```
Flutter（Dart）                         原生 GL 线程
FBEngine.create(externalContext: true)
engine.setSmoothing / setReshape  →    TRTC onProcessVideoFrame
await engine.setFilter                 FacebetterPlugin.processTexture(tex, w, h)
engine.dispose()                       dst.textureId = out
```

不要在这台引擎上调用 `processFile` / `processImageBytes` / `processImageFile` / `processImageToUiImage`。那些接口需要 `externalContext: false`，并且要用另一台引擎。

## 前置条件

- 工程里已接入 `tencent_trtc_cloud`（或原生 TRTC）
- `facebetter_flutter: ^2.0.0`
- 有效的 `appId` / `appKey` 或 `licenseToken` — [授权与许可证](/zh/intro/license)

打开 TRTC 自定义前处理时指定 **Texture2D + Texture buffer**，不要走 YUV / PixelBuffer。

## 1. 在 Dart 里创建引擎

必须在打开自定义前处理**之前**创建。`externalContext` 默认为 `true`，接 TRTC **必须保持 true**。

```dart
import 'package:facebetter_flutter/facebetter_flutter.dart';

FBEngine.setLogConfig(console: true, level: FBLogLevel.info);

final engine = await FBEngine.create(const FBEngineConfig(
  appId: 'your_app_id',
  appKey: 'your_app_key',
  externalContext: true,
  enableLandmarks: false,
));

engine.setSmoothing(0.8);
engine.setWhitening(0.5);
engine.setReshape(FBReshape.faceThin, 0.3);
engine.setLipstick(0.4);
await engine.setFilter(path: '/path/to/filter.fbd');
```

滑条回调可以直接调同步 setter：

```dart
onChanged: (v) => engine.setSmoothing(v),
```

然后打开 TRTC 自定义前处理（方法名随 TRTC Flutter 插件版本可能略有差异）：

```dart
await trtcCloud.enableCustomVideoProcess(true);
```

## 2. iOS — 在 `onProcessVideoFrame` 里喂纹理

```objc
#import <facebetter_flutter/FacebetterPlugin.h>

- (uint32_t)onProcessVideoFrame:(TRTCVideoFrame *)srcFrame
                        dstFrame:(TRTCVideoFrame *)dstFrame {
  uint32_t out = [FacebetterPlugin processTexture:srcFrame.textureId
                                            width:srcFrame.width
                                           height:srcFrame.height];
  if (out != 0) {
    dstFrame.textureId = out;
  }
  return 0;
}
```

若使用 `tencent_trtc_cloud` 的 `ITXCustomBeautyProcesser`，像素格式仍选 **Texture2D / Texture**，在 `onProcessVideoFrame` 里调用同一个 `processTexture`。工厂注册必须在 `GeneratedPluginRegistrant.register(with:)` **之后**。

## 3. Android — 同样的回调，Kotlin

```kotlin
import net.pixpark.facebetter.flutter.FacebetterPlugin

override fun onProcessVideoFrame(
    srcFrame: TRTCCloudDef.TRTCVideoFrame,
    dstFrame: TRTCCloudDef.TRTCVideoFrame,
): Int {
    val out = FacebetterPlugin.processTexture(
        srcFrame.texture.textureId,
        srcFrame.width,
        srcFrame.height,
    )
    if (out != 0) {
        dstFrame.texture.textureId = out
    }
    return 0
}
```

`processTexture` 必须在**当前 GL 线程**调用，不要切到 UI isolate。

## 4. 销毁

1. `enableCustomVideoProcess(false)`（或先退房）
2. `engine.dispose()`

```dart
await trtcCloud.enableCustomVideoProcess(false);
engine.dispose();
```

## 静图 vs 实时视频

| | TRTC 引擎 | 静图引擎 |
| --- | --- | --- |
| `externalContext` | `true`（默认） | `false` |
| 帧 | 原生 `processTexture` | Dart `processFile` / `processImageBytes` / … |
| 混用 | 不要调静图接口 | 不要用于 TRTC |

## 不要做的事

- 不要从 Dart 每帧传像素或 texture id — Flutter 与 TRTC 的 GL 上下文不能和 Dart 共用。
- 不要在非 GL 线程调用 `processTexture`。
- 不要把 `FBEngine` 当成进程级单例。用 `FBEngine.create` 创建，通话结束时 `dispose()`。
