<Note>
本文档对应 SDK **2.0.0**。引擎类是 **`FBEngine`**（不是单例）。鉴权：[授权与许可](/zh/intro/license)。枚举：[参数枚举](/zh/intro/makeup)。
</Note>

## 环境要求

- **Flutter** `>= 3.24` / **Dart** `>= 3.5`
- **iOS** 12.0+
- **Android** minSdk **24**
- 原生 Facebetter SDK **2.0**（由插件带入）

## 安装

```yaml
dependencies:
  facebetter_flutter: ^2.0.0
```

```bash
flutter pub get
cd ios && pod install && cd ..
```

## 获取示例源码

```bash
git clone https://github.com/pixpark/facebetter-sdk.git
cd facebetter-sdk/demo/flutter
flutter create --org net.pixpark --project-name fbexample .
```

Demo 目录只保留业务代码，`flutter create` 会生成 `ios/` 和 `android/`。

## 绑定标识并获取密钥

在控制台绑定：

- **iOS**：Bundle ID（例如 `net.pixpark.fbexample`）
- **Android**：Application ID（例如 `net.pixpark.fbexample`）

复制 `appId` / `appKey`，或以 `licenseToken` 传入（服务端下发的短时 token，或联系销售获取的离线 `.lic`）。见 [订阅服务](/zh/intro/enable-service) 与 [授权与许可](/zh/intro/license)。

## 创建引擎

修改 `lib/main.dart`。日志必须在 `create` **之前**配置：

```dart
import 'package:facebetter_flutter/facebetter_flutter.dart';

FBEngine.setLogConfig(console: true, level: FBLogLevel.info);

final engine = await FBEngine.create(FBEngineConfig(
  appId: 'your_app_id',
  appKey: 'your_app_key',
  // 或 licenseToken: '...',
  enableLandmarks: false,
  externalContext: true, // 默认值；接第三方实时前处理必须为 true
  resourcePath: null,    // 由插件定位 resource.fbd
));

engine.setSmoothing(0.8);
engine.dispose();
```

<Tip>
`externalContext: true`（默认）复用调用方 GL 上下文，接第三方实时前处理必须如此。静图接口需要**另一台**引擎且 `externalContext: false`。同一实例不要混用两种模式。
</Tip>

## 运行

```bash
flutter devices
flutter run -d <device-id>
```
