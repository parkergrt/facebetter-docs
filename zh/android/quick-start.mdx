## 环境要求

- **Android**：7.0（API 24）及以上
- **开发语言**：Java
- **架构**：`armeabi-v7a`、`arm64-v8a`
- **SDK**：Facebetter **2.0.0**（`net.pixpark:facebetter:2.0.0`）

## 获取示例源码

克隆 [GitHub 仓库](https://github.com/pixpark/facebetter-sdk)，用 Android Studio 打开 `demo/android`。

```bash
git clone https://github.com/pixpark/facebetter-sdk.git
```

## 绑定包名与凭证

### 绑定应用包名

按 [订阅与凭证](/zh/intro/enable-service#绑定应用信息) 在控制台绑定 Android **应用包名**，例如 `com.example.app`。

### 创建引擎

按 [订阅与凭证](/zh/intro/enable-service#获取-appid-和-appkey) 复制 `appId` / `appKey`，或使用 `licenseToken`。打开 Demo 相机 Activity，在 `new BeautyEffectEngine(...)` 之前设置 `EngineConfig`。

**在线鉴权**（`appId` + `appKey` → `/facebetter/v2/auth`）：

```java
BeautyEffectEngine.EngineConfig config = new BeautyEffectEngine.EngineConfig();
config.appId = "your appId";
config.appKey = "your appKey";
mBeautyEngine = new BeautyEffectEngine(this, config);
```

**Token**（许可证 token、`{token}` JSON，或离线 `.lic` 全文）。`licenseToken` 非空时优先使用，SDK **不会**再用 `appId` / `appKey` 请求网络：

```java
BeautyEffectEngine.EngineConfig config = new BeautyEffectEngine.EngineConfig();
config.licenseToken = "/* 许可证 token、{token} JSON，或 .lic 全文 */";
mBeautyEngine = new BeautyEffectEngine(this, config);
```

<Tip>
鉴权方式与离线 `.lic` 说明见 [授权认证](/zh/intro/license)。
</Tip>

在 Android Studio 中 Sync Gradle，选择真机或模拟器后运行。
