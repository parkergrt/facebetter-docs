美颜 setter 返回 `int`，请与 `ErrorCode` 比较。构造引擎和 `processImage` 还可能抛异常或返回 `null`。

## ErrorCode

```java
public final class ErrorCode {
  public static final int SUCCESS = 0;
  public static final int INVALID_ARGUMENT = -1;
  public static final int NOT_INITIALIZED = -2;
  public static final int LICENSE = -3;
  public static final int UNSUPPORTED = -4;
  public static final int IO = -5;
  public static final int NO_SLOT = -6;
  public static final int PROCESS = -7;
  public static final int OUT_OF_MEMORY = -8;
}
```

| 值 | 常量 | 常见原因 |
| --- | --- | --- |
| `0` | `SUCCESS` | 调用成功 |
| `-1` | `INVALID_ARGUMENT` | 空路径、空 `byte[]`、`null` 回调等 |
| `-2` | `NOT_INITIALIZED` | 引擎未初始化，或已 `release()` |
| `-3` | `LICENSE` | Token / 在线鉴权被拒绝 |
| `-4` | `UNSUPPORTED` | 格式或功能不可用 |
| `-5` | `IO` | 找不到 `.fbd`、图片不可读、日志路径异常 |
| `-6` | `NO_SLOT` | 资源达到上限 |
| `-7` | `PROCESS` | 帧处理失败 |
| `-8` | `OUT_OF_MEMORY` | 内存不足 |

<Note>
**`-1` 表示参数无效。`-2` 表示引擎未初始化。**
</Note>

```java
int ret = engine.setSmoothing(0.5f);
if (ret != ErrorCode.SUCCESS) {
    Log.e(TAG, "setSmoothing 失败: " + ret);
}
```

## 构造引擎

`new BeautyEffectEngine(context, config)` 在以下情况抛出 `IllegalArgumentException`：

- `context` 或 `config` 为 `null`
- `config.isValid()` 为 `false`（没有 `licenseToken`，且缺少 `appId` / `appKey`）

构造函数 **不会** 返回 `null`。

```java
BeautyEffectEngine.EngineConfig config = new BeautyEffectEngine.EngineConfig();
config.appId = "your_app_id";
config.appKey = "your_app_key";
// config.licenseToken = "...";

BeautyEffectEngine engine;
try {
    engine = new BeautyEffectEngine(this, config);
} catch (IllegalArgumentException e) {
    Log.e(TAG, "EngineConfig 无效", e);
    return;
}
```

授权与资源初始化仍可能异步失败。请订阅引擎事件：

```java
EngineCallbacks callbacks = new EngineCallbacks();
callbacks.onEngineEvent = (code, message) -> {
    if (code == EngineEventCode.LICENSE_VALIDATION_FAILED
        || code == EngineEventCode.INITIALIZATION_FAILED) {
        Log.e(TAG, "引擎事件 " + code + ": " + message);
    }
};
engine.setCallbacks(callbacks);
```

| `EngineEventCode` | 值 |
| --- | --- |
| `LICENSE_VALIDATION_SUCCESS` | `0` |
| `LICENSE_VALIDATION_FAILED` | `1` |
| `INITIALIZATION_COMPLETE` | `100` |
| `INITIALIZATION_FAILED` | `101` |

鉴权排查见 [授权认证](/zh/intro/license)。务必在构造 **之前** 打开日志，见 [实现美颜](/zh/android/implement-beauty)。

## processImage

```java
if (input == null || !input.isValid()) {
    Log.e(TAG, "输入帧无效");
    return null;
}
if (input.type == null) {
    input.type = ImageFrame.FrameType.VIDEO;
}

ImageFrame output;
try {
    output = engine.processImage(input);
} catch (IllegalArgumentException e) {
    Log.e(TAG, "processImage 拒绝了该帧", e);
    return null;
}
if (output == null) {
    Log.e(TAG, "processImage 返回 null（引擎已释放或原生失败）");
    return null;
}
```

- 输入为 `null` 或 `type` 为 `null` → `IllegalArgumentException`
- 引擎已 `release()` → 返回 `null`（不抛异常）
- 在 `finally` 中同时 `release()` 输入和输出

```java
ImageFrame output = null;
try {
    input.type = ImageFrame.FrameType.VIDEO;
    output = engine.processImage(input);
    return output;
} finally {
    if (input != null) {
        input.release();
    }
}
```

若对输出做了 `convert` / `toBitmap`，额外产生的帧也要释放。

## 滤镜、贴纸、虚拟背景

空路径或空 `byte[]` 返回 `ErrorCode.INVALID_ARGUMENT`。文件不存在通常返回 `ErrorCode.IO`。

```java
int ret = engine.setFilter(fbdPath);
if (ret == ErrorCode.INVALID_ARGUMENT) {
    Log.e(TAG, "滤镜路径为空");
} else if (ret == ErrorCode.IO) {
    Log.e(TAG, "无法读取 .fbd: " + fbdPath);
} else if (ret != ErrorCode.SUCCESS) {
    Log.e(TAG, "setFilter: " + ret);
}
```

LUT / 贴纸的 GPU 上传发生在 **下一次** `processImage`。setter 成功并不代表纹理已上传；请结合后续 `processImage` 结果和 SDK 日志判断。

## 日志配置

`setLogConfig` 在 `config` 或 `level` 为 `null` 时抛异常。开启文件日志前请先创建父目录。

```java
File logFile = new File(getFilesDir(), "facebetter.log");
File parent = logFile.getParentFile();
if (parent != null && !parent.exists() && !parent.mkdirs()) {
    Log.e(TAG, "无法创建日志目录");
    return;
}
BeautyEffectEngine.LogConfig logConfig = new BeautyEffectEngine.LogConfig();
logConfig.consoleEnabled = true;
logConfig.fileEnabled = true;
logConfig.level = BeautyEffectEngine.LogLevel.DEBUG;
logConfig.fileName = logFile.getAbsolutePath();
BeautyEffectEngine.setLogConfig(logConfig);
```

## 内存不足

`ErrorCode.OUT_OF_MEMORY` 或 `OutOfMemoryError` 通常是帧未释放、分辨率过高，或堆 / Direct Buffer 堆积。

- 相机 / 打包像素使用 `ByteBuffer.allocateDirect`
- 释放每一个 `ImageFrame`（含 `convert` 结果）
- 实时预览使用 `FrameType.VIDEO`
- 不要每帧都 `new` 一个引擎

## 用统计排查卡顿

```java
EngineStats stats = engine.getStats();
if (stats.avgProcessTimeMs > 33) {
    Log.w(TAG, "管线偏慢: " + stats.avgProcessTimeMs + " ms, fps=" + stats.fps);
}
```
