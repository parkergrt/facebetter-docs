## Linux 说明

- 分发 `libfacebetter.so`。设置 `LD_LIBRARY_PATH`、rpath 或 `ldconfig`。
- 用 `./scripts/build_linux.sh` 编译 SDK（产物在 `build/linux/release`），或使用 CMake。
- `resource_path` 必须是 **`resource.fbd` 文件**。
- 没有 `SetRenderView`。
- `external_context = true` 使用调用线程的当前 GL 上下文（GLFW / EGL / OSMesa）。

```cmake
target_include_directories(app PRIVATE /path/to/sdk/include)
target_link_libraries(app PRIVATE /path/to/sdk/lib/libfacebetter.so GL)
```

## 引擎

### `EngineConfig`

| 字段 | 说明 |
| --- | --- |
| `app_id` / `app_key` | 原生在线 v2 鉴权 |
| `resource_path` | `resource.fbd` 文件路径（不是目录） |
| `license_token` | token / `{token}` JSON / `.lic` — 非空时优先 |
| `external_context` | `false`：SDK 管理 OpenGL；`true`：调用方上下文 |

```cpp
struct EngineConfig {
  std::string app_id;
  std::string app_key;
  std::string resource_path;
  std::string license_token;
  bool external_context = false;
};

static std::shared_ptr<BeautyEffectEngine> BeautyEffectEngine::Create(
    const EngineConfig& config);
```

## 图像

```cpp
enum class Format { I420, NV12, NV21, BGRA, RGBA, BGR, RGB, Texture };
enum class Rotation { Rotation_0, Rotation_90, Rotation_180, Rotation_270 };
enum class FrameType { Image = 0, Video = 1 };
```

**工厂：** `CreateWithFile`、`Create`、`CreateWithRGBA/BGRA/RGB/BGR`、`CreateWithI420/NV12/NV21`、`CreateWithTexture`。

**操作：** `Rotate`、`Mirror("horizontal"|"vertical"|"both")`、`SetMirror`、`Convert`、`ToFile`。

**访问器：** `Width/Height/Stride/Size/GetFormat/Data`、YUV 平面、`Texture()`、`Buffer()`。字段：`FrameType type`。

```cpp
struct FaceDetectionResult {
  Rect rect;
  std::vector<Point2d> key_points;  // 111
  std::vector<float> visibility;
  int face_id = -1;
  float score = 0.0f;
  float pitch, roll, yaw;
};
```

## 错误码

| 码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `-1` | 参数非法 |
| `-2` | 未初始化 |
| `-3` | 授权 |
| `-4` | 不支持 |
| `-5` | I/O |
| `-6` | 无槽位 |
| `-7` | 处理失败 |
| `-8` | 内存不足 |

将 `ProcessImage` 串行化到同一线程。`Data()` 像素指针只读。
