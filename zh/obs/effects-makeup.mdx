每一块都有 **强度**。0 表示这一项关闭。有样式又有颜色的，先两边都选好，再把强度拉上去。

这一页上的重置会把这些控件恢复成默认。
面板怎样跟着当前源走，见 [调节效果](/zh/obs/effects)。

## 口红

颜色：**玫瑰红**、**复古红**、**蜜桃**、**珊瑚橘**、**温柔粉**、**活力橙**、**豆沙**、**砖红**、**浆果**、**奶茶**。

- **强度** — 0 表示这一项关闭。

## 腮红

可选：**日晒**、**微醺**、**柔和**、**苹果肌**、**经典**、**娃娃**、**玫瑰**。

颜色：**蜜桃粉**、**雾玫瑰**、**正红**、**莓果**、**元气橘**、**蜜桃**、**樱花粉**。

- **强度** — 0 表示这一项关闭。

## 牙齿

- **强度** — 0 表示这一项关闭。

## 修容

可选：**自然**、**立体**、**提亮**、**瘦脸**、**挺鼻**、**高光**。

- **强度** — 0 表示这一项关闭。

## 眼影

可选：**柔和**、**眼窝**、**烟熏**、**光晕**、**提亮**、**浓妆**、**暖调**。

颜色：**梅紫**、**暖棕**、**金棕**、**藕粉**、**香槟**、**焦糖**、**酒红**、**烟灰**。

- **强度** — 0 表示这一项关闭。

## 眼线

可选：**经典**、**拉长**、**猫眼**、**自然**、**加粗**、**柔雾**。

颜色：**黑色**、**深咖**、**巧克力**、**灰色**、**酒红**、**梅紫**、**雾紫**。

- **强度** — 0 表示这一项关闭。

## 眉毛

可选：**自然**、**柔雾**、**羽化**、**淡雾**、**上挑**、**粉雾**、**飞丝**、**饱满**、**平直**。

颜色：**深棕**、**灰棕**、**浅棕**、**黑色**。

- **强度** — 0 表示这一项关闭。

## 睫毛

可选：**经典**、**漫画**、**拉长**、**蓬松**、**簇状**、**娃娃**。

颜色：**黑色**、**棕色**、**柔黑**。

- **强度** — 0 表示这一项关闭。

## 美瞳

颜色：**琥珀**、**冰蓝**、**摩卡**、**橄榄**、**深棕**、**苔绿**、**沙棕**、**高光**、**岩灰**。

- **强度** — 0 表示这一项关闭。
