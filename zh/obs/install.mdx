Facebetter 是 OBS Studio 的实时美颜滤镜。美肤、美型、美妆、调色、贴纸、美体和背景都在这台电脑上处理。它不会铺满整个 OBS，只跟着你选中的画面源走。

## 开始之前

- macOS 13 或更高。Intel Mac 用 Intel 版 OBS，Apple 芯片用 Apple 版 OBS。
- OBS Studio 28 或更高，并且是 64 位。

下载：[https://facebetter.net/zh/obs](https://facebetter.net/zh/obs)。 其他系统：[Windows](/zh/obs/install-windows)、[Ubuntu](/zh/obs/install-ubuntu)。

## 安装

安装前先完全退出 OBS，菜单栏里的图标也要退。装的时候 OBS 开着，这次启动不会加载新插件。

从上面的页面下载 macOS 的 zip，双击解压。里面是安装器 `Facebetter-OBS-*-macos-universal.pkg`，以及简短说明 `README.zh.txt`、`README.en.txt`。

双击 pkg。介绍页点「继续」。磁盘确认页再点「继续」。到「安装类型」时保持默认，点「安装」。不要改安装位置。插件只装给当前这个 macOS 用户。

系统可能再问一次登录密码或触控 ID。装完之后，插件在：

```text
~/Library/Application Support/obs-studio/plugins/facebetter.plugin
```

然后看 [登录并使用](/zh/obs/login)。
