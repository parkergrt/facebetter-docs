## 面板里没有 Facebetter，滤镜列表里也没有

确认用的是 64 位 OBS Studio 28 或更高版本。复制完文件夹后，必须完全退出 OBS 再打开。

插件不要放在 `%APPDATA%\obs-studio\`。确认这两个文件都在，文件名不要改：

```text
C:\ProgramData\obs-studio\plugins\obs-facebetter\bin\64bit\obs-facebetter.dll
C:\ProgramData\obs-studio\plugins\obs-facebetter\bin\64bit\facebetter.dll
```

`bin` 旁边的 `data` 目录也要留着。安装步骤见 [在 Windows 上安装](/zh/obs/install-windows)。

## 滑块是灰的，拖不动

滤镜还没加到来源上。面板里会写：需添加滤镜才能调节。回到来源上右键 → 滤镜 → + → Facebetter 美颜。分页标题可以点，用来先看有哪些功能；滑块要等滤镜加上才能拖。完整步骤见 [登录并添加滤镜](/zh/obs/login)。

## 加了滤镜，预览却没有变化

看面板顶部的开关是不是开着，来源菜单是不是选中了当前这个源。滑块如果都在 0，画面看起来会和原片一样。美体需要人在画面里占得比较全，只露一张脸时变化不明显。各分页做什么，见 [调节效果](/zh/obs/effects)。
