Facebetter 是 OBS Studio 的实时美颜滤镜。美肤、美型、美妆、调色、贴纸、美体和背景都在这台电脑上处理。它不会铺满整个 OBS，只跟着你选中的画面源走。

## 开始之前

- Windows 10 或 Windows 11，64 位。
- OBS Studio 28 或更高，并且是 64 位。

下载：[https://facebetter.net/zh/obs](https://facebetter.net/zh/obs)。 其他系统：[macOS](/zh/obs/install)、[Ubuntu](/zh/obs/install-ubuntu)。

## 安装

安装前先完全退出 OBS，菜单栏里的图标也要退。装的时候 OBS 开着，这次启动不会加载新插件。

下载 Windows 的 zip 并解压。双击 `Facebetter-OBS-*-windows-x64-setup.exe`，允许管理员权限后按提示安装。

安装器未签名。如果 SmartScreen 提示「Windows 已保护你的电脑」，点「更多信息」，再点「仍要运行」。

插件装在：

```text
C:\ProgramData\obs-studio\plugins\obs-facebetter\
```

然后看 [登录并使用](/zh/obs/login)。
