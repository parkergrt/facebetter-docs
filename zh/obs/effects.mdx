选中一个源，然后在这里调。OBS 预览会跟着滑块变。推流和录制出去的是处理后的画面。底部 **按住对比** 按下期间，这一小段是原画面。

顶部如果写着 **调节后将添加美颜滤镜**，拖一下滑块就会给这个源加上 **Facebetter 美颜**。面板没出现，或滑块锁着，看 [登录并使用](/zh/obs/login)。

每一页有自己的重置。[偏好设置](/zh/obs/settings) 里的 **调节源时自动加滤镜** 默认开着。

| 分页 | 这一页在调什么 |
| --- | --- |
| [美肤](/zh/obs/effects-skin) | 磨皮样式、祛痘祛斑、肤色、红润、清晰。可以只作用在皮肤上。 |
| [美型](/zh/obs/effects-shape) | 脸、额头和眉、眼睛、鼻子、嘴。每项都能往两个方向拖，0 是不动。 |
| [美妆](/zh/obs/effects-makeup) | 口红、腮红、牙齿、修容、眼影、眼线、眉毛、睫毛、美瞳。强度为 0 就是关掉这一项。 |
| [调色](/zh/obs/effects-color) | 亮度、对比度、饱和度、色温、色调，然后再选一个 LUT。 |
| [贴纸](/zh/obs/effects-sticker) | 一个面部贴纸、屏幕贴纸或 3D 道具。选无就去掉。 |
| [美体](/zh/obs/effects-body) | 身形、肩臂、腿。人在画面里要比只露一张脸更大，变化才明显。 |
| [背景](/zh/obs/effects-background) | 保留、虚化或换掉背景。抠图可以用人物检测，也可以用绿幕、蓝幕、红幕。 |
