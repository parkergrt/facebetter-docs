滤镜加上之后，在右侧面板里调。拖滑块时，OBS 预览会跟着变。推流和录制出去的是处理后的画面。还没加滤镜时，先看 [登录并添加滤镜](/zh/obs/login)。

</Frame>

面板最上排从左到右是：

- **开关**：对比开和关。关掉时预览回到原画面，方便看差别。推流前再打开。
- **来源菜单**：选某一个已添加滤镜的源，或 **All sources（全部源）**。选全部源时，调节会写到每一个 Facebetter 滤镜上。
- **重置**：把当前这一页的参数清回默认。
- **齿轮**：设置。可以改「启动 OBS 时打开面板」，也可以看账号和订阅。

设置下面是七个分页：

| 分页 | 用来做什么 |
| --- | --- |
| Skin 美肤 | 磨皮、美白、红润、锐化。打开 **Skin only（仅皮肤）** 后，只处理皮肤，衣服、背景和手里的商品不会跟着被磨白。磨皮有 Texture（保留纹理）、Natural（自然）、Smooth（奶油质感）。美白有 Cool、Pink、Warm、Wheat、Tan 五种色调。 |
| Shape 美型 | 脸型、额头和眉、眼睛、鼻子、嘴。每项都能往两个方向调，0 是不动。 |
| Makeup 美妆 | 口红、腮红、修容、眼影、眼线、眉毛、睫毛、美瞳。样式、色号和强度分开调。 |
| Filter 滤镜 | 胶片调色。先选一种 LUT，再拉强度。选 None 就是不用调色。 |
| Sticker 贴纸 | 2D 人脸跟随、2D 屏幕贴纸和 3D 贴纸。选 None 去掉。 |
| Body 美体 | 瘦身、瘦腰、瘦腿、瘦肩、瘦胳膊、长腿、美胸。适合半身或全身出镜。 |
| BG 背景 | 保留原背景、背景虚化，或换成预设图。抠图可以用人像分割，也可以用绿幕、蓝幕、红幕。 |

语言跟随 OBS。支持简体中文、繁体中文、英语、日语、韩语、葡萄牙语、西班牙语、德语，其余语言显示英文。
