iOS 与 macOS 共用同一套 Objective-C API。iOS 独有：`+[FBImageFrame createWithUIImage:]`。最低系统：**iOS 12.0**，架构 **arm64**。

## 日志

### `FBLogLevel`

```objc
typedef NS_ENUM(NSInteger, FBLogLevel) {
  FBLogLevel_Trace = 0,
  FBLogLevel_Debug,
  FBLogLevel_Info,
  FBLogLevel_Warn,
  FBLogLevel_Error,
  FBLogLevel_Critical,
};
```

### `FBLogConfig`

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `consoleEnabled` | `BOOL` | 控制台输出 |
| `fileEnabled` | `BOOL` | 文件输出 |
| `level` | `FBLogLevel` | 最低级别 |
| `fileName` | `NSString *` | 日志路径（`fileEnabled` 为 `YES` 时生效） |

```objc
FB_OBJC_API @interface FBLogConfig : NSObject
@property(nonatomic, assign) BOOL consoleEnabled;
@property(nonatomic, assign) BOOL fileEnabled;
@property(nonatomic, assign) FBLogLevel level;
@property(nonatomic, copy, nullable) NSString *fileName;
- (instancetype)init;
@end
```

在 `createEngineWithConfig:` **之前**调用 `+[FBBeautyEffectEngine setLogConfig:]`。返回 `FBErrorCode`（`0` 成功，`config` 为 nil 时 `-1`）。

## 引擎配置

### `FBEngineConfig`

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `appId` | `NSString *` | 控制台 App ID（在线授权） |
| `appKey` | `NSString *` | 控制台 App Key（在线授权） |
| `licenseToken` | `NSString *` | 许可证 token、`{token}` JSON，或原生 `.lic` 内容 |
| `externalContext` | `BOOL` | 默认 `NO`。`YES`：使用调用方的 OpenGL ES 上下文，SDK 不创建内部上下文 |

**授权优先级：** `licenseToken` 非空则本地校验，跳过 `/facebetter/v2/auth`；否则用 `appId` + `appKey` 在线授权。请在控制台绑定应用 **Bundle ID**。

```objc
FB_OBJC_API @interface FBEngineConfig : NSObject
@property(nonatomic, copy) NSString *appId;
@property(nonatomic, copy) NSString *appKey;
@property(nonatomic, copy, nullable) NSString *licenseToken;
@property(nonatomic, assign) BOOL externalContext;
- (instancetype)init;
@end
```

### `FBFrameType`

在 `processImage:` 前设置 `FBImageFrame.type`。不是方法参数。

```objc
typedef NS_ENUM(NSInteger, FBFrameType) {
  FBFrameTypeImage = 0,  // 静图
  FBFrameTypeVideo = 1   // 实时 / 相机
};
```

### 虚拟背景与色键

| 方法 | 说明 |
| --- | --- |
| `setChromaKey:` | 绿 / 蓝 / 红遮罩。填充仍是模糊或图片 |
| `clearChromaKey` | 恢复人像分割遮罩；**不**清除填充 |
| `setChromaKeySimilarity:` | 抠像阈值 `[0, 1]` |
| `setChromaKeySmoothness:` | 边缘羽化 `[0, 1]` |
| `setChromaKeyDesaturation:` | 溢色抑制 `[0, 1]` |

### 滤镜与贴纸

没有按 ID 注册。传路径或字节；GPU 资源在下一次 `processImage:`（GL 线程 / 外部上下文）创建。

| 方法 | 说明 |
| --- | --- |
| `setFilter:` | 从 `.fbd` 路径加载 LUT |
| `setFilterWithData:` | 从 `.fbd` 字节加载 LUT |
| `clearFilter` | 移除 LUT |
| `setFilterIntensity:` | `[0, 1]` |
| `setSticker:` | 2D 贴纸 `.fbd` 路径 |
| `setStickerWithData:` | 贴纸字节 |
| `clearSticker` | 移除贴纸 |

空路径 / nil 或空 `NSData` → `FBErrorCode_InvalidArgument`。

### 处理

```objc
- (FBImageFrame * _Nullable)processImage:(FBImageFrame *)imageFrame;
```

读取 `imageFrame.type`（`FBFrameTypeImage` 或 `FBFrameTypeVideo`）。输出格式与输入一致。失败返回 `nil`。

## `FBImageFrame`

### 创建

| 方法 | 说明 |
| --- | --- |
| `createWithData:width:height:format:` | 原始缓冲 + `FBImageFormat` |
| `createWithRGBA:width:height:stride:` | |
| `createWithBGRA:width:height:stride:` | |
| `createWithRGB:width:height:stride:` | |
| `createWithBGR:width:height:stride:` | |
| `createWithI420:...` | Y / U / V 平面 |
| `createWithNV12:...` | Y + UV |
| `createWithNV21:...` | Y + VU |
| `createWithFile:` | png / jpg 路径 |
| `createWithTexture:width:height:stride:` | 当前上下文中的 `GL_TEXTURE_2D`；`stride` 通常为 `width * 4` |
| `createWithUIImage:` | **仅 iOS** |

### 操作

| 方法 | 说明 |
| --- | --- |
| `rotate:` | `FBImageRotation`；返回 `FBErrorCode` |
| `mirror:` | `"horizontal"` / `"vertical"` / `"both"`（大小写不敏感）；直接改像素 |
| `setMirror:` | 供 `processImage:` 使用的标记（避免额外格式转换）。`nil` / `@""` 清除 |
| `convert:` | 返回目标 `FBImageFormat` 的新帧 |
| `toFile:quality:` | 质量 `0`–`100` |
| `toFile:` | 质量 `90` |

### 属性与访问器

`width`、`height`、`stride`、`size`、`type`。方法：`data`、`format`、`texture`（非纹理时为 `0`）。YUV：`dataY` / `dataU` / `dataV` / `dataUV`，`strideY` / `strideU` / `strideV` / `strideUV`（非 YUV 时为 `NULL` / `0`）。

```objc
typedef NS_ENUM(NSInteger, FBImageFormat) {
  FBImageFormatI420,
  FBImageFormatNV12,
  FBImageFormatNV21,
  FBImageFormatBGRA,
  FBImageFormatRGBA,
  FBImageFormatBGR,
  FBImageFormatRGB,
  FBImageFormatTexture,
};

typedef NS_ENUM(NSInteger, FBImageRotation) {
  FBImageRotation0,
  FBImageRotation90,   // 顺时针
  FBImageRotation180,
  FBImageRotation270,
};
```

```objc
FBImageFrame *frame = [FBImageFrame createWithUIImage:image];
frame.type = FBFrameTypeImage;
FBImageFrame *out = [engine processImage:frame];
```
