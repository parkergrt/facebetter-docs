## 生产环境鉴权

`app_id` / `app_key` 放在服务器。由**你的后端**换一张短时有效的 `licenseToken`，再传给引擎。

```javascript
const licenseToken = await fetch('/api/facebetter/auth', { method: 'POST' }).then((r) => r.text());
const engine = new BeautyEffectEngine(new EngineConfig({ licenseToken }));
```

<Warning>
不要把 `appKey` 打进生产前端包。`fetchLicenseToken` 只适合 localhost。
</Warning>

在控制台绑定与线上一致的域名。Web 不能使用离线 `.lic`。

## 一页一个引擎

创建一个 `BeautyEffectEngine`，`init()` 一次，整段会话复用。不要每帧 new 一个引擎。

```javascript
useEffect(() => {
  let engine;
  (async () => {
    engine = new BeautyEffectEngine(new EngineConfig({ licenseToken }));
    await engine.init();
    engineRef.current = engine;
  })();
  return () => {
    engineRef.current?.destroy();
    engineRef.current = null;
  };
}, []);
```

## 帧循环

- 用 `requestAnimationFrame` 驱动视频，不要空转 `while`。
- 摄像头用 `FrameType.Video`，静图用 `FrameType.Image`。
- Canvas 尺寸与处理后的 `ImageData` 对齐，避免额外缩放。
- `video.readyState >= 2` 且 `videoWidth > 0` 再处理。
- 优先 `processImage`。`processTexture` 不应用镜像。

```javascript
const result = engine.processImage(
  video,
  video.videoWidth,
  video.videoHeight,
  FrameType.Video,
  MirrorMode.Horizontal,
);
ctx.putImageData(result, 0, 0);
```

## 参数

实时预览从低强度开始（磨皮约 `0.2`–`0.5`）。美型范围是 `[-1, 1]`，摄像头上小幅调节更自然。

界面不需要关键点就不要注册 `onFaceLandmarks`，否则每帧都会跑检测。

磨皮较高时打开 `setBeautySkinOnly(true)`，避免背景被抹糊。

## 资源

- 把 `resource.fbd` 放到 `/resource.fbd`（或你配置的 `resourcePath`）。
- 滤镜 / 贴纸 `.fbd` 和背景 jpg/png 作为静态文件托管，把 URL 传给 `setFilter` / `setSticker` / `setVirtualBackground`。
- 在用户操作时切换滤镜 / 贴纸，不要每帧切换。

## 内存

- 卸载页面或离开路由时调用 `destroy()`。
- 复用展示用 canvas，不要每帧新建。

## HTTPS 与 CORS

摄像头需要 HTTPS 或 localhost。若 `resource.fbd` 在其他源，需要配置 CORS。
