<Note>
SDK **2.0.0**。鉴权失败见 [授权与许可](/zh/intro/license)。
</Note>

调用失败会抛 `FacebetterError`。数值型 `code` 见下表。加载 / 鉴权失败时部分错误使用**字符串** `code`。

```javascript
import { BeautyEffectEngine, EngineConfig, FacebetterError } from 'facebetter';

try {
  const engine = new BeautyEffectEngine(new EngineConfig({
    authProxyUrl: '/api/facebetter/auth',
  }));
  await engine.init();
  engine.setSmoothing(0.5);
} catch (error) {
  if (error instanceof FacebetterError) {
    console.error(error.code, error.message);
  } else {
    console.error(error);
  }
}
```

## 数值错误码

| 码 | 含义 |
| --- | --- |
| `0` | 成功（`checkResult` 不抛错） |
| `-1` | 参数非法（空指针、空路径、强度越界等） |
| `-2` | 引擎未初始化或已销毁 |
| `-3` | 授权无效 |
| `-4` | 当前平台 / 格式不支持 |
| `-5` | I/O（资源包 / 滤镜 / 贴纸 / 背景图） |
| `-6` | 槽位池已满（背压，应丢帧） |
| `-7` | 处理失败 |
| `-8` | 内存分配失败 |

## JavaScript 层码（字符串）

出现在 `init()` / 加载 / 鉴权阶段：

| `error.code` | 场景 |
| --- | --- |
| `'TIMEOUT'` | `init()` 超时 |
| `'NETWORK_ERROR'` | 网络 / fetch 失败 |
| `'WASM_LOAD_ERROR'` | SDK 加载失败（网络、CDN 或广告拦截） |
| `'LICENSE_ERROR'` | 缺少鉴权配置，或 `fetchAuthResponse` / 代理拒绝 |
| `'ENGINE_CREATE_FAILED'` | 引擎创建失败 |
| `'UNKNOWN_ERROR'` | 未分类的 JS 异常被包成 `FacebetterError` |

```javascript
try {
  await engine.init({ timeout: 30000 });
} catch (error) {
  if (!(error instanceof FacebetterError)) throw error;
  if (error.code === 'LICENSE_ERROR' || error.code === -3) {
    // 代理宕机、域名未绑定或 token 过期 — 见 /zh/intro/license
  } else if (error.code === 'WASM_LOAD_ERROR' || error.code === 'TIMEOUT') {
    // 网络、CDN 或广告拦截
  }
}
```

## 初始化排查

1. 配置合法：`licenseToken`、`authProxyUrl`、`fetchAuthResponse` 至少有一个。
2. `resource.fbd` 能从 `resourcePath` 访问到（默认 `/resource.fbd`）。
3. 页面处于[安全上下文](https://developer.mozilla.org/zh-CN/docs/Web/Security/Secure_Contexts)。
4. 生产环境控制台绑定的域名与页面 origin 一致。
5. 生产前端包里**没有**嵌入 `appKey`。

## 参数与处理错误

美颜强度必须在 `[0.0, 1.0]`，美型必须在 `[-1.0, 1.0]`。越界会在进入原生之前抛 `FacebetterError`。

引擎未初始化、缓冲分配失败或原生处理返回非 0 时，`processImage` 会抛错。调用前确认视频 `readyState`，以及 `videoWidth` / `videoHeight` 非 0。

滤镜 / 贴纸 / 背景的**路径不能为空**；关闭请用 `clearFilter()`、`clearSticker()`、`clearVirtualBackground()`。

## 引擎事件与异常

`init()` 已经成功返回后，鉴权 / 初始化结果仍可能通过 `onEngineEvent` 到达（`EngineEventCode` 的 `0` / `1` / `100` / `101`）。即使 `init()` 没抛错，也要监听 `LicenseValidationFailed` 和 `InitializationFailed`。
