## 环境要求

- **浏览器**：Chrome 57+、Firefox 52+、Safari 11+、Edge 16+
- **语言**：JavaScript（ES6+）或 TypeScript
- **运行环境**：HTTPS 或 `localhost`（摄像头需要 HTTPS 或 localhost）

## 安装 SDK

```bash
npm install facebetter
```

```javascript
import {
  BeautyEffectEngine,
  EngineConfig,
  FrameType,
  MirrorMode,
  Reshape,
} from 'facebetter';
```

## 获取示例源码

克隆 [GitHub 仓库](https://github.com/pixpark/facebetter-sdk)，进入 `demo/web/react`：

```bash
git clone https://github.com/pixpark/facebetter-sdk.git
cd demo/web/react
```

这是 Vite + React 示例。开发时通过 `file:` 依赖仓库内的 SDK。

## 绑定域名并获取凭证

1. 在控制台绑定 Web **域名**（例如 `example.com`）。见 [订阅服务](/zh/intro/enable-service)。
2. 复制 `appId` / `appKey`。**不要写进 `EngineConfig`。** Web 上密钥只应放在**你的服务器**。

Web **不支持**离线 `.lic`。完整说明：[授权与许可](/zh/intro/license)。

## 配置示例

Demo **不在前端放密钥**。页面请求自家代理 `/api/facebetter/auth`（见 `src/fetchLicenseToken.js`），再把响应交给引擎。线上代理实现见 `api/facebetter/auth.js`；本地开发时 Vite 会把该路径转到已部署的 Demo 代理。

```javascript
const licenseToken = await fetch('/api/facebetter/auth', { method: 'POST' }).then((r) => r.text());
const engine = new BeautyEffectEngine(new EngineConfig({ licenseToken }));
await engine.init();
```

生产环境请在**你们自己的服务器**实现同样的代理。完整步骤与 Node 示例见 [授权与许可](/zh/intro/license)。

SDK 会在 `init()` 时加载运行时文件。**不必**把 `resource.fbd` 拷进 `public/`。可选：`init({ onProgress })` 报告下载百分比。3D 贴纸需要 `resource_3d.fbd`，美体需要 `resource_body.fbd`，见 [可选资源包](/zh/intro/resource-packs)。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 Vite 打印的地址（一般为 `http://localhost:5175`）。

## 验证

1. 打开开发者工具（F12）查看控制台。
2. 如需摄像头，允许权限。
3. 拖动美颜滑条，预览应出现磨皮 / 美型效果。

## 生产环境最小初始化

```javascript
import { BeautyEffectEngine, EngineConfig } from 'facebetter';

const licenseToken = await fetch('/api/facebetter/auth', { method: 'POST' }).then((r) => r.text());
const engine = new BeautyEffectEngine(new EngineConfig({ licenseToken }));
await engine.init();
```

服务器保管 `app_id` / `app_key` 并返回 token。服务端示例见 [授权与许可](/zh/intro/license)。
