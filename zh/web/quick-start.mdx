## 环境要求

- **浏览器**：Chrome 57+、Firefox 52+、Safari 11+、Edge 16+
- **语言**：JavaScript（ES6+）或 TypeScript
- **运行环境**：HTTPS 或 `localhost`（摄像头需要 HTTPS 或 localhost）

## 安装 SDK

```bash
npm install facebetter
```

```javascript
import {
  BeautyEffectEngine,
  EngineConfig,
  FrameType,
  MirrorMode,
  Reshape,
  fetchLicenseToken,
} from 'facebetter';
```

## 获取示例源码

克隆 [GitHub 仓库](https://github.com/pixpark/facebetter-sdk)，进入 `demo/web/react`：

```bash
git clone https://github.com/pixpark/facebetter-sdk.git
cd demo/web/react
```

这是 Vite + React 示例。开发时通过 `file:` 依赖仓库内的 SDK。

## 绑定域名并获取凭证

1. 在控制台绑定 Web **域名**（例如 `example.com`）。见 [订阅服务](/zh/intro/enable-service)。
2. 复制 `appId` / `appKey`。**不要写进 `EngineConfig`。** Web 上密钥只应放在**你的服务器**。本地调试才可以用 `fetchLicenseToken({ appId, appKey })`。

Web **不支持**离线 `.lic`。完整说明：[授权与许可](/zh/intro/license)。

## 配置示例

打开 `src/useStudioEngine.js`。示例先向 `/api/fb-auth` 换 token（Vite 代理持有 `app_id` / `app_key`），再传入 `licenseToken`：

```javascript
const licenseToken = await fetch('/api/fb-auth', { method: 'POST' }).then((r) => r.text());
const engine = new BeautyEffectEngine(new EngineConfig({ licenseToken }));
await engine.init();
```

没有代理时的本地调试：

```javascript
const engine = new BeautyEffectEngine(new EngineConfig({
  licenseToken: await fetchLicenseToken({
    appId: 'your-app-id',
    appKey: 'your-app-key',
  }),
}));
await engine.init();
```

<Warning>
`fetchLicenseToken` 会把 `appKey` 打进前端包，只适合 localhost。生产环境必须由**你的服务器**换 token，再传入 `licenseToken`。
</Warning>

把打包好的 `resource.fbd` 放到站点根路径 `/resource.fbd`（默认 `resourcePath`）。开发时复制到 `public/`，Vite 即可托管。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 Vite 打印的地址（一般为 `http://localhost:5173`）。

## 验证

1. 打开开发者工具（F12）查看控制台。
2. 如需摄像头，允许权限。
3. 拖动美颜滑条，预览应出现磨皮 / 美型效果。

## 生产环境最小初始化

```javascript
import { BeautyEffectEngine, EngineConfig } from 'facebetter';

const licenseToken = await fetch('/api/facebetter/auth', { method: 'POST' }).then((r) => r.text());
const engine = new BeautyEffectEngine(new EngineConfig({ licenseToken }));
await engine.init();
```

服务器保管 `app_id` / `app_key` 并返回 token。服务端示例见 [授权与许可](/zh/intro/license)。
