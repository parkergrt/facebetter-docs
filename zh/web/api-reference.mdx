npm 包：**`facebetter`**。常用导入：

```javascript
import {
  BeautyEffectEngine,
  EngineConfig,
  FrameType,
  MirrorMode,
  Reshape,
  createDirectAuthFetcher,
} from 'facebetter';
```

## EngineConfig

```javascript
new EngineConfig({
  licenseToken,      // string — 许可证 token，或 `{token}` JSON
  authProxyUrl,      // string — 把 SDK 鉴权请求 POST 到你的服务器
  fetchAuthResponse, // async (challenge) => string | object
  resourcePath,      // string — 默认 `/resource.fbd`
})
```

Web **不接受**在该对象上设置 `appId` / `appKey`。Web **不支持**离线 `.lic`。

`licenseToken`、`authProxyUrl` 或 `fetchAuthResponse` 任一存在时，`isValid()` 为 true。

本地调试辅助（禁止用于生产）：

```javascript
fetchAuthResponse: createDirectAuthFetcher({ appId, appKey })
```

## BeautyEffectEngine

```javascript
const engine = new BeautyEffectEngine(config);
await engine.init();
```

### 生命周期

| 方法 | 说明 |
| --- | --- |
| `init(options?)` | 初始化引擎（鉴权与资源）。`options.timeout`（默认 `30000`）为初始化超时（毫秒）。 |
| `setLogConfig({ consoleEnabled, fileEnabled, level, fileName })` | 全局日志。请在 `init()` 前调用。`level`：`0` TRACE … `5` CRITICAL。浏览器不支持文件日志。返回 `Promise<void>`。 |
| `destroy()` | 释放引擎及其资源。 |

`init()` 成功后 `engine.initialized` 为 `true`。

### 皮肤

| 方法 | 范围 |
| --- | --- |
| `setSmoothing(value)` | `[0, 1]` |
| `setSmoothingStyle(style)` | `SmoothingStyle` |
| `setWhitening(value)` | `[0, 1]` |
| `setWhiteningStyle(style)` | `WhiteningStyle` |
| `setSharpening(value)` | `[0, 1]` |
| `setRosiness(value)` | `[0, 1]` |
| `setBeautySkinOnly(enabled)` | `boolean` |

### 美型

`setReshape(param, value)` — `param` 为 `Reshape.*`，`value` 范围 **`[-1.0, 1.0]`**。见 [参数枚举](/zh/intro/makeup)。

### 美妆

强度 `[0, 1]`。风格 / 色号枚举：[参数枚举](/zh/intro/makeup)。

| 强度 | 风格 / 色号 |
| --- | --- |
| `setLipstick` | `setLipstickColor` |
| `setBlush` | `setBlushStyle`、`setBlushColor` |
| `setContour` | `setContourStyle` |
| `setEyeShadow` | `setEyeShadowStyle`、`setEyeShadowColor` |
| `setEyeLiner` | `setEyeLinerStyle`、`setEyeLinerColor` |
| `setEyebrow` | `setEyebrowStyle`、`setEyebrowColor` |
| `setEyelash` | `setEyelashStyle`、`setEyelashColor` |
| `setPupil` | `setPupilColor` |

### 滤镜 / 贴纸

| 方法 | 说明 |
| --- | --- |
| `setFilter(path \| Uint8Array)` | 用 URL 或字节应用 LUT `.fbd` |
| `clearFilter()` | 清除当前滤镜 |
| `setFilterIntensity(intensity)` | `[0, 1]` |
| `setSticker(path \| Uint8Array)` | 应用 2D 贴纸 `.fbd` |
| `clearSticker()` | 清除贴纸 |

### 虚拟背景 / 色度键

| 方法 | 说明 |
| --- | --- |
| `setVirtualBackgroundBlur(level)` | 连续虚化 `[0, 1]`。`0` 表示关闭 |
| `setVirtualBackground(path \| Uint8Array)` | png/jpg 路径或编码字节 |
| `clearVirtualBackground()` | 关闭虚化 / 背景图 |
| `setChromaKey(color)` | `ChromaKeyColor.Green` / `Blue` / `Red` |
| `clearChromaKey()` | 恢复人像分割遮罩 |
| `setChromaKeySimilarity(value)` | `[0, 1]` |
| `setChromaKeySmoothness(value)` | `[0, 1]` |
| `setChromaKeyDesaturation(value)` | `[0, 1]` |

### 回调

```javascript
engine.setCallbacks({
  onFaceLandmarks, // (faces) => void
  onEngineEvent,   // (code, message) => void
  maxFaces,        // 可选，默认 10
});
```

### 处理

```javascript
processImage(input, width, height, frameType = FrameType.Video, mirrorMode = MirrorMode.None) → ImageData
```

- `input`：`ImageData` \| `HTMLImageElement` \| `HTMLCanvasElement` \| `HTMLVideoElement` \| `Uint8ClampedArray`
- 仅 `Uint8ClampedArray` 时必须传 `width` / `height`

```javascript
processTexture(textureHandle, width, height, stride, frameType, mirrorMode) → number
```

返回输出 `GL_TEXTURE_2D` 句柄。**该路径不应用镜像。** 请优先使用 `processImage`。

### 统计

```javascript
engine.getStats() → { fps, avgProcessTimeMs, sessionTimeS }
```

## 枚举（JS）

取值与原生一致。美妆 / 美型完整表：[参数枚举](/zh/intro/makeup)。

```javascript
FrameType = { Image: 0, Video: 1 }

MirrorMode = { None: 0, Horizontal: 1, Vertical: 2, Both: 3 }

EngineEventCode = {
  LicenseValidationSuccess: 0,
  LicenseValidationFailed: 1,
  InitializationComplete: 100,
  InitializationFailed: 101,
}

ChromaKeyColor = { Green: 0, Blue: 1, Red: 2 }

Reshape = { FaceThin: 0, FaceVShape: 1, /* … BrowThickness: 25 */ }
```

同时导出：`SmoothingStyle`、`WhiteningStyle`、`LipstickColor`、`BlushStyle`、`BlushColor`、`ContourStyle`、`EyeShadowStyle`、`EyeShadowColor`、`EyeLinerStyle`、`EyeLinerColor`、`EyebrowStyle`、`EyebrowColor`、`EyelashStyle`、`EyelashColor`、`PupilColor`。

## FacebetterError

```javascript
class FacebetterError extends Error {
  constructor(message, code = -1)
  // name === 'FacebetterError'
  // code: number 或 string
}
```

数值码：`0`、`-1` … `-8`。见 [错误处理](/zh/web/error-handling)。
