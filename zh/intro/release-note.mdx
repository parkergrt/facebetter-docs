本站描述 **SDK 2.x**。当前最新：**v2.2.1**。

## v2.2.1

2026-10-30

1. 强度调节在下一帧生效，不必等当前这一帧画完。
2. 皮肤和人像遮罩更快。

## v2.2.0

2026-10-29

1. 全画面调色：亮度、对比度、饱和度、色温、色调、清晰度。清晰度取代原来单独的锐化。
2. 祛痘，独立于磨皮，作用在皮肤区域。
3. 牙齿美白，只处理张开的嘴。
4. 虚拟背景抠像可以加主体描边。
5. Android 与 iOS 的口红、腮红、眼影、眼线、眉毛色号与统一预设对齐。
6. 眉毛样式会先淡化原有眉毛再绘制。
7. 美体以两肩为锚，瘦腰和美胸分开。
8. Web 离线许可证可以绑定页面来源。在线鉴权在第一个地址失败后会改用备用地址。
9. 静态图片返回刚提交的这一帧。实时视频返回上一帧已处理的结果。
10. 水印位置上移，缩小时更清晰。
11. 修复 Windows 调色横条、OpenGL 遮罩条纹，以及 Linux 预览。

## v2.1.1

2026-09-30

1. 桌面示例从程序旁边加载资源，拷走后仍能运行。
2. Windows 示例界面跟随显示器缩放。

## v2.1.0

2026-09-21

1. 美体：瘦身、瘦腰、瘦腿、瘦肩、瘦胳膊、长腿、美胸等。见 [参数枚举](./makeup)
2. 3D 贴纸（眼镜、帽子等网格道具）
3. 美体和 3D 贴纸使用可选资源包，见 [可选资源包](./resource-packs)

## v2.0.1

2026-09-15

1. 提升 Web 和 Android 处理性能

## v2.0.0

2026-09-09

1. 新鉴权：原生可用许可证 token 或 `appId` + `appKey`；Web 只用 token（由你的服务器换取）
2. 美颜：磨皮、美白、锐化、红润、仅皮肤，以及风格预设
3. 美型（26 项）
4. 美妆：强度、形状、色号。见 [参数枚举](./makeup)
5. LUT 滤镜和 2D 贴纸（`.fbd`）
6. 虚拟背景：虚化、换图、色键
7. 处理统计（`getStats()`）
