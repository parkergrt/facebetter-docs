<Note>
本文档对应 SDK **2.0**。枚举数值在 C++、Objective-C、Java、JavaScript、Dart 上完全一致。
</Note>

美妆是三个旋钮：

1. **强度** — `SetLipstick` / `SetBlush` / `SetContour` / `SetEyeShadow` / `SetEyeLiner` / `SetEyebrow` / `SetEyelash` / `SetPupil`，范围 `[0.0, 1.0]`。`0` 关闭该效果。
2. **形状** — 换蒙版贴图（`SetBlushStyle`、`SetContourStyle`、`SetEyeShadowStyle` 等）。
3. **色号** — 给当前形状染色（`SetLipstickColor`、`SetBlushColor`、`SetEyeShadowColor` 等）。**美瞳和修容不染色**，换项就是换贴图。

| C++ / JS | Java | Objective-C | Dart |
| --- | --- | --- | --- |
| `LipstickColor::Rouge` | `LipstickColor.ROUGE` | `FBLipstickColor_Rouge` | `FBLipstickColor.rouge` |

## 美白（`WhiteningStyle`）

配合 `SetWhiteningStyle` 使用。强度仍由 `SetWhitening` 控制。默认：`ColdWhite`。

| 值 | 名称 | 说明 |
| --- | --- | --- |
| 0 | `ColdWhite` | 冷白 |
| 1 | `PinkWhite` | 粉白 |
| 2 | `WarmWhite` | 暖白 |
| 3 | `Wheat` | 小麦 |
| 4 | `Tan` | 美黑 |

## 磨皮（`SmoothingStyle`）

配合 `SetSmoothingStyle` 使用。强度仍由 `SetSmoothing` 控制。默认：`Natural`。

| 值 | 名称 | 说明 |
| --- | --- | --- |
| 0 | `Natural` | 保留毛孔 |
| 1 | `Texture` | 更干净，仍保留质感 |
| 2 | `Smooth` | 奶油肌 |

## 美型（`Reshape`）

配合 `SetReshape(param, intensity)` 使用。范围是 **`[-1.0, 1.0]`**。`0` 关闭。正负为相反方向（例如瘦脸：瘦脸 / 丰脸颊）。

| 值 | 名称 | 正向 / 负向 |
| --- | --- | --- |
| 0 | `FaceThin` | 瘦脸 / 丰脸颊 |
| 1 | `FaceVShape` | V 脸 / 方下巴 |
| 2 | `FaceNarrow` | 窄脸 / 宽脸 |
| 3 | `FaceShort` | 短脸 / 长脸 |
| 4 | `Cheekbone` | 瘦颧骨 / 扩颧骨 |
| 5 | `Jawbone` | 瘦下颌 / 扩下颌 |
| 6 | `Chin` | 拉长下巴 / 缩短下巴 |
| 7 | `NoseSlim` | 瘦鼻 / 宽鼻 |
| 8 | `EyeSize` | 大眼 / 小眼 |
| 9 | `EyeDistance` | 拉开眼距 / 拉近眼距 |
| 10 | `FaceSmall` | 小脸 / 大脸 |
| 11 | `Forehead` | 丰额头 / 压额头 |
| 12 | `NoseLong` | 长鼻 / 短鼻 |
| 13 | `Philtrum` | 缩短人中 / 拉长人中 |
| 14 | `MouthSize` | 大嘴 / 小嘴 |
| 15 | `MouthPosition` | 嘴下移 / 嘴上移 |
| 16 | `MouthSmile` | 微笑 / 下垂嘴角 |
| 17 | `LipThickness` | 厚唇 / 薄唇 |
| 18 | `EyeRound` | 圆眼 / 细长眼 |
| 19 | `EyePosition` | 眼下移 / 眼上移 |
| 20 | `EyeAngle` | 眼尾上扬 / 眼尾下垂 |
| 21 | `EyeCornerOpen` | 开眼角 / 收眼角 |
| 22 | `LowerEyelid` | 卧蚕 / 提眼睑 |
| 23 | `BrowPosition` | 眉上移 / 眉下移 |
| 24 | `BrowDistance` | 拉开眉距 / 拉近眉距 |
| 25 | `BrowThickness` | 粗眉 / 细眉 |

Java 使用 `SNAKE_CASE`（`FACE_THIN`、`FACE_V_SHAPE` …）。Objective-C 使用 `FBReshape_FaceThin`。Dart 使用 `FBReshape.faceThin`。

| 4 | `Classic` | 经典两点 |
| 5 | `Doll` | 脸颊 + 鼻尖 |
| 6 | `Rose` | 玫瑰双颊 |

| --- | --- | --- |

## 修容（`ContourStyle`）

中灰 Overlay：比 128 亮是高光，比 128 暗是阴影。换贴图，不染色。默认：`Natural`。

| 值 | 名称 | 说明 |
| --- | --- | --- |
| 0 | `Natural` | 日常薄修容 |
| 1 | `Sculpt` | 立体深修容 |
| 2 | `Glow` | 提亮为主 |
| 3 | `Slim` | 瘦颧骨 |
| 4 | `Nose` | 鼻梁立体 |
| 5 | `Glam` | 高光点 |
