SDK **2.0** 使用 **license token** 鉴权。原生平台也可以用 `appId` + `appKey` 走在线鉴权。Web **禁止**在前端 JavaScript 里嵌入 `appKey`。

<Tip>
请先完成 [订阅服务](./enable-service)：在控制台绑定应用标识（Bundle ID / 包名 / 域名）并开通套餐。
</Tip>

## 原生（Android / iOS / macOS / Windows / Linux / Flutter）

创建引擎时二选一：

| 模式 | 配置字段 | 适用场景 |
|------|----------|----------|
| 在线 | `appId` + `appKey` | 设备能访问 `/facebetter/v2/auth` |
| Token | `licenseToken` | 许可证 token、`{token}` JSON，或原生离线 `.lic` |

**优先级**：`licenseToken` 非空时，SDK 本地校验该 token，**不会**再用 `appId` / `appKey` 请求网络。

**iOS / macOS**

```objc
FBEngineConfig *config = [[FBEngineConfig alloc] init];
config.licenseToken = @"/* 许可证 token、{token} JSON，或 .lic 全文 */";
self.beautyEffectEngine = [FBBeautyEffectEngine createEngineWithConfig:config];
```

**Android**

```java
BeautyEffectEngine.EngineConfig config = new BeautyEffectEngine.EngineConfig();
config.licenseToken = "/* 许可证 token、{token} JSON，或 .lic 全文 */";
mBeautyEngine = new BeautyEffectEngine(this, config);
```

**C++（Windows / Linux）**

```cpp
facebetter::EngineConfig config;
config.license_token = "/* 许可证 token、{token} JSON，或 .lic 全文 */";
config.resource_path = "/path/to/resource.fbd";
auto engine = facebetter::BeautyEffectEngine::Create(config);
```

**Flutter**

```dart
final engine = await FBEngine.create(
  FBEngineConfig(licenseToken: '/* 许可证 token、{token} JSON，或 .lic 全文 */'),
);
```

原生在线鉴权写法：

```java
config.appId = "your appId";
config.appKey = "your appKey";
```

离线 `.lic` 建议作为资源随包分发，运行时读取，不要写死在源码里。

## Web

浏览器 SDK **没有** `appId` / `appKey` 字段。三选一：

| 模式 | 配置字段 | 适用场景 |
|------|----------|----------|
| Token | `licenseToken` | 你的服务器已经签发许可证 token 或 `{token}` JSON |
| 代理 | `authProxyUrl` | SDK 把鉴权请求 POST 到**你的**服务器；服务器持有 `app_id` / `app_key` 再请求 Facebetter 鉴权接口 |
| 自定义 | `fetchAuthResponse` | 自己实现 `async (challenge) => string \| object`。本地调试可用 `createDirectAuthFetcher({ appId, appKey })` |

<Warning>
不要把 `appKey` 打进生产前端包。`createDirectAuthFetcher` 仅用于本地调试。Web **不支持**离线 `.lic`。
</Warning>

```javascript
import { BeautyEffectEngine, EngineConfig, createDirectAuthFetcher } from 'facebetter';

// A. 服务端已经返回 v2 token
const config = new EngineConfig({
  licenseToken: await fetch('/api/facebetter/auth', { method: 'POST' }).then((r) => r.text()),
});

// B. 生产推荐：由你的服务器代理 SDK 鉴权请求
const config = new EngineConfig({
  authProxyUrl: '/api/facebetter/auth',
});

// C. 仅本地调试 —— 密钥会出现在前端
const config = new EngineConfig({
  fetchAuthResponse: createDirectAuthFetcher({
    appId: 'your-app-id',
    appKey: 'your-app-key',
  }),
});

const engine = new BeautyEffectEngine(config);
await engine.init();
```

Node 代理示例：

```javascript
import { createHmac } from 'node:crypto';

app.post('/api/facebetter/auth', async (req, res) => {
  const { nonce, timestamp, platform, user_agent } = req.body;
  const appId = process.env.FB_APP_ID;
  const appKey = process.env.FB_APP_KEY;
  const payload = `v2|${appId}|${timestamp}|${nonce}|${platform}`;
  const hmac = createHmac('sha256', appKey).update(payload).digest('hex');

  const upstream = await fetch('https://facebetter.pixpark.net/facebetter/v2/auth', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      app_id: appId,
      hmac_signature: hmac,
      timestamp,
      nonce,
      platform,
      user_agent,
    }),
  });
  res.status(upstream.status).send(await upstream.text());
});
```

## 离线许可证（仅原生）

1. 登录 [控制台](https://facebetter.net/zh/dashboard)
2. 选择项目，下载离线许可证
3. 把**文件全文**赋给 `licenseToken` / `license_token`

有效期与当前订阅一致。续费或改套餐后需重新下载并替换。

### 注意

- 离线许可证绑定控制台里配置的应用标识，不匹配会校验失败。
- 未过期：能力跟随订阅套餐。
- 已过期：引擎仍可初始化，能力回退到**免费版**（始终带水印，不含关键点回调）。续费后重新下载。
- Web 不能使用离线许可证，必须走在线 v2 鉴权。

## 引擎事件

通过 `onEngineEvent` / Flutter `engine.events` 监听授权和初始化结果：

| 码 | 名称 | 含义 |
| --- | --- | --- |
| 0 | `LICENSE_VALIDATION_SUCCESS` | Token / 在线鉴权成功 |
| 1 | `LICENSE_VALIDATION_FAILED` | 鉴权失败（见 message） |
| 100 | `INITIALIZATION_COMPLETE` | 引擎就绪 |
| 101 | `INITIALIZATION_FAILED` | 引擎初始化失败 |
