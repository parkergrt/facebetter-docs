美颜特效 SDK 处理图片和实时视频，覆盖 Android、iOS、Web、macOS、Windows、Linux。处理走 GPU 加速。枚举见 [参数枚举](./makeup)，套餐见 [套餐与功能](./pricing)。

## 核心能力

### 美肤

磨皮、美白、红润、祛痘。强度都是 `[0.0, 1.0]`，`0` 为关闭。

- 磨皮有 3 种风格：自然、质感、光滑。默认自然。
- 美白有 5 种色调：冷白、粉白、暖白、小麦、美黑。默认冷白。
- `setBeautySkinOnly` 让美肤只作用在皮肤区域。
- 祛痘独立于磨皮，使用皮肤区域，不使用人脸关键点。

### 调色

全画面调节。不使用人脸关键点或皮肤区域，也独立于美白、红润和 LUT 滤镜。

亮度、对比度、饱和度、色温、色调为 `[-1.0, 1.0]`，`0` 为中性。清晰度为 `[0.0, 1.0]`，`0` 为关闭，用来提高局部对比。

### 牙齿

`setTeethWhiten` 的范围是 `[0.0, 1.0]`，`0` 为关闭。只处理张开的嘴，闭嘴时不变。

### 美型

26 项，强度 `[-1.0, 1.0]`。`0` 保持原比例，正负为相反方向。单帧最多同时对 **5 张人脸**做美型和美妆。完整列表见 [参数枚举](./makeup)。需要**专业版**（免费版可带水印试用）。见 [套餐与功能](./pricing)。

### 美体

9 项，强度 `[0.0, 1.0]`，`0` 为关闭。没有负向。

其中 7 项沿身体变形：瘦身、瘦腰、瘦腿、瘦肩、瘦胳膊、长腿、美胸。这 7 项需要可选包 `resource_body.fbd`。见 [可选资源包](./resource-packs)。

`LegStretch`（腰以下拉伸）和 `TorsoLong`（下巴到腰修长）只用脸部关键点，不需要这个包。

需要**专业版 Plus**（免费版可带水印试用）。见 [套餐与功能](./pricing)。

### 美妆

口红、腮红、修容、眼影、眼线、眉毛、睫毛、美瞳。强度 `[0.0, 1.0]`。形状和色号分开设置，有两处例外：

- 口红是一张唇部蒙版加色号，共 6 个色号，没有样式切换。
- 修容和美瞳只换贴图，不染色。美瞳 9 色。

多项可以同时打开。枚举见 [参数枚举](./makeup)。需要**专业版**（免费版可带水印试用）。

### 滤镜

资源库有 **51** 款 LUT，分人像、新锐、美食、风景四类。可调强度。自定义滤镜是 `.fbd` 文件，用 `setFilter` 加载。需要**专业版**（免费版可带水印试用）。

### 贴纸

- **屏幕贴纸**：固定在画面上的位置。
- **人脸贴纸**：跟着人脸关键点移动。
- **3D 贴纸**：眼镜、帽子、面具等网格道具。需要 `resource_3d.fbd`。见 [可选资源包](./resource-packs)。

资源都是 `.fbd`。同一时刻一套 2D 贴纸用 `setSticker`，一套 3D 贴纸用 `set3DSticker`（路径或字节），用 `clearSticker` / `clear3DSticker` 关闭。新资源在下一帧处理后生效。需要**专业版 Plus**（免费版可带水印试用）。

### 虚拟背景

- **虚化**：`setVirtualBackgroundBlur`。`0` 关闭。
- **换图**：`setVirtualBackground`，传入 JPEG 或 PNG 的路径或编码字节。
- **色键**：以绿幕、蓝幕或红幕作为遮罩。相似度、边缘羽化、溢色抑制分开调节。没有虚化或换图时，抠除区域为透明。
- **主体描边**：沿抠像轮廓描边。虚化、换图或色键打开时才会画。

需要**专业版 Plus**（免费版可带水印试用）。

## 输入格式

| 类型 | 格式 |
| --- | --- |
| 静态图片 | JPEG、PNG |
| 视频帧 | YUV I420、NV12、NV21、RGB、RGBA、BGR、BGRA |
| GPU 纹理 | OpenGL / OpenGL ES 纹理 |

`ImageFrame` 可以在这些像素格式之间转换。

## 平台

| 平台 | 要求 |
| --- | --- |
| Android | 7.0+（API 24） |
| iOS | 12.0+ |
| Web | Chrome 57+、Firefox 52+、Safari 11+、Edge 16+。摄像头需要 HTTPS 或 `localhost` |
| macOS | 10.15+ |
| Windows | Windows 10+ |
| Linux | Ubuntu 22.04+ |

| 语言 | 适用 |
| --- | --- |
| Java / Kotlin | Android |
| Objective-C / Swift | iOS、macOS |
| C++ | Windows、Linux、macOS |
| JavaScript | 浏览器 SDK。不要把 `appKey` 放进页面。Node 只用来在服务端换许可证 token。见 [授权与许可](./license)。 |
