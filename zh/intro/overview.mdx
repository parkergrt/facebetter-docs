Facebetter 是一款面向开发者的实时美颜特效引擎，支持对图片与视频流进行高质量的 AI 美颜处理。引擎经 GPU 加速，具备低延迟、低 CPU 占用和高帧率，可集成到 Android、iOS、macOS、Windows、Linux、Web 与 Flutter。

## 核心能力

### 美肤

对人脸肤质进行细腻优化，包含磨皮、美白、红润、锐化四项基础参数。强度范围 `[0.0, 1.0]`（`0` 关闭）。磨皮和美白另有风格预设。

### 美型

从面部轮廓到五官比例进行全方位调整：

- **脸型**：瘦脸、V 脸、窄脸、短脸、小脸、额头
- **轮廓**：颧骨、下颌、下巴
- **五官**：瘦鼻 / 鼻长、人中、嘴大小 / 位置 / 微笑、嘴唇厚度
- **眼眉**：眼大小 / 眼距 / 圆眼 / 位置 / 角度 / 开眼角、卧蚕、眉位 / 眉距 / 眉粗细

强度范围 `[-1.0, 1.0]`。完整枚举见 [参数枚举](./makeup)。

> 单帧最多同时对 **5 张人脸**做美型与美妆。

### 美妆

提供真实感的分层彩妆：口红、腮红、眼影、眼线、眉毛、睫毛、美瞳、修容。强度、形状、色号可分开调节，多个项目可同时叠加。完整枚举见 [参数枚举](./makeup)。

### 滤镜与风格

内置 20+ 款实时风格滤镜，涵盖人像、美食、风景、现代风等多种主题，支持强度调节。自定义滤镜是 `.fbd` 文件，通过 `setFilter` 加载。

### 虚拟背景

基于实时人像分割实现以下两种效果：

- **背景模糊**：保留前景人物，对背景应用高斯模糊
- **背景替换**：将背景替换为 JPEG / PNG 图片

### 贴纸特效

支持 2D 贴纸特效，包括：

- **屏幕贴纸**：固定叠加在画面指定位置
- **人脸跟随贴纸**：锁定人脸关键点，随头部动态跟随

贴纸和滤镜资源都是 **`.fbd` 文件**。同一时刻只应用一套：用 `setSticker` / `setFilter`（路径或字节）加载，用 `clearSticker` / `clearFilter` 关闭。同一时刻只应用一套；新资源在下一帧处理后生效。

### 高级能力

- **人脸关键点回调**：每张检出的人脸返回 **111** 个归一化关键点（以及可见度、姿态、face id），可用于自定义特效与业务逻辑
- **色键抠图**：可抠绿幕 / 蓝幕 / 红幕，作为虚拟背景的遮罩

功能是否可用取决于订阅套餐。免费版可带水印试用大部分效果。详见 [套餐与功能](./pricing)。

## 输入 / 输出格式

### 图像格式

| 类型 | 支持格式 |
| --- | --- |
| 静态图片 | `JPEG`、`PNG` |
| 视频帧 | `YUV I420`、`NV12`、`NV21`、`RGB`、`RGBA`、`BGR`、`BGRA` |
| GPU 纹理 | OpenGL / OpenGL ES `Texture` |

### 分辨率上限

| 场景 | 上限 |
| --- | --- |
| 实时视频流 | `720P @ 60fps` / `1080P @ 30fps` |
| 静态图片处理 | 最高 `4K` |

`ImageFrame` 可在上述格式之间转换。

## 性能指标

| 指标 | 数据 |
| --- | --- |
| 渲染延迟 | `1080P` 平均约 `10ms`（GPU 并行） |
| CPU 占用 | 实时渲染阶段 < `5%` |
| 内存占用 | 主要驻留于 GPU 显存，系统内存占用低 |
