美颜特效 FCP 插件在 Final Cut 里的名字是 **Facebetter Beauty**，用于 **Final Cut Pro** 和 **Motion**，只支持 macOS Apple 芯片。美肤、美型、美妆、调色、贴纸、美体和背景都在这台 Mac 上处理。控件和 [OBS 美颜滤镜插件](/zh/obs/effects) 相同。这个插件没有 Facebetter 账号登录，没有效果预设，也没有按住对比。

只在 **FxFactory** 销售，没有独立安装包。试用带水印。在 FxFactory 购买后去掉水印。这是一次性购买，不是 Facebetter 订阅。

## 开始之前

- macOS **Apple 芯片**（M1 / M2 / M3 / M4）。
- 已安装 Final Cut Pro 或 Motion。
- 已安装 [FxFactory](https://fxfactory.com)。

## 安装

1. 从 [fxfactory.com](https://fxfactory.com) 安装 FxFactory。
2. 在 FxFactory 里安装 **Facebetter Beauty**。可以先试用再购买。
3. 完全退出 Final Cut Pro 或 Motion，再重新打开。
4. 在效果浏览器中找到 **Facebetter Beauty**，加到片段上。

同一套安装也可以在 Motion 里使用。

面板如果提示没有 FxFactory，先安装它再打开这个产品。**购买** 会打开 FxFactory 里的购买。

每一页调什么，见 [调节效果](/zh/fcp/effects)。找不到效果时看 [常见问题](/zh/fcp/faq)。
