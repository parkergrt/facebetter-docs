把 **Facebetter Beauty** 加到片段上，在效果面板里调节。画面在这台 Mac 上处理。

每一页有自己的重置，其他页不变。

<Note>
控件和 [OBS 美颜滤镜插件](/zh/obs/effects) 相同。OBS 文档里的「选中画面源」「登录」「按住对比」「效果预设」不适用于这个插件。这里没有 Facebetter 账号。试用水印和购买都在 FxFactory。见 [安装](/zh/fcp/install)。
</Note>

| 分页 | 这一页在调什么 |
| --- | --- |
| 美肤 | 磨皮样式、祛痘祛斑、肤色、红润、清晰。可以只作用在皮肤上。 |
| 美型 | 脸、额头和眉、眼睛、鼻子、嘴。每项都能往两个方向拖，0 是不动。 |
| 美妆 | 口红、腮红、牙齿、修容、眼影、眼线、眉毛、睫毛、美瞳。强度为 0 就是关掉这一项。 |
| 调色 | 亮度、对比度、饱和度、色温、色调，然后再选一个 LUT。 |
| 贴纸 | 一个面部贴纸、屏幕贴纸或 3D 道具。选无就去掉。 |
| 美体 | 身形、肩臂、腿。人在画面里要比只露一张脸更大，变化才明显。 |
| 背景 | 保留、虚化或换掉背景。抠图可以用人物检测，也可以用绿幕、蓝幕、红幕。 |
