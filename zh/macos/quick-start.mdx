## 环境要求

- **macOS 版本**：`macOS 10.15` 及以上
- **开发语言**：`Objective-C`（AppKit / `NSImage`）
- **架构支持**：`x86_64`、`arm64`（Apple Silicon）

## 获取示例源码

克隆 [GitHub 仓库](https://github.com/pixpark/facebetter-sdk) 到本地，进入 `demo/macos` 目录。

```bash
# clone
git clone https://github.com/pixpark/facebetter-sdk.git

# 进入 macOS Demo 目录
cd facebetter-sdk/demo/macos

# 安装依赖
pod install
```

<Warning>
**Xcode 15+ 编译错误**

使用 **Xcode 15** 或更高版本时，编译可能出现 `Sandbox: rsync.samba deny(1)`。这是 Xcode 默认开启 **User Script Sandboxing** 导致的。

**解决方法：**
1. 在 Xcode 中选择 **Project**。
2. 打开 **Build Settings**。
3. 搜索 `ENABLE_USER_SCRIPT_SANDBOXING`。
4. 将值从 `Yes` 改为 **`No`**。
</Warning>

## 配置应用信息与密钥

### 绑定应用 Bundle ID

按照 [绑定应用信息](/zh/intro/enable-service#绑定应用信息) 在控制台绑定 macOS 应用 Bundle ID，例如：`com.example.app`。

### 获取凭证

按照 [获取 AppID 和 AppKey](/zh/intro/enable-service#获取-appid-和-appkey) 取得 `appId` 和 `appKey`。打开 `demo/macos/FBExampleObjc/BeautyCameraViewController.m`，在 `FBEngineConfig` 上填写凭证。

```objc
FBEngineConfig *engineConfig = [[FBEngineConfig alloc] init];
engineConfig.appId = @"your appId";
engineConfig.appKey = @"your appKey";
// 推荐：licenseToken（许可证 token、{token} JSON，或 .lic 内容）
// engineConfig.licenseToken = @"your license token";

self.beautyEffectEngine = [FBBeautyEffectEngine createEngineWithConfig:engineConfig];
```

<Tip>
若 `licenseToken` 非空，SDK 会在本地校验该 token，**不会**再用 `appId` / `appKey` 请求 `/facebetter/v2/auth`。详见 [授权与许可](/zh/intro/license)。
</Tip>

1. 确保 Xcode 工程签名正确。
