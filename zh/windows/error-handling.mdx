## 返回值

大多数 setter 返回 `int`：

| 码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `-1` | 参数非法 |
| `-2` | 未初始化 |
| `-3` | 授权 |
| `-4` | 不支持 |
| `-5` | I/O |
| `-6` | 无空闲槽位（背压） |
| `-7` | 处理失败 |
| `-8` | 内存不足 |

`BeautyEffectEngine::Create()` 返回 `std::shared_ptr`，失败为 `nullptr`。`ProcessImage` 失败也可能返回空指针。

```cpp
int ret = engine->SetSmoothing(0.5f);
if (ret != 0) {
    std::cerr << "SetSmoothing failed: " << ret << std::endl;
}
```

## 引擎事件

`Create` 之后注册 `on_engine_event`：

| 码 | 含义 |
| --- | --- |
| `0` | 授权成功 |
| `1` | 授权失败 |
| `100` | 初始化完成 |
| `101` | 初始化失败 |

失败时 `message` 含详细说明。

```cpp
EngineCallbacks cbs;
cbs.on_engine_event = [](int code, const std::string& message) {
    if (code == 1 || code == 101) {
        std::cerr << "engine event " << code << ": " << message << std::endl;
    }
};
engine->SetCallbacks(cbs);
```

## 常见失败

### 1. `Create` 返回 `nullptr`

常见原因：

- `resource_path` 是目录、路径错误，或不是 `resource.fbd` **文件**
- `app_id` + `app_key` 无效，或 `license_token` 错误
- `facebetter.dll` 缺失或与 `facebetter.lib` 不匹配
- 无法访问 `/facebetter/v2/auth`

务必在 `Create` **之前**打开日志：

```cpp
LogConfig log_cfg;
log_cfg.console_enabled = true;
log_cfg.level = LogLevel::Debug;
BeautyEffectEngine::SetLogConfig(log_cfg);

EngineConfig cfg;
cfg.app_id = "your_app_id";
cfg.app_key = "your_app_key";
cfg.resource_path =
    (std::filesystem::current_path() / "resource" / "resource.fbd").string();

auto engine = BeautyEffectEngine::Create(cfg);
if (!engine) {
    std::cerr << "Create 失败：检查日志、resource.fbd 与授权。" << std::endl;
    return -1;
}
```

---

### 2. 找不到 `facebetter.dll`

DLL 不在加载路径时，Windows 会弹窗。

```bat
dir build\facebetter.dll
copy sdk\lib\facebetter.dll build\
```

或重新构建，让 CMake 复制到可执行文件旁。

---

### 3. `ProcessImage` 返回 `nullptr`

检查输入帧、引擎指针和日志（setter 上的 `-7` 处理失败 / `-8` 内存不足）。

```cpp
auto input = ImageFrame::CreateWithFile("input.jpg");
if (!input || !input->Data()) {
    std::cerr << "加载输入失败。" << std::endl;
    return;
}
input->type = FrameType::Image;
auto output = engine->ProcessImage(input);
if (!output || !output->Data()) {
    std::cerr << "ProcessImage 失败。" << std::endl;
}
```

---

### 4. 效果看起来没变化

2.0 **没有** `SetBeautyTypeEnabled`。强度为 `0` 即关闭。美型 / 美妆还需要检测到人脸。

```cpp
engine->SetSmoothing(0.5f);
engine->SetReshape(Reshape::FaceThin, 0.3f);
engine->SetLipstick(0.5f);
input->type = FrameType::Video;
```

---

### 5. OpenGL / 显示

驱动过旧、虚拟机或无 GPU 的远程桌面会导致 GLFW / `gladLoadGLLoader` 失败。

```cpp
if (!glfwInit()) {
    std::cerr << "GLFW init failed." << std::endl;
    return 1;
}
glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 0);
```

若应用已持有 GL 上下文，设置 `EngineConfig::external_context = true`，并在该线程调用 `ProcessImage`。

## 调试日志

```cpp
LogConfig log_cfg;
log_cfg.console_enabled = true;
log_cfg.file_enabled = true;
log_cfg.level = LogLevel::Debug;
log_cfg.file_name = "facebetter.log";
BeautyEffectEngine::SetLogConfig(log_cfg);
```

未使用绝对路径时，日志文件相对当前工作目录写入。
