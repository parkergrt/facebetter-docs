title: "快速开始"
description: "在 Windows 上构建并运行 Facebetter C++ 桌面示例（GLFW + ImGui）"
---

<Note>
本文对应 SDK **2.0.0**。Windows 与 Linux 共用同一套 C++ API（`facebetter` 命名空间，头文件 `facebetter/*.h`）。
</Note>

本文说明如何在 Windows 上构建 Facebetter C++ 桌面 Demo。Demo 使用 **GLFW + Dear ImGui + OpenGL 3**：左侧实时预览，右侧调节美颜参数。

## 环境要求

| 工具 | 版本 |
| --- | --- |
| Visual Studio / MSVC | 2019 或更高（C++17） |
| CMake | 3.16+ |
| Ninja | 任意较新版本（`winget install Ninja-build.Ninja`） |
| Windows SDK | 10.0+ |

<Tip>
也可以使用 MinGW-w64，但推荐 MSVC。
</Tip>

## 第一步：克隆仓库

```bash
git clone https://github.com/pixpark/facebetter-sdk.git
cd facebetter-sdk
```

## 第二步：放置 SDK 文件

将 Windows SDK 解压后放入 `demo/cpp/sdk/`：

```
demo/cpp/sdk/
├── include/
│   └── facebetter/
│       ├── beauty_effect_engine.h
│       ├── beauty_params.h
│       ├── image_frame.h
│       └── type_defines.h
├── lib/
│   ├── facebetter.lib      ← 导入库
│   └── facebetter.dll      ← 运行时 DLL
└── resource/
    ├── resource.fbd        ← 模型与资源包（必需）
    └── resource_3d.fbd     ← 可选；3D 贴纸。与 `resource.fbd` 同目录或调用 `AddResourcePack`
```

<Warning>
桌面端 `EngineConfig::resource_path` 必须指向 **`resource.fbd` 文件本身**，不能填目录。例如：`demo/cpp/sdk/resource/resource.fbd`。
</Warning>

<Tip>
SDK 包见 [下载页](https://facebetter.net/zh/download) 或 [控制台](https://facebetter.net/zh/dashboard)。
</Tip>

## 第三步：配置授权

运行前设置 `app_id` / `app_key`（在线 v2 鉴权），或设置 `license_token`。`license_token` 非空时优先（许可证 token、`{token}` JSON，或离线 `.lic` 内容）。详见 [授权与许可](/zh/intro/license)。

## 第四步：构建

打开 **Developer Command Prompt for VS**（或已加载 MSVC 环境的 PowerShell）：

```bat
cd demo\cpp
cmake -B build -G "Ninja" -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

构建完成后 CMake 通常会：

- 将 `facebetter.dll` 复制到 `build/` 可执行文件旁
- 将 `resource/resource.fbd` 复制到 `build/resource/resource.fbd`
- 若存在 `demo.png`，复制到 `build/resource/demo.png`

## 第五步：准备预览图（可选）

将人脸照片命名为 `demo.png`，放到 `demo/cpp/`：

```
demo/cpp/demo.png
```

## 第六步：运行

```bat
cd demo\cpp\build
.\facebetter_demo.exe
```

窗口包含：

- **左侧** — 实时美颜预览
- **右侧** — 控制面板：基础美颜、26 项美型（范围 `[-1.0, 1.0]`）、美妆、滤镜 / 贴纸 / 虚拟背景

点击 **Reset All** 可将强度归零。

## 常见问题

**Q：启动提示找不到 `facebetter.dll`**  
A：确认 `demo/cpp/sdk/lib/facebetter.dll` 存在，再执行 `cmake --build build` 让 CMake 复制到可执行文件旁。

**Q：`Create` 返回空指针 / 授权失败**  
A：`resource_path` 必须指向 `resource.fbd`，并配置 `license_token` 或有效的 `app_id` + `app_key`。见 [授权与许可](/zh/intro/license)。

**Q：CMake 找不到 Ninja**  
A：执行 `winget install Ninja-build.Ninja`，或改用 `-G "Visual Studio 17 2022"` 并配合 `--config Release`。
