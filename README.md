# Facebetter Docs

Mintlify documentation for the Facebetter SDK.

## Local preview

```bash
npm i -g mint
mint dev
```

Open [http://localhost:3000](http://localhost:3000).

## Navigation

- Languages: English / 简体中文
- Tabs: **SDK Docs** | **Effect Creator**
- Sidebar groups under SDK Docs: Introduction, Android, iOS, macOS, Windows, Linux, Web, Flutter

## Deploy

Connect this repository in the Mintlify dashboard. Pushes to the default branch publish to your `*.mintlify.app` site.
